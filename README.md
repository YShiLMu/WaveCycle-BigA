# 观复（WaveCycle）· 技术分析融合版

> 万物并作，吾以观复。——《道德经》

一个面向 A 股的 Codex/ZCode Skill：**以 Elliott Wave（艾略特波浪理论）数浪为主框架，叠加道氏理论（趋势前提）、江恩理论（时间/价位验证）与蜡烛图（K 线信号确认）交叉验证**。声明分析级别、数浪、Rule/Guideline 逐条校验、主备方案 + 独立失效价位、八因子概率排序、共振状态标注，输出自包含的分析报告（Markdown + 网页）与交易计划。

## 安装方法

### 方式一：把一句话发给 AI（推荐）

不需要碰命令行。打开 ZCode / Codex / DSH 任一客户端，新建对话，把下面这句话原样发给它：

```text
帮我安装这个技能：https://github.com/YShiLMu/WaveCycle-BigA
```

AI 会克隆仓库并放到本地技能目录（`~/.agents/skills/wavecycle`）。装完**重启客户端**，再发一句确认是否生效：

```text
列出你当前可用的技能，看看有没有 wavecycle
```

### 方式二：手动安装

```bash
git clone https://github.com/YShiLMu/WaveCycle-BigA.git wavecycle
cp -r wavecycle ~/.agents/skills/    # 通用技能目录；ZCode 亦识别 ~/.zcode/skills/，Codex 识别 ~/.codex/skills/
# 重启客户端
```

## 前置依赖

> **以下两条是硬性要求，缺一不可。**
>
> 1. **必须安装 Python 3.10 或 3.11**。其他版本（3.9 及更早、3.12 及以上）未经验证，可能因第三方依赖装不上而跑不起来。
> 2. **必须安装两个库：`pandas` 与 `matplotlib`**。技能的分析脚本（取数、锚点检测、绘图、校验）全部依赖它们，缺任何一个都会直接报错。

```bash
pip install pandas matplotlib
```

- 未装 Python 时从官网下载：https://www.python.org/downloads/ （Windows 安装时务必勾选 "Add Python to PATH"）
- 装完可自检：`python --version` 与 `python -c "import pandas, matplotlib"`

### A 股数据（仅分析 A 股时需要）

1. 安装 [`a-stock-data`](https://github.com/simonlin1212/a-stock-data) skill：同样把链接发给 AI 说"帮我安装这个技能"，或手工放入技能目录后重启客户端；
2. 安装其 Python 依赖：`pip install mootdx requests pandas stockstats`。

**不想装 `a-stock-data` 也可以**：在同花顺日线页面按 **F1** 导出数据（或直接截图），作为数据源交给技能即可。

分析非 A 股市场（美股、港股、期货、加密货币等）不需要 `a-stock-data`，由用户直接提供数据或图表即可（上方 Python 环境与两个库仍需安装）。

## 使用方法

装好之后就是一句话的事：

```text
分析一下贵州茅台的走势
```

标的换成任意股票名称或代码都行，非 A 股直接附上图表。技能会自动接管：定级别、数浪、主备方案校验、标失效价位、出报告，中途需要确认的地方（如交付深度）会主动问你。

## 输出物

每次分析交付两份文档（归档到 `分析输出/<标的>_<代码>_<时间>/`）：

- **分析报告.md**：8 章节——分析前提（含道氏趋势状态）、主方案、替代方案（各含道氏背景、江恩共振与蜡烛图信号）、八因子概率排序与理由（含共振状态表）、失效价位清单、交易计划、风险提示、更新与跟踪；
- **网页报告.html**：同一内容的快捷查看版，主备方案图标签页切换，图片自包含。

## 四层分工

- **道氏理论（前提层）**：管"能不能做"。用高低点结构与指数互证判定趋势状态（牛市/熊市/震荡），作为数浪的方向先验；
- **波浪理论（主框架）**：管"做到哪一步"。结构、数浪、级别与失效价位；
- **江恩理论（验证层）**：管"什么时候到"。角度线、1/8 分割、时间窗只做目标测算与共振加分；
- **蜡烛图（信号层）**：管"转折是否确认"。K 线信号（反转/持续）做数浪方向与关键位的交叉确认。

**优先级铁律：波浪 Rule > 道氏 > 江恩 ≈ 蜡烛图**。道氏、江恩、蜡烛图一律是 Guideline 级证据，永不否决数法、永不覆盖失效价位。共振时出手、背离时观望——这是本 Skill 的核心纪律。

## 特性

- **48 条硬规则 + 42 条准则的双层裁决**：Rule 违反即数法无效，Guideline 违反只降概率并说明理由；另配 EG-01~EG-07 工程门禁（级别声明、主备完备、细分深度穿透、留痕等）机器强制校验
- **八因子概率排序**：Guideline 命中数 ×2 + 结构完整度 + 斐波那契共振 + 道氏趋势一致性 + 江恩价格共振 + 江恩时间共振 + 蜡烛图信号 + 失效价位距离（权重 2:1:1:1:1:1:1:1），按 0/1/2 打分，不输出伪精确的百分比
- **共振状态标签与仓位闸门**：三共振/双共振/单信号/背离四态；双共振（含道氏一致）升一档、三共振再升一档，背离强制观望
- **江恩时间纪律**：固定时间窗清单（30/60/90/144/180/360 天 + 周年日）+ 预登记制度，"波浪定带、江恩定点"，禁止事后挑窗
- **A 股指数互证口径**：主板 = 上证指数 + 板块指数；创业板（300）= 创业板指 + 板块指数；科创板（688）= 科创指数 + 板块指数
- **主备双方案机制**：标准分析给出主方案 + 至少一个替代方案，各自独立失效逻辑与含影线极值价位；仅在豁免条件成立时才允许单方案并披露
- **自包含交付**：分析报告 + 网页报告，浪型图（K 线 + 浪段标注 + 失效价位 + 可选江恩角度线）base64 内嵌，单文件即可转发

## 设计原则

- **不谈级别的数浪无效**：任何分析先声明分析级别（Degree）；
- **失效价位是最高权威**：任何理论（包括江恩）给出的价位都不能覆盖失效价位；
- **概率表述有边界**：只说"大概率/倾向于/通常"，禁止"必然/一定/绝对"；
- **假设数据必须显著标注**：后续走势尚未发生时如实标注为预期，禁止编造已完成的结构。

│   ├── checklists.md         # 校验清单与 EG-01~EG-07 双轨门禁
│   ├── workflow.md           # 分析工作流
│   └── patterns.md / terminology.md / defaults.md / data.md / rule_conflicts.md / tool_discipline.md
├── assets/                   # 报告、网页报告、复盘、失效追踪、交易计划模板

    ├── rule_check.py         # R 系列硬规则机审
