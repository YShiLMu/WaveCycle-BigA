## 一、数据契约与列序铁律（最高优先级）

在量化技术分析与多尺度波浪推演中，数据清洗与落盘格式是整个分析大厦的基石。任何列序错位或数据污染都将导致极值计算错误、波浪端点漂移甚至方向颠倒。

### 1.1 CSV 表头列序强制契约（D28）
所有进入 WaveCycle 流水线的行情 CSV 文件，在落盘或输入脚本前，**必须且只能**严格遵循以下表头字段与排列顺序：

$$\text{Columns} = [\texttt{date}, \texttt{open}, \texttt{high}, \texttt{low}, \texttt{close} \quad (,\texttt{volume})]$$

| 字段索引 | 字段名 | 类型 | 严格定义与物理含义 |
| :---: | :---: | :---: | :--- |
| `0` | `date` | `string` | 交易日期或分钟时间戳（日线格式 `YYYY-MM-DD`，分钟线格式 `YYYY-MM-DD HH:MM:SS`） |
| `1` | `open` | `float` | 开盘价（严格大于 0） |
| `2` | `high` | `float` | 最高价（必须满足 $\text{high} \ge \max(\text{open}, \text{close}, \text{low})$） |
| `3` | `low` | `float` | 最低价（必须满足 $\text{low} \le \min(\text{open}, \text{close}, \text{high})$） |
| `4` | `close` | `float` | 收盘价（严格大于 0） |
| `5` | `volume` | `float/int` | 成交量（可选字段，若存在必须 $\ge 0$） |

#### 严打接口返回“倒错陷阱”
- **腾讯接口（`fqkline`/`mkline`）与部分美股、港股源**返回的数据格式中，原生列序常为 `[date, open, close, high, low, volume]`（即 `close` 排在 `high` 之前）。
- **铁律警告**：若直接将此类原始数据送入分析引擎，最高价与收盘价将产生致命对调，导致所有的长上影线被削平、突破判定失效、摆动极值点（Swing Pivots）彻底失真！
- **强制清洗动作**：数据获取脚本在将 DataFrame/字典写入 CSV 之前，必须显式执行字段重排：
  ```python
  # 强制字段重排防呆模板
  df = df[['date', 'open', 'high', 'low', 'close', 'volume']]
  ```

### 1.2 「data_check」（源文件） 严格校验与退出码 1 熔断机制
在任何数据文件提供给后续分析模块前，必须无条件执行数据自检工具：
```bash
python 06_技能_skill/scripts/data_check.py --csv "<CSV绝对路径>" --source "<数据源>" --fq qfq --require-metadata
```
- **注意**：`--csv` 为**具名必填参数**，四个数据脚本（「data_check」（源文件） / 「preflight」（源文件） / 「swings」（源文件） / 「key_levels」（源文件））都不接受位置参数；照抄漏写 `--csv` 会直接 argparse 报错。
- **表头精准匹配**：「data_check」（源文件） 会逐字比对首行表头。凡存在字段缺少、名称大小写不符、多余空格或列序错位者，脚本**立即抛出致命异常并以退出码 1 熔断退出**。
- **元数据绑定（Metadata）**：生产级分析必须配套 `<CSV路径>.metadata.json`，声明数据源（`source`）、复权类型（`fq`）、截止时间戳（`as_of`）、时区（`timezone`）以及对应 CSV 的 SHA-256 哈希值。**复权口径**：日线默认前复权（`qfq`），与同花顺/东财前复权可见价位一致，也是 `02_案例库` 的既有口径；仅当用户显式要求后复权时才使用 hfq（此时须确保 a-stock-data 复权因子完整、匹配且应用结果通过自检），禁止自行推算因子或谎称 hfq；分钟分形层独立不复权（`none`，见 D42）。除权后 qfq 历史价格整体漂移，更新报告时必须全量重算失效价位并在第 8 章登记。哈希校验不一致时同样触发熔断。

### 1.3 中间数据落盘口径与环境隔离
为保持代码库与生产工作区的纯净，杜绝并发分析时的脏文件冲突：
- **中间数据一律写入系统临时目录**：分析过程产生的临时行情切片、调试文本、中间转换 CSV，必须通过 Python 的 `tempfile.gettempdir()` 写入系统临时目录（如 `%TEMP%` 或 `/tmp`）。
- **三项绝对禁止**：
  1. 绝对禁止将中间数据、临时脚本写入仓库根目录；
  2. 绝对禁止写入任何源码与技能目录（如 `01_`–`07_`）；
  3. 绝对禁止将调试中间件散落写入正式的 `分析输出/` 归档目录。
- **内联脚本路径铁律**：内联运行的脚本在读写文件时，必须使用解析后的绝对路径，严禁使用相对路径 `./` 依赖当前工作目录。

## 二、CLI 脚本调用与防呆纪律

WaveCycle 体系配备了高精度的标准化 Python 工具箱（位于 `06_技能_skill/scripts/`）。严禁任何执行代理“重复造轮子”或自行拼接不可靠的即兴数学逻辑。

### 2.1 脚本优先与“调用先读 `--help`”契约
1. **能调入库工具，绝不自写脚本**：极值提取用 「swings」（源文件），预检质检用 「preflight」（源文件），关键位扫描用 「key_levels」（源文件），规则复核用 「rule_check」（源文件），绘图用 「ew_chart」（源文件）。
2. **强制查阅接口定义**：在首次调用任何工具或传递复杂参数前，必须先在终端执行 `python <脚本路径> --help` 确认最新支持的参数标志，严禁凭模糊记忆臆造命令行参数。

### 2.2 核心脚本传参标准与格式防呆

```
+---------------------------------------------------------------------------------------------------+
|                                 核心 CLI 脚本传参规范与防呆拓扑                                    |
+---------------------------------------------------------------------------------------------------+
|  [ preflight.py ]  --> 数据自检 + 道氏高低点 + 关键锚点 (默认 --compact 截断尾部 40 点防爆窗口)  |
|         |                                                                                         |
|  [ swings.py ]     --> 局部极值提取: --k 5/3/1 自适应多尺度; 格式输出: [索引, 日期, 极值类型, 价格] |
|         |                                                                                         |
|  [ key_levels.py ] --> 三类物理锚点: 摆动簇 (Pivots) + 筹码峰 (Clusters) + 道氏分水岭 (Dow)       |
|         |                                                                                         |
|  [ rule_check.py ] --> 冒号三段传参: --wave "标签:起点价:终点价" (支持自适应极值容差)            |
|         |                                                                                         |
|  [ ew_chart.py ]   --> 绘图引擎: --path "标签@索引" (单浪链拓扑连续性 + 端点唯一性校验)           |
+---------------------------------------------------------------------------------------------------+
```

#### 1. 「rule_check」（源文件）：冒号三段格式
调用波浪规则校验脚本时，波浪几何参数必须采用标准的冒号分隔三段格式：
```bash
python 06_技能_skill/scripts/rule_check.py --wave "标签:起点价格:终点价格"
# 示例：验证大级别浪 1 推动
python 06_技能_skill/scripts/rule_check.py --wave "[1]:2635.09:3174.27" --wave "[2]:3174.27:2689.70"
```
- **禁止格式**：严禁写成逗号分隔、空格分隔或以日期代替价格。
- **方向与价位自洽**：起点价格与终点价格必须严格反映行情波动的真实方向（上升浪终点高于起点，下跌浪终点低于起点）。

#### 2. 「ew_chart」（源文件）：单一连续浪链与端点索引映射
- **整数索引对齐**：「ew_chart」（源文件） 内部基于 K 线数组的整数索引（Index `0` 到 `N-1`）进行几何渲染。
- **`--path` 单一浪链连续性契约**：传入 `--path` 的浪型路径必须是拓扑连续的折线链条。除起点外，每一段子浪的起点必须与前一段子浪的终点严格重合。
- **端点日期唯一性约束**：同一条折线路径中，各节点的日期序列必须单调递增，严禁出现时间回溯或同一日期重复绑定不同价位的矛盾。
- **分层独立出图**：大级别浪（无连字符，如 `(1)`、`[1]`）、第二层子浪（带单连字符，如 `1-1`）、第三层微观子浪（如 `1-1-1`）必须按层级独立配置参数，工具箱已设置硬拒绝门禁，跨层级混放进同一条 `--path` 将直接报错熔断！

#### 3. 「preflight」（源文件）：输出紧凑与全量切换（D40）
- **默认紧凑模式（Compact）**：为防止长周期 K 线数据（如上千根日线）导致 LLM 上下文爆炸，「preflight」（源文件） 默认仅返回行情摘要、道氏关键高低点结构以及尾部 40 个摆动点（满足 95% 实战数浪场景）。
- **全量参数切换**：当且仅当需要回溯数年以上的历史超大级别母浪划分时，方可显式传入 `--no-compact` 参数拉取全量数据。

## 三、分析报告三大法定交付门禁

任何技术分析报告或方案输出，必须无条件通过以下三大法定交付门禁。缺少任何一项，该交付物在系统评审中将直接被判定为不合格。

### 门禁一：波浪级别声明强制（EG-01）
> **“不谈级别的数浪毫无意义。” —— 艾略特波浪理论公理**

1. **强制声明双层级别**：在展开任何具体数浪推演前，必须在报告正文第一章明确声明：
   - **分析主级别（Primary Degree）**：如大浪（Major）、中浪（Intermediate）；
   - **微观细分级别（Sub-Degree）**：如小浪（Minor）、细浪（Minute）、微浪（Minuette）。
2. **严禁孤立数浪**：禁止在脱离宏观级别背景的情况下直接给出 `1-2-3-4-5`。
3. **级别变更追溯**：在后续跟踪中若因形态重构需要调整分析级别，必须在报告“变更日志”中详细阐明级别升降的数学与形态理由。

### 门禁二：标注符号与层级契约（EG-02）
为消除语义模糊与层级混淆，WaveCycle 全面采纳普莱切特（Prechter）经典 9 级波浪标注符号体系。严禁在同一份报告中自相矛盾或混用不同风格的标注符号。

#### 普莱切特 9 级波浪标注标准映射表
| 级别层级 | 英文名称（Degree） | 驱动浪标注符号（Impulse） | 调整浪标注符号（Correction） | 推荐图表展示色彩 |
| :---: | :--- | :---: | :---: | :---: |
| **L1** | 超大循环浪（Grand Supercycle） | `[I]` `[II]` `[III]` `[IV]` `[V]` | `[A]` `[B]` `[C]` | 紫红色 |
| **L2** | 大循环浪（Supercycle） | `(I)` `(II)` `(III)` `(IV)` `(V)` | `(A)` `(B)` `(C)` | 亮白色 |
| **L3** | 循环浪（Cycle） | `I` `II` `III` `IV` `V` | `A` `B` `C` | 亮白色 |
| **L4** | 大浪（Primary） | `[1]` `[2]` `[3]` `[4]` `[5]` | `[A]` `[B]` `[C]` | 亮白色（主网格） |
| **L5** | 中浪（Intermediate） | `(1)` `(2)` `(3)` `(4)` `(5)` | `(A)` `(B)` `(C)` | 青绿色 |
| **L6** | 小浪（Minor） | `1` `2` `3` `4` `5` | `A` `B` `C` | 青绿色 / 橙黄色 |
| **L7** | 细浪（Minute） | `(i)` `(ii)` `(iii)` `(iv)` `(v)` | `(a)` `(b)` `(c)` | 橙黄色 |
| **L8** | 微浪（Minuette） | `i` `ii` `iii` `iv` `v` | `a` `b` `c` | 鲜橙色 |
| **L9** | 次微浪（Subminuette） | `[i]` `[ii]` `[iii]` `[iv]` `[v]` | `[a]` `[b]` `[c]` | 亮黄绿色（分钟图） |

#### 标注契约铁律
- **形态类别绑定**：推动浪与斜纹浪只能使用数字系列；常规单调整浪只能使用英文字母 `A-B-C`；三角形调整浪只能使用 `A-B-C-D-E`；复合调整浪（双重/三重）只能使用 `W-X-Y` 或 `W-X-Y-X-Z`。
- **层级包含单调性**：父级波浪绝不能包含与自身同级别或更高级别的子浪标记（例如：中浪 `(1)` 内部只能细分为小浪 `1-2-3-4-5`，绝不能出现父级 `(1)` 内部包含 `(1)-(2)` 的嵌套倒错）。

### 门禁三：多重数浪双方案强制（EG-03）
> **市场走势存在内在的多重可能性。单一方案的自信是技术分析者陷入灾难性认知偏见（Confirmation Bias）的根源。**

1. **主备方案强制并存**：任何标准分析交付物，**必须同时提供【主方案（Preferred Count）】与至少一个【替代方案（Alternate Count）】**。
2. **独立失效价位声明**：主方案与替代方案必须各自拥有**完全独立的失效条件与物理失效价位（Invalidation Level）**。严禁含糊其辞地共享一个模糊区间。
3. **单方案防御特例（观望模式）**：
   - 仅在极度罕见的极端单边突破或极端数据缺失场景下，若穷尽合法组合仍无法构建具备理论支撑的替代方案，允许触发“单方案防御”；
   - **代价与约束**：一旦触发单方案防御，报告必须在扉页加粗警示“当前处于单方案防御状态”，明确指出缺失替代方案的原因与待确认观察项，**并将交易计划强制锁定为“观望（Zero Position）”，严禁提出任何激进建仓建议**！

## 四、深度分形与图表呈现规范

### 4.1 细分深度 3 层/4 层登记门禁（EG-04）
波浪分析的价值在于全息分形（Fractal）与微观验证，绝不能退化为简陋的几条宏观大折线。

**深度与分钟层是两个正交维度，不得混为一谈**：交付深度只表示**日线树深度**（3 或 4）；分钟分形层是**附加验证层**，不参与编号，也不改变交付深度。

1. **默认分析深度（日线 3 层）**：
   标准日线交付必须覆盖 3 个层级：
   - **第 1 层（大级别骨架）**：宏观走势大浪/中浪（如 Primary / Intermediate）；
   - **第 2 层（子浪推进）**：当前波段的小浪（Minor）；
   - **第 3 层（微观确认）**：最新活跃波段的细浪（Minute）。
   - 登记标识：`细分深度来源=默认-3层`（用户明确要求 3 层则 `用户确认-3层`）。
2. **日线 4 层扩展（大级别标的专属）**：
   - **适用对象**：主要股指、长史板块等跨度长、日线分辨率充裕的标的 —— 这类标的**在日线上就能分出第 4 层**，不需要分钟数据；
   - **触发方式**：「门禁 A」（`01_数据获取` §六）询问后由用户确认，**未询问不得自行下钻**；
   - **范围限定**：用 `fourth_layer_roots` 指定展开到 4 层的第三层父浪（全分析树或指定分支），「analysis_scope」（源文件） 拒绝更深路径；
   - 登记标识：`细分深度来源=用户确认-4层`。
3. **分钟分形层（附加验证层，D42）**：
   - **不是第 4 层的同义词**：不论交付 3 层还是日线 4 层，都可能启用或不启用分钟层；
   - **触发方式**：「门禁 B」（`02_数浪` §4.6）在交付深度最后一层完成后询问；
   - 登记标识：报告【分析前提】的“分钟分形层”行，值 ∈ `已询问-启用`／`已询问-不启用`／`未询问-环境无交互`。
4. **严查“大直线退化”防偷懒铁律（D41）**：
   - **15 根 K 线红线**：在日线分析中，任何一段历史已确认走完的父级波浪，若其时间跨度横跨超过 **15 根日 K 线**，**严禁以“走势光滑”、“无明显回调”或“缺少更细数据”为由将其画为一条孤立的大直线**！
   - **必须强制展开次级内部构造**：哪怕内部子浪幅度较小，也必须借助多尺度摆动算法（$k=3$ 或 $k=1$）提取内部 5 浪或 3 浪分形，完整登记端点。

### 4.2 实虚线与波浪完成状态契约（EG-06）
在波浪图表绘制与路径规划中，必须以线型清晰区分“客观历史事实”与“主观推演外推”。

```
=============================================================================
【历史已发生区间】                                   【未来外推与未完成区间】
-----------------------------------------------------------------------------
[实线 (Solid Line)]                                  [虚线 (Dashed Line)]
- 历史确认已走完波浪                                  - 当前正在运行中的活跃未完成段
- 完成候选段 (completion_candidate)                 - 未来路径预测与斐波那契投射轨迹
  (端点递增连续、价格交替、后续推进已展开)               (严禁标注确定终点与虚构未来日期)
=============================================================================
```

1. **实线绘制范围**：
   - 所有历史已完全确认终点的波浪；
   - **历史完成候选段（`completion_candidate`）**：历史已走完区间内部的子浪，只要满足端点递增连续、价格高低交替且后续反向/同向推进已实质展开，即刻作为完成候选以**实线**绘制，不再机械要求必须等待漫长的大级别反向摆动确认。
2. **虚线绘制范围**：
   - 当前正在进行、终点尚未物理封口的活跃推进段；
   - 基于波浪结构与斐波那契目标外推的未来预测路径。
3. **未完成段严禁伪造事实**：当前活跃段绝对不能在图表或数据中伪造确定终点价格，未发生的时间窗口绝对不能填写虚构的未来交易日期。

### 4.3 渲染色彩规范与分层辨识度
为确保图表视觉清晰，「ew_chart」（源文件） 严格遵循四色分级标准：
- **第一层（大级别宏观骨架）**：纯白实线（`#FFFFFF`），粗度 2.0px；
- **第二层（次级子浪推进）**：青绿实线（`#00E5FF` / `#00C853`），粗度 1.5px；
- **第三层（微观细分子浪）**：亮橙实线（`#FF9100`），粗度 1.2px；
- **第四层（日线第 4 层或分钟分形微浪，配色按路径深度）**：黄绿虚线/细线（`#AEEA00`），粗度 1.0px；分钟图组为独立图表，其层级配色沿用 `--path` 路径深度，不代表“第 4 层＝分钟”；
- **失效警戒线（Invalidation Line）**：红色虚线（`#D50000`），强制标注触发失效的具体规则编号（如 `R-IMP-02`）。

## 五、多 Agent 协同契约框架（Subagent Brief Frame）

在复杂分析任务中，主协调 Agent（Main Agent）常常需要派发细分子代理（如专门数微观浪的 `wave-3` 或分钟线微观探针）。为保证协同效率与上下文纯净，必须严格遵守以下契约。

### 5.1 子代理输入上下文隔离契约
主 Agent 在生成子代理 Prompt 时，必须将信息严格约束在“任务最小必要集”之内，严禁将全量无关知识库全文灌入子代理。

#### 子代理标准 Prompt 包装结构
```markdown
### 1. 任务背景与分析标的
- 标的名称与代码：[如 科创50 / 1B0688]
- 行情数据切片绝对路径：[必须提供 %TEMP% 下已完成列序重排的标准化 CSV]
- 待细分父浪标签与属性：[如 中浪 (3)，性质：驱动浪，起点与终点已知价格范围]

### 2. 分析时间窗口与极值基准
- 起点时间与价格：[YYYY-MM-DD / P_start]
- 终点时间与价格：[YYYY-MM-DD / P_end]
- 必须强制契合的三类技术锚点：[列出 key_levels 提取的该区间关键 Pivots]

### 3. 工作范围与绝对红线
- 任务：仅提取该父浪内部的次级波浪划分（5 浪或 3 浪）；
- 绝对禁止：子代理不评估大级别方向，不输出最终投资建议，严禁擅自改动父浪的起终点！
```

### 5.2 子代理输出标准结构化格式
子代理完成计算后，必须以结构化 Markdown 表格形式回传结果，严禁返回杂乱的口语化叙述：

```markdown
#### 子浪划分清单（Sub-Wave Breakdown）
| 序号 | 子浪标签 | 起点日期 | 起点价格 | 终点日期 | 终点价格 | 涨跌幅(%) | 浪型性质 | 完成状态 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 1 | 3-1 | 2026-02-05 | 802.10 | 2026-02-28 | 895.40 | +11.63% | 推动浪 | 确认完成 |
| 2 | 3-2 | 2026-02-28 | 895.40 | 2026-03-15 | 838.20 | -6.39% | 单锯齿 | 确认完成 |
| 3 | 3-3 | 2026-03-15 | 838.20 | 2026-04-10 | 972.50 | +16.02% | 延长推动 | 确认完成 |
| 4 | 3-4 | 2026-04-10 | 972.50 | 2026-04-25 | 920.00 | -5.40% | 平台形 | 确认完成 |
| 5 | 3-5 | 2026-04-25 | 920.00 | 2026-05-12 | 1015.30| +10.36% | 推动浪 | 确认完成 |

- **内部几何验证**：浪 3 长度 (134.30) > 浪 1 长度 (93.30)，且浪 3 绝非最短浪；浪 4 终点 (920.00) 远离浪 1 顶点 (895.40)，未发生重叠。硬性规则校验 100% 通过。
```

### 5.3 越权裁决防御机制
- **状态冻结**：若子代理在计算微观波浪时发现与父浪既定前提产生冲突（例如发现内部只能数成三浪调整，无法构成五浪推动），**子代理无权自行篡改父级标签**！
- **异常上报**：子代理必须在输出中明确标记 `【结构冲突异常上报】`，将微观矛盾原样回传给主协调 Agent，由主协调 Agent 在更高维度的“多重数浪推演流水线”中统一裁决是否升级替代方案。

### 1.3 复权模式规范与基准披露三要素
在技术分析与波浪形态度量中，必须保证历史价格的几何连续性：
1. **复权口径（与线上 references/data.md 对齐）**：
   - **日线默认前复权（QFQ）**：报告全部价位即同花顺/东财前复权可见价位，与 `02_案例库` 既有口径一致，便于用户直接对照行情软件；腾讯 `fqkline` + 新浪因子链路可直接产出；
   - **可执行路径与可选后复权**：仅当用户显式要求后复权（HFQ）时，才须确保 a-stock-data 的复权因子完整、匹配且 `apply_adjust` 结果通过自检，否则拒绝而非静默降级，**禁止自行推算因子、禁止谎称 hfq**；
   - **不变式与漂移代价**：hfq 与 qfq 只差一个常数比例因子，形态、比例、时间关系完全相同，换口径不得据此推翻既有数浪；但除权后 qfq 历史价格整体漂移，更新报告时必须全量重算失效价位并在第 8 章登记；
   - **分钟层**：分钟分形层一律独立不复权（`none`，D42），与日线只做时间戳锚定，禁止跨周期混算价格。
2. **基准披露三要素**：在生成的《分析市场准备卡》与最终报告中，必须完整披露：
   $$\text{Benchmark} = \{\text{复权方式: hfq/qfq/none（实际值）}, \quad \text{数据源名称: 如腾讯 fqkline}, \quad \text{数据截至时间戳: YYYY-MM-DD HH:MM}\}$$
3. **口径漂移禁令**：同一标的的日线与分钟线必须分别登记各自复权口径；报告中不得只写"复权"而不注明 hfq/qfq/none。

### 1.4 分钟分形层切片协议（Minute Fractal Slicing，D42）

分钟分形层是**附加验证层**：不参与日线交付深度编号，是否启用由 Step 02 的「门禁 B」询问用户后决定（见 「02_数浪实战与多重候选推演」（源文件））。启用后唯一入口为 `scripts/minute_slice.py`，**三轮交互**，脚本只产出切片与摆动候选事实，浪级/形态/完成状态一律由模型裁决。

| 轮次 | 动作 | 脚本命令 | 产出与裁决 |
| :--- | :--- | :--- | :--- |
| 第 1 轮 | 日线深度完成，锁定活跃浪起点 `T_d0`（含 H/L 属性） | 无（模型裁决） | `T_d0` 日期 + 极值属性；写入候选 JSON 与询问记录 |
| 第 2 轮 | 切 60m | `minute_slice.py --freq 60 --anchor-date <T_d0> --anchor-kind H\|L`（可选 `--daily-csv` 做锚点日跨源核对） | 契约 CSV + 元数据 + 指标 sidecar + 分形 Pivot 候选；模型裁决 60m 当前子浪起点 `T_60m0`（精确到 bar 时间戳） |
| 第 3 轮 | 切 30m + 15m | `minute_slice.py --freq 30,15 --anchor-ts <T_60m0>` | 模型完成 30m/15m 分析，检验「日线最深层 — 60m — 30m — 15m」四级分形共振与蜡烛图确认 |

**固定口径（禁止自行改动）**：

1. **数据源**：分钟线唯一全板块可用源为腾讯 `mkline`；**固定按 800 根请求并校验返回根数**——>800 静默回退 320 根属高危陷阱，不足即报错重取。东财/百度分钟线存在断流与时间戳错位，禁用。
2. **bar 密度与保底**：60m=4 根/日、30m=8 根/日、15m=16 根/日；保底根数 60m=32、30m=24、15m=32（15m 窗口上限 64 根，起点取 30m 最新摆动段起点与最近 32 根的较早者）。
3. **前浪缓冲**：60m 左留 8 根、30m 左留 4 根作为前浪上下文，并在元数据标注“前浪上下文”。
4. **锚点对齐**：日级锚点用当日 `argmin(low)`／`argmax(high)` 排名定位（并列取最早）；跨源极值核对容差 0.5%，超差只披露不阻断。时间戳标 **bar 结束时刻**（60m=10:30/11:30/14:00/15:00）。
5. **复权隔离**：分钟线全源不复权（`none`），与日线（hfq/qfq）**只做时间戳锚定与结构映射，严禁跨周期混算价格**；分钟级斐波那契/江恩按本周期切片自身极值独立计算。报告数据基准须分别披露日/60m/30m/15m 四条数据链。
6. **指标**：MACD(12,26,9)／RSI(14)／MA(5,10,20,60) 在全量数据上先算后切片，只进 `*.indicators.csv` sidecar，**仅作动量衰竭/背离的辅助共振证据，禁入结构判定**。
7. **单次分析锁单一时源**；切片参数与锚点写入元数据，供复核复现。

## 二、行情数据拉取与前置质量校验（Preflight Check）

数据拉取后，严禁直接送入数浪算法，必须执行自动化的预检质检流水线。

### 2.1 自动化拉取与格式清洗脚本
数据抓取脚本必须无条件遵守 `00_系统工程规范`，在写入磁盘前完成列序重排与路径隔离：

> **可执行片段（唯一取数入口）**：常规 A 股日/周/月 K 线按下面的片段取数，**不需要加载 a-stock-data**；仅当需要非常用端点（研报、资金面、期权、公告、打板等）时才整篇加载它。分钟线走 §1.4 的 mkline 协议；其他市场以用户提供数据为准。

```python
"""最小可执行取数片段：A 股日/周/月 K 线（腾讯 fqkline）+ 复权（新浪因子）。

输出契约：<TEMP>/wavecycle/<symbol>_<freq>_<fq>.csv（date,open,high,low,close,volume）
         同名 .metadata.json（source/fq/as_of/timezone/csv_sha256）
可直接喂 data_check.py / preflight.py；周/月线改 freq="week"/"month"。
"""
import hashlib
import json
import os
import tempfile
from datetime import datetime

import pandas as pd
import requests

UA = {"User-Agent": "Mozilla/5.0"}
KLINE_URL = "https://web.ifzq.gtimg.cn/appstock/app/fqkline/get"
FACTOR_URL = "https://finance.sina.com.cn/realstock/company/{symbol}/{kind}.js"
PRICE_KEYS = ("open", "high", "low", "close")


def to_frame(rows):
    """腾讯列序是 date,open,close,high,low,volume —— 先重排为标准 OHLC 列序（D28）。"""
    df = pd.DataFrame(rows).iloc[:, :6]
    df.columns = ["date", "open", "close", "high", "low", "volume"]
    df["date"] = df["date"].astype(str).str[:10]
    for col in PRICE_KEYS + ("volume",):
        df[col] = pd.to_numeric(df[col], errors="coerce")
    return df[["date", "open", "high", "low", "close", "volume"]]


def fetch_raw(symbol, freq="day", start="1990-01-01", end=None, pages=12):
    """腾讯 fqkline 不复权全历史：单请求上限 1300 根，按首根日期向前翻页。"""
    end = end or datetime.now().strftime("%Y-%m-%d")
    segs, cursor = [], end
    for _ in range(pages):
        r = requests.get(KLINE_URL, headers=UA, timeout=25,
                         params={"param": f"{symbol},{freq},{start},{cursor},1300,"})
        r.raise_for_status()
        rows = (r.json().get("data") or {}).get(symbol, {}).get(freq) or []
        if not rows:
            break
        segs.append(rows)
        if rows[0][0] <= start:
            break
        cursor = (pd.Timestamp(rows[0][0]) - pd.Timedelta(days=1)).strftime("%Y-%m-%d")
    if not segs:
        raise RuntimeError(f"腾讯 fqkline 无数据：{symbol}/{freq}")
    return (pd.concat([to_frame(s) for s in segs], ignore_index=True)
            .drop_duplicates("date").sort_values("date").reset_index(drop=True))


def sina_factor(symbol, kind):
    """新浪复权因子（kind=qfq|hfq，日期升序）；响应尾部挂 base64 注释，必须 raw_decode。"""
    url = FACTOR_URL.format(symbol=symbol, kind=kind)
    r = requests.get(url, timeout=15,
                     headers={"User-Agent": "Mozilla/5.0", "Referer": "https://finance.sina.com.cn/"})
    r.raise_for_status()
    text = r.text
    data, _ = json.JSONDecoder().raw_decode(text[text.find("{"):])
    items = ({"date": it["d"], "factor": float(it["f"])} for it in data.get("data", []))
    return sorted(items, key=lambda x: x["date"])


def check_factors(hfq, qfq):
    """hfq 最早因子=1、qfq 最新因子=1、同日 hfq×qfq 恒定；任一不成立即降级 qfq 并披露。"""
    assert hfq and qfq, "复权因子为空"
    assert hfq[0]["factor"] == 1.0, "hfq 最早因子不为 1.0"
    assert qfq[-1]["factor"] == 1.0, "qfq 最新因子不为 1.0"
    qfq_map = {x["date"]: x["factor"] for x in qfq}
    products = {round(x["factor"] * qfq_map[x["date"]], 9) for x in hfq if x["date"] in qfq_map}
    assert len(products) == 1, f"hfq×qfq 不恒定：{products}"


def apply_adjust(df, factors, kind):
    """hfq 乘因子、qfq 除因子（方向传反不报错，只会把价格整体放大/缩小数倍）。"""
    out, idx, cur = [], 0, None
    for row in df.to_dict("records"):
        while idx < len(factors) and factors[idx]["date"] <= row["date"]:
            cur = factors[idx]["factor"]
            idx += 1
        if cur is None:
            raise ValueError(f"{row['date']} 无复权因子")
        for key in PRICE_KEYS:
            row[key] = round(row[key] * cur, 4) if kind == "hfq" else round(row[key] / cur, 4)
        out.append(row)
    return pd.DataFrame(out)


def factor_evidence(hfq, qfq, kind):
    """把因子链结论固化为 metadata 证据块，供 data_check 复验（不落因子全量）。"""
    qfq_map = {x["date"]: x["factor"] for x in qfq}
    products = {round(x["factor"] * qfq_map[x["date"]], 9)
                for x in hfq if x["date"] in qfq_map}
    payload = json.dumps({"hfq": hfq, "qfq": qfq}, ensure_ascii=False, sort_keys=True)
    return {"kind": kind, "factor_source": "sina",
            "hfq_first": hfq[0]["factor"], "qfq_last": qfq[-1]["factor"],
            "product_constant": len(products) == 1,
            "factor_sha256": hashlib.sha256(payload.encode("utf-8")).hexdigest()}


def write_csv(df, symbol, freq, fq, source, adjust=None):
    """落盘 %TEMP% + 同名 metadata；csv_sha256 缺失时 data_check 拒绝作为正式数据链。"""
    assert (df["high"] >= df[["open", "close", "low"]].max(axis=1)).all(), "high 非最高"
    assert (df["low"] <= df[["open", "close", "high"]].min(axis=1)).all(), "low 非最低"
    out_dir = os.path.join(tempfile.gettempdir(), "wavecycle")
    os.makedirs(out_dir, exist_ok=True)
    csv_path = os.path.join(out_dir, f"{symbol}_{freq}_{fq}.csv")
    df.to_csv(csv_path, index=False, lineterminator="\n")
    with open(csv_path, "rb") as fh:
        digest = hashlib.sha256(fh.read()).hexdigest()
    meta = {"source": source, "fq": fq, "as_of": f"{df['date'].iloc[-1]} 15:00",
            "timezone": "Asia/Shanghai", "csv_sha256": digest}
    if adjust is not None:
        meta["adjust"] = adjust
    with open(os.path.splitext(csv_path)[0] + ".metadata.json", "w", encoding="utf-8") as fh:
        json.dump(meta, fh, ensure_ascii=False, indent=2)
    return csv_path


def main(symbol="sh603259", freq="day", fq="qfq"):
    raw = fetch_raw(symbol, freq)
    if fq == "none":
        return write_csv(raw, symbol, freq, fq, "腾讯 fqkline", {"kind": "none"})
    hfq, qfq = sina_factor(symbol, "hfq"), sina_factor(symbol, "qfq")
    check_factors(hfq, qfq)
    evidence = factor_evidence(hfq, qfq, fq)
    adjusted = apply_adjust(raw, hfq if fq == "hfq" else qfq, fq)
    return write_csv(adjusted, symbol, freq, fq, "腾讯 fqkline + 新浪因子", evidence)
```

拿到返回的 CSV 路径后，依次跑 「data_check」（源文件）（带 `--fq` 与 `--require-metadata`）和 「preflight」（源文件）。复权口径只能取 `hfq`／`qfq`／`none` 三者之一，并在报告【1 分析前提】如实披露。

metadata 的 `adjust` 块是复权证据（kind、因子边界、hfq×qfq 乘积恒定、因子 SHA-256）。「data_check」（源文件） 对 `qfq` 允许"声明未验证"并披露；对 `hfq` 无 `adjust` 块或校验失败直接判不通过，禁止以声明代替验证。

### 3.1 宏观母浪归属的三项判决标准
1. **方向对齐律**：日线级别的推动浪必须顺应周线级别的主趋势方向。如果周线处于明确的下行趋势中，日线级别的任何向上五浪只能定位为大级别调整浪的子浪（例如反弹浪 A 或扩散平台浪 B 的内部子浪），绝不能直接标记为新超级牛市的启动大浪 `[1]`。
2. **完整推动后的组织律**：同一级别内一旦出现清晰的 5 浪推动完成结构，后续走势**必须作为一个整体调整形态**（如 ABC 或 WXY）进行自洽组织，严禁在未经历合规调整的情况下继续数出第 6 浪或第 7 浪。
3. **宏观分水岭锁定**：在日线分析前，必须在草案中白纸黑字写下宏观分水岭（例如：“周线级别多空分界点为 2024-02-05 低点 2635.09 点；跌破该点则全盘大级别推演彻底失效”）。

### 4.2 长影线多日未破处理原则（D27）
市场在剧烈博弈时经常出现极端长影线（例如日内急拉急跌后回落）。
1. **长影线判定标准**：上影线（或下影线）长度大于等于其实体长度的 **2.0 倍**。
2. **多日未破验证**：若在长影线出现后的 10 个交易日内，收盘价始终未能突破影线最高点（或跌破最低点），该影线尖端被正式认证为**强阻力/强支撑物理锚点**。
3. **数浪端点吸收**：波浪端点必须采纳长影线的极端最高/最低价（00 规则），严禁因影线过长而主观截断使用收盘价。
4. **禁止反向绑架**：长影线锚点必须原样记录在关键结构位清单中，但**绝对禁止仅仅因为存在一个未破阻力位，就在缺乏波浪形态证据的情况下擅自强行逆转数浪的主方向**。

### 4.3 趋势线与通道线辅助连线规范
在三类物理锚点基础上，分析人员应构建第四类几何辅助——**趋势线（Trendlines）**：
- **上升趋势线**：连接连续抬高的两个或多个波谷低点；
- **下降趋势线**：连接连续降低的两个或多个波峰高点；
- **通道辅助**：通过与趋势线平行的轨道线，构建初步的艾略特通道雏形（为 Step 02/03 的通道验证提供基准）。

## 一、物理端点提取与容差纪律（EG-05 极端价位门禁）

在艾略特波浪理论中，波浪几何形态是由价格波动的极值端点所决定的。任何偏离客观成交极值的画线都属于人为篡改市场事实。

### 1.1 极端价位原则（Extreme Price Rule）
1. **真实影线必须纳入口径**：所有波浪的起点与终点，**必须取自 K 线客观发生的真实最高价（High）或最低价（Low），必须包含所有上下影线与盘中瞬时极值**。
2. **严禁使用收盘价/开盘价偷换端点**：部分分析者为了强行凑出满足斐波那契比例或避免破位重叠，主观采用收盘价连线，这在 WaveCycle 体系中被定性为严重的学术违规与工程作弊行为。
3. **盘中即刻生效原则（D3）**：规则失效价位（如浪 4 绝不可进入浪 1 领地）只要在盘中被影线瞬时触及，该数浪方案即宣告**机械性规则失效（Rule Violation）**，概率立即归零，无须等待日线收盘确认。

### 1.2 自动化提取局部极值点：「swings」（源文件）
推演前，必须使用入库工具 「swings」（源文件） 从清洗后的 CSV 中提取客观摆动高低点：
```bash
python 06_技能_skill/scripts/swings.py --csv "<标准化CSV绝对路径>" --k 5
```
- **参数注意**：分形窗口是 `--k`（双连字符），不是 `-k`；写 `-k` 会被 argparse 判为 `unrecognized arguments` 直接退出。
- **输出格式**：`[Index, Date, Type(PEAK/TROUGH), Price]`。
- **物理约束**：提取出的极值点在时间轴上必须严格高低交替（PEAK 与 TROUGH 必须交替出现，绝不允许连续出现两个同向极值点）。

### 1.3 算法多尺度自适应容差机制（$k=5/3/1$ 窗口机制）
在实战量化中，单一固定的算法窗口往往无法完美捕捉所有级别的波动：
- **默认主干窗口（$k=5$）**：要求极值点在前后各 5 根 K 线内为最高/最低，用于提取大浪（Primary）与中浪（Intermediate）级别的骨干端点。
- **次级自适应窗口（$k=3$ 或 $k=1$）**：当遇到微观子浪较短、行情单边极速推进或局部震荡剧烈时，若次级子浪未命中 $k=5$ 极值点：
  1. **非阻断性原则**：此情况仅作为“待核对提示（Notice/Pending）”，**绝对不得将其上升为使数法无效的硬性规则违反（退出码 1）**！
  2. **局部高精度回溯**：允许分析算法自动下调窗口至 $k=3$ 或直接以局部物理真实极值（$k=1$）作为次级子浪端点。
  3. **事实锁定**：只要端点落在真实的局部最高/最低价上，且满足子浪时间递增连续与价格几何交替，即视为合法端点。

## 二、形态实战辨析指南（跨形态排雷五大对比矩阵）

在复杂市场中，很多形态在表面视觉上极其相似，实战数浪者极易落入假信号陷阱。必须运用以下五大跨形态排雷矩阵进行严格甄别。

```
+----------------------------------------------------------------------------------------------------+
|                                    跨形态排雷甄别决策矩阵                                           |
+----------------------------------------------------------------------------------------------------+
|  [ 场景 1: 行情初期多次推进与重叠 ]  --> 辨析: 标准推动 vs 前置斜纹 vs 嵌套 1-2                    |
|  [ 场景 2: 趋势末端剧烈震荡破位 ]    --> 辨析: 终结斜纹 vs 浪 5 延长 vs 调整浪 C                    |
|  [ 场景 3: 三段式急促推进看似五浪 ]  --> 辨析: 双锯齿 W-X-Y vs 推动浪 1-2-3-4-5 (假五浪陷阱)        |
|  [ 场景 4: 回调后价格创出反向新高 ]  --> 辨析: 扩散平台浪 B 突破 vs 新推动浪第 1 浪启动              |
|  [ 场景 5: 两条收敛趋势线包络价格 ]  --> 辨析: 收缩三角形 (调整浪) vs 倾斜斜纹浪 (驱动浪)           |
+----------------------------------------------------------------------------------------------------+
```

---

### 辨析 1：标准推动 vs 前置斜纹 vs 嵌套 1-2
- **实战场景**：在牛市初期或波段启动阶段，价格走出多次推进和回踩，甚至出现子浪低点与前一子浪高点轻微重叠。

| 甄别维度 | 标准推动浪（Impulse） | 前置斜纹浪（Leading Diagonal） | 嵌套推动浪（Nested 1-2s） |
| :--- | :--- | :--- | :--- |
| **浪 4 与浪 1 重叠性** | **严格禁止任何重叠**（R-IMP-10） | **几乎必然重叠**（R-DIA-09，含原著脚注例外） | 属于不同级别的浪 2 回撤，**无同级重叠** |
| **内部子浪几何构型** | 严格为 $5-3-5-3-5$ | 准则形态 $3-3-3-3-3$，有时呈 $5-3-5-3-5$（G-DIA-02） | 每一个内部推动都为严格的 $5-3-5-3-5$ |
| **出现的位置约束** | 驱动浪的主体，可出现在 1/3/5/A/C | **仅允许出现在大浪 1 或调整浪 A**（R-DIA-03） | 处于大级别浪 3 启动前的蓄势阶段 |
| **成交量配合特征** | 浪 3 显著爆发放量，远超浪 1 | 整体呈逐步收缩萎缩态势 | 浪 (1) 温和放量，次级浪 1 再次温和放量 |
| **实战排雷铁律** | **防重叠硬伤**：一旦重叠立即排除标准推动。 | **防位置滥用**：严禁在浪 3 或浪 5 位置数出前置斜纹！ | **严禁无休止嵌套**：禁止为了保持盲目看涨，无证据地连续数出“浪 1-2、浪 (1)-(2)、浪 ((1))-((2))”。嵌套数法必须拥有逐级清晰的次级微观推进证据。 |

---

### 辨析 2：终结斜纹 vs 浪 5 延长 vs 调整浪 C
- **实战场景**：在一轮长期牛市末端，走势震荡加剧，频繁出现破轨与高位放量回落。

| 甄别维度 | 终结斜纹浪（Ending Diagonal） | 浪 5 延长推动（Wave 5 Extension） | 调整浪 C 终结（Correction C） |
| :--- | :--- | :--- | :--- |
| **内部子浪几何构型** | **必须全为三浪（$3-3-3-3-3$）**（R-DIA-04） | 内部为清晰的五浪（$5-3-5-3-5$） | 锯齿形中为五浪（$5$），平台形中为五浪（$5$） |
| **形态几何边界** | 汇聚于楔形两收敛轨道内，常出现**翻越（Throw-over）** | 通常突破原平行通道上轨，呈现陡峭抛物线推进 | 遵循通道规则，常在平行通道下轨/上轨处受阻 |
| **动能与量价特征** | 动能指标出现严重多重顶背离，成交量递减 | 成交量异常暴增（天量见天价），换手率极高 | 动能通常在尾声萎缩或出现钝化 |
| **前序波浪完备性** | **前提必须已存在清晰的浪 1 至浪 4** | 浪 1 与浪 3 幅度适中，浪 4 充分横盘 | 属于大级别调整浪的一部分，前序必有 A 浪 |
| **实战排雷铁律** | **内部必须为三浪**：如果所谓“终结楔形”的第 5 浪内部走出了清晰的 5 浪推动，则**绝非终结斜纹**，必须立即修正为浪 5 延长！ | **防错把顶背离当衰竭**：强庄股或大牛市末端常出现大五浪延长，严禁过早以楔形为由摸顶。 | **防主客倒置**：必须核实前面是否经历了完整的 5 浪推动；若前序仅为单边下跌，此处只能是反弹 C 浪。 |

---

### 辨析 3：双锯齿 W-X-Y vs 推动浪 1-2-3-4-5（假五浪陷阱）
- **实战场景**：行情走出一段非常陡峭的三段式急促推进，视觉上包含 5 个明显的拐点，很多初学者将其误判为推动浪。

```
【推动浪 1-2-3-4-5 构型】           【双锯齿 W-X-Y 构型 (假五浪陷阱)】
       (5)                                    (Y) = 5-3-5
       /\                                     /\
  (3) /  \                               (W) /  \
  /\ /    \ (4)                          /\ /    \
 /  V      \                            /  V      \
/ (2)       \                          /  (X)=3    \
(1)                                   (A-B-C)
内部: 5 - 3 - 5 - 3 - 5                内部: (5-3-5) - (3) - (5-3-5)
```

| 甄别维度 | 推动浪 1-2-3-4-5 | 双锯齿调整浪 W-X-Y |
| :--- | :--- | :--- |
| **内部子浪细分结构** | 包含 3 个驱动浪与 2 个调整浪（$5-3-5-3-5$） | 包含 2 个五浪驱动与 3 个三浪调整（$(5-3-5)-3-(5-3-5)$） |
| **通道拟合特征** | 浪 3 通常会**极度陡峭地向上突破** $1-2$ 通道线 | 整体走势会**极其完美地契合在一条平行的直线通道**内 |
| **中继连接浪性质** | 浪 2 与浪 4 必须展现**交替原则（Alternation）**（形态、深度交替） | 反向浪 X 必须为三浪结构，通常回撤较浅，表现为简单中继 |
| **宏观趋势指向** | 顺应更高一级主趋势方向，开启全新推进周期 | 逆着更高一级主趋势方向运行，本质属于深幅修正 |
| **实战排雷铁律** | **防三段凑五段**：必须切入日内或次级周期检查：所谓“浪 1”内部是否由 5 浪构成？如果第 1 段内部仅为 3 浪反弹，则全盘否定推动浪，必须归类为双锯齿 W 浪！ |

### 辨析 4：平台浪 B 突破前高 vs 新推动浪第 1 浪启动
- **实战场景**：标的经历一轮下跌后强力反弹，价格不仅收复失地，而且突破了前期波段高点，引发市场全线多头追高。

| 甄别维度 | 扩散平台浪 B（Expanded Flat Wave B） | 新一轮推动浪浪 1（New Impulse Wave 1） |
| :--- | :--- | :--- |
| **反弹内部微观结构** | **严格为 3 浪结构（$a-b-c$）**（R-FLAT-02） | **严格为 5 浪结构（$1-2-3-4-5$）**（R-IMP-02） |
| **突破前高的性质** | **多头陷阱（Bull Trap）**：虚假突破，通常突破前高幅度在 $1.05 \sim 1.382$ 斐波那契区间后戛然而止 | **真实突破**：伴随成交量持续放大，突破后形成支撑回踩 |
| **后续 C 浪破坏力** | 随后将迎来极其凶猛的 **5 浪暴跌（C 浪）**，甚至跌破 A 浪低点 | 随后仅走出浅幅的 3 浪回踩（浪 2），且绝不跌破启动点 |
| **实战排雷铁律** | **反弹不过三，冲高即防空**：任何突破前高但内部子浪仅呈现清晰三浪结构的走势，**一律优先判定为扩散平台浪 B 诱多**！严禁将其认定为新牛市确立。必须将失效位设于突破点下方，警惕断头台式 C 浪杀跌。 |

---

### 辨析 5：收缩三角形 vs 倾斜斜纹浪
- **实战场景**：价格在两条相互收敛的趋势线之间窄幅震荡，高点不断降低，低点不断抬高。

| 甄别维度 | 收缩三角形（Contracting Triangle） | 倾斜斜纹浪（Diagonal） |
| :--- | :--- | :--- |
| **形态本质与大类** | **纯调整浪（Corrective Wave）**（无净趋势前进） | **纯驱动浪（Motive Wave）**（带动市场净前进） |
| **内部子浪组成** | **严格为 $3-3-3-3-3$（全为 3 浪）**（R-CT-02） | 前置斜纹可为 $5-3-5-3-5$；终结斜纹为 $3-3-3-3-3$ |
| **出现的位置约束** | **仅出现在主趋势最后一浪之前**（如浪 4、浪 B） | **仅出现在趋势的起点或终点**（浪 1/5 或浪 A/C） |
| **形态突破方向** | 调整结束后，将**顺应前序主趋势方向**发生推刺突破 | 形态完成后，市场将发生**剧烈的反向趋势反转** |
| **实战排雷铁律** | **防位置与功能混淆**：三角形是行情的休止与蓄势，斜纹浪是行情的衰竭或启动。绝不能在波段半山腰将斜纹浪当作三角形数，也不能在趋势转折点将三角形当作推动浪终结！ |

## 三、数浪实战 6 大通病与避坑指南（防呆指南）

大量技术分析者在实战中屡屡受挫，并非理论本身存在缺陷，而是陷入了主观推演的致命思维惯性。以下梳理全系统严禁触犯的 **6 大通病**：

```
+----------------------------------------------------------------------------------------------------+
|                                    数浪实战 6 大通病防呆排查表                                      |
+----------------------------------------------------------------------------------------------------+
|  [ 通病 1: 看三段就认调整 ]  --> 症状: 见到三条折线就草率标记为 ABC, 漏查内部到底由几浪驱动。       |
|  [ 通病 2: 斐波目标当终点 ]  --> 症状: 价格刚到 0.618 就臆断波浪结束, 忽视微观反转形态是否成立。   |
|  [ 通病 3: 局部完成作父级 ]  --> 症状: 将第一个锯齿 W 的结束当成整个大调整的结束, 遭遇 X 浪诱多。 |
|  [ 通病 4: 单一方案搞偷懒 ]  --> 症状: 只输出一套主观最偏好的方案, 缺乏替代防御方案 (触犯 EG-03)。   |
|  [ 通病 5: 级别错配跨级标 ]  --> 症状: 把小级别微浪与大级别母浪并列标注, 破坏层级分形逻辑。       |
|  [ 通病 6: 滥用罕见形态开脱] --> 症状: 数错浪后为了圆谎, 随意套用顺势平台、扩散三角等极小概率形态。|
+----------------------------------------------------------------------------------------------------+
```

### 3.1 避坑 1：看三段就认调整（盲目认 ABC）
- **致命陷阱**：在图表上看到“下跌-反弹-再下跌”的三段折线，就想当然地打上 $A-B-C$ 标签。
- **真相与排查**：调整浪既可能是单锯齿（$5-3-5$），也可能是平台形（$3-3-5$），甚至是双重锯齿（$W-X-Y$）。如果第一段下跌内部包含 5 个清晰子浪，而第三段下跌也是 5 个子浪，才是锯齿形；如果第一段只有 3 浪，它绝不可能是常规锯齿形的 A 浪！必须拆解内部子浪成分，严禁仅凭宏观三段直接判定。

### 3.2 避坑 2：把斐波那契目标当终点（静态思维）
- **致命陷阱**：计算出浪 3 的 $1.618$ 扩展位在 3200 点，当价格触及 3200 点时，立即断言“浪 3 已经结束，准备反手做空做浪 4”。
- **真相与排查**：**斐波那契只是数学投影窗口，不是物理刹车片**！在强烈的单边延长行情中，浪 3 完全可以奔向 $2.618$ 甚至 $4.236$ 倍。波浪是否终结，**必须等待其内部 5 浪结构完整封口，且出现道氏破位或蜡烛图反转信号确认**，绝不能单凭价格到站就主观摸顶抄底。

### 3.3 避坑 3：局部完成等同于父级完成（忽视复合形态）
- **致命陷阱**：标的经历暴跌后走出清晰的 $A-B-C$ 三浪反弹，分析者兴奋宣布“大调整彻底完成，反转启动”。随后市场仅反弹一段便再度破位暴跌。
- **真相与排查**：这往往只是双重调整浪中的第一个浪 $W$！后续连接的只是浪 $X$，等待投资者的还有更加残暴的浪 $Y$。在复杂大周期调整中，**必须始终保留“复杂联合形调整（$W-X-Y$）”作为核心替代方案**，在行情未实质突破大级别分水岭之前，绝不能将局部子形态的完成等同于大级别调整的终结。

### 3.4 避坑 4：单方案偷懒与执念（违背 EG-03）
- **致命陷阱**：分析者根据持仓偏好，只给出一套极其看多的数浪方案，拒不考虑看空或深度回调的可能性。
- **真相与排查**：市场永远存在测不准边界。当主方案破位时，单方案分析者会陷入巨大的认知失调，甚至不断篡改规则以维持原判断。**流水线强制要求（EG-03）必须同时推演主方案与替代方案**，并为替代方案设立独立的触发开关，做到“涨跌皆有推演，破位从容应对”。

### 3.5 避坑 5：级别错配与跨层级混标（层级混乱）
- **致命陷阱**：在报告中写出：“当前处于 Intermediate (3) 的第 4 浪回调，且该回调与 Intermediate (1) 发生重叠”。
- **真相与排查**：把次级子浪 4 拿去与高级母浪 (1) 比较重叠性，属于典型的级别错配。重叠规则只发生在同级别波浪之间（如 Minor 4 不能重叠 Minor 1）。必须严格对照普莱切特 9 级符号系统，子浪归子浪，母浪归母浪，严禁跨层级混乱对比。

### 3.6 避坑 6：随意采用罕见形态为错误数法开脱（滥用稀有形态）
- **致命陷阱**：数浪出现致命矛盾（如浪 4 深度回撤严重破位）后，为了不推翻原有预判，强称走出了“罕见的顺势平台（Running Flat）”或“极其罕见的扩散三角形（Expanding Triangle）”。
- **真相与排查**：原著对这些形态的定性全部是"罕见/尚未见过"，**从未给出任何百分比或样本量**（如「价格记录中几乎没有顺势平台的例子」「三重三浪极其罕见」「尚未见过九浪结构的屏障三角形」）。因此不得以"低于 X%"之类的伪统计作判据。**“夏洛克·福尔摩斯原则”要求**：当常规数法走不通时，首先应当怀疑的是当前波浪划分是否存在根本性错误，而不是立刻抓一根罕见形态的救命稻草。**采用任何罕见形态必须具备逐条排他的充分证据**（写出被排除的每一种常规数法及其不成立的理由），否则直接判定数浪推演无效。

### 4.1 步骤 1：固定关键物理摆动极值点序列
- 从 `01_准备卡` 中读取清洗后的历史极值点序列；
- 将历史区间划分为两大部分：**历史已完全走完的基准段**（用实线固定）与**当前正在展开的活跃震荡段**。

### 4.2 步骤 2：枚举所有满足 06 纯理论规则的合法组合
- 针对当前走势的推进性质，列出所有理论可能：
  - 可能性 A：5 浪推动推进（$1-2-3-4-5$）；
  - 可能性 B：三浪锯齿修正反弹（$A-B-C$）；
  - 可能性 C：平台形横盘蓄势（$A-B-C$）；
  - 可能性 D：双重锯齿复合推进（$W-X-Y$）。
- 运行 「rule_check」（源文件） 对每一种可能进行二元排他性过滤，直接剔除硬性违规方案。

### 4.3 步骤 3：构建主方案与替代方案
- **主方案（Preferred Count）**：选取几何形态最自然、与道氏趋势最共振、符合交替原则与斐波那契回撤比例最高的方案。打分一律按 `03_03` §4.1（Guideline×2 + 七因子 0/1/2）由 「score」（源文件） 计算，**不输出百分比概率**。
- **替代方案（Alternate Count）**：必须至少构建 1 个在方向或形态分类上与主方案互补的备选数法，并独立打分（同样走 「score」（源文件））。
  - *经典组合模式*：主方案认为当前是浪 3 主升推进，替代方案则推演当前仅为 B 浪反弹，随后仍有 C 浪回踩。

### 4.4 步骤 4：细分深度展开与事实登记
- 按「门禁 A」取得的交付深度执行（3 层或日线 4 层），严格贯彻 EG-04 与 D41 纪律：凡跨度 $\ge 15$ 根日 K 线的波段必须展开至下一层级别；
- 交付 4 层时，展开范围按 `fourth_layer_roots` 限定（全分析树或指定第三层父浪），范围外仍按三层检查，「analysis_scope」（源文件） 会拒绝超出第三层的分支路径；
- 运行 「wave_facts」（源文件） 脚本，将确立的各级波浪端点注册为系统事实，供后续绘图与报告模块无损读取。

### 4.5 步骤 5：方案独立标注结构前提与失效价位
- **主方案失效价位（$P_{\text{inv, main}}$）**：基于主方案形态硬规则推导（例如：若主方案为浪 3 主升，则浪 2 起点价格 $P_{\text{start}}$ 即为铁血失效位；若被击穿，主方案立刻死亡）。
- **替代方案失效价位（$P_{\text{inv, alt}}$）**：基于备用方案的临界触发点推导（例如：若突破前期阻力位 $P_{\text{res}}$，则替代方案的反弹 B 浪假设被打破，替代方案失效，反向印证主方案的正确性）。

### 4.6 强制交互门禁 B：分钟分形层确认（Minute Layer Gate）

本条是**物理阻断门禁**。门禁 A 定的是日线深度；本条定的是**是否额外下钻分钟线**，两者互不替代。

1. **触发时机**：交付深度的**最后一层**细分完成并锁定当前活跃浪起点 `T_d0`（含 H/L 属性）之后 —— 交付 3 层即第 3 层之后，交付日线 4 层即第 4 层之后。**早问（如 4 层模式在第 3 层后问）与晚问（报告写完才问）都算违规。**
2. **必须动作**：调用宿主交互工具（ZCode 为 `AskUserQuestion`，其他宿主用其对应确认机制）询问一次：“是否启用分钟分形层（60m/30m/15m）做第 4 层共振验证？”**收到明确答复前不得进入 Step 03 验证、不得生成报告。**
3. **登记**：答复写入报告【分析前提】的“分钟分形层”行，取值只允许 `已询问-启用`／`已询问-不启用`／`未询问-环境无交互`；「report_common」（源文件） 强制校验该行，缺失或非法值直接拒绝出报告。
4. **降级（唯一例外）**：交互工具调用失败，或宿主确无交互能力且**已实际尝试调用**，登记 `未询问-环境无交互`，并在同一行披露原因。**严禁以“判断当前为非交互环境”代替实际调用**——这是本门禁要堵的漏洞。
5. **复用**：同一标的同一轮分析不重复询问；「05_失效追踪与方案动态更新」（源文件） 的更新轮默认沿用上次答复，用户显式更改才变更。
6. **启用后**：按 「01_数据获取与市场分析准备」（源文件） §1.4「分钟分形层切片协议」执行三轮交互，并按 「04_生成报告与图表交付规范」（源文件） §2.2 成组出 60m/30m/15m 分钟图（只允许全组或全不出）；「embed_report_images」（源文件） 会核对“询问记录 ↔ 分钟图组”是否一致，启用却缺图、未启用却有图都会拒绝交付。

| **平台形（Flat）** | R-FLAT-01 ~ R-FLAT-04 | 1. 子浪数 $\neq 3$ 或内部非 3-3-5（R-FLAT-01）；<br>2. 浪 A/浪 B 非调整模式，或浪 C 非驱动模式（R-FLAT-02）；<br>3. 浪 A 为三角形（R-FLAT-03）；<br>4. 浪 B 回撤不足浪 A 的 90%（R-FLAT-04）。 |

| **扩散三角形（Expanding Triangle）** | R-ET-01 ~ R-ET-03 | 1. 子浪数 $\neq 5$（R-ET-01）；<br>2. 浪 C 未越浪 A 终点、浪 D 未越浪 B 终点或浪 E 未越浪 C 终点（R-ET-02）；<br>3. 浪 B/C/D 的回撤不在 $[100\%, 150\%]$ 区间（R-ET-03）。 |
| **联合形（Combination）** | R-COMB-01 ~ R-COMB-06 | 1. 缺少反向连接浪 X 或 X 方向错误（R-COMB-01）；<br>2. 锯齿形联合中混入平台形或三角形（R-COMB-02）；<br>3. 模式组合不在原著列举序列内（R-COMB-03）；<br>4. 分量包含扩散平台形（R-COMB-04）；<br>5. 水平三角形出现在 W 浪或任一 X 浪（R-COMB-05）；<br>6. 三重三浪中三角形数量 $>1$（R-COMB-06）。 |

### 1.2 第二轨：系统工程交付合规性门禁（系统工程审查）

由分析师或子代理提交的方案必须符合系统工程纪律，杜绝偷懒、退化与交付缺陷。

- **1. 级别声明完整性（EG-01）**：必须显式声明主分析级别（Primary Degree），严禁脱离时间尺度与波浪级别的无锚点数浪。
- **2. 标注符号规范性（EG-02）**：同一张图表内严格区分驱动浪符号（1-2-3-4-5）与调整浪符号（A-B-C / W-X-Y / A-B-C-D-E），严禁同图混用两套符号体系。
- **3. 主备双方案完备性（EG-03）**：常规分析必须同时提供主方案（Primary Count）与至少一个合法的替代方案（Alternate Count），各自拥有独立的逻辑假设与失效边界。
  - **单方案豁免的举证门槛（强制）**：仅当同时满足以下三项才允许保留单方案——① 在报告中列出**被枚举过的全部备选假设**（不少于 2 个）；② 逐一注明每个备选**被 06 哪一条编号的硬公理证伪**（须可复算，如"备选 B 违反 R-FLAT-04：浪 B 回撤 78% < 90%"）；③ 单独章节披露防御观望档位与待确认信号。仅写"行情极端、无法构建替代方案"不构成豁免理由，按 EG-03 判 Fail。
- **4. 细分深度穿透性（EG-04）**：交付深度只指日线树深度——历史波浪框架必须向下穿透至第 3 层细分（例如 `(1)` → `1-2-3-4-5` → `①-②-③-④-⑤`）；经门禁 A 确认的**日线 4 层**须穿透至第 4 层并按 `fourth_layer_roots` 限定范围。**分钟分形层是附加验证层，不参与深度编号**，启用与否由门禁 B 决定，启用时另按 60m/30m/15m 三级切片审查四级共振证据。严禁以单根折线替代复杂多月/多年长走势的退化偷懒标注。**判 Fail 的量化阈值**：已走完的父浪时间跨度 $\ge 15$ 根当前周期 K 线（日线即 ≥15 根日 K）而内部未展开任何子浪者，直接判 Fail，不得以"走势光滑""分辨率不足"作为理由——除非同时给出该区间可得的最细周期数据源与仍不可分的证据。
- **7. 交互门禁留痕（EG-07）**：报告【分析前提】须有唯一“分钟分形层”行（`已询问-启用`／`已询问-不启用`／`未询问-环境无交互`），且与实际分钟图组一致；`细分深度来源` 须与门禁 A 答复一致。缺记录、值非法或记录与图组矛盾，一律判 Fail（详见 「04_校验清单_checklists/00_校验总纲与双轨门禁规程_framework」（源文件） EG-07）。
- **5. 极端价位严谨性（EG-05）**：所有结构端点、回撤计算与失效边界，必须采用 K 线的实际极端价位（含最高/最低影线），绝不能仅以收盘价代替。
- **6. 未完成段虚线暂定原则（EG-06）**：已确认结束的历史浪段使用实线，正在进行中或预测的外推走势必须使用虚线标注暂定端点，严禁将未发生的未来走势画为确凿实线。

## 二、跨流派多维度交叉验证流程

在波浪结构通过双轨绝对门禁后，引入道氏理论、江恩理论、蜡烛图信号与事后行为进行四维立体交叉印证。各流派验证旨在为方案提供佐证置信度，属于准则（Guidelines）级别证据，**只赋予权重与分值，永不凌驾于波浪硬规则之上**。

```
                                  ┌── 1. 道氏理论（Dow Theory）: 大级别趋势与牛熊阶段互证
                                  ├── 2. 江恩理论（Gann Theory）: 1×1 角度线分水岭与时间窗共振
波浪方案（通过双轨门禁）── 交叉印证 ──┼── 3. 蜡烛图（Candlestick）: 浪顶/浪底经典反转与缺口配合
                                  └── 4. 事后验证（Neely Post-Constructive）: 穿线时间与回撤深度
```

### 2.1 道氏理论（Dow Theory）趋势与阶段验证

道氏理论是技术分析的宏观基石，负责确立背景趋势的合法性与牛熊演进阶段：
1. **主要趋势（Primary Trend）方向对齐**：核验数浪方案所定义的推进方向是否与道氏理论的主要趋势一致（波峰与波谷逐级抬高定义为牛市；波峰与波谷逐级降低定义为熊市）。若主升浪方案逆道氏主要趋势展开，该方案必须受到严格的降权审查。
2. **次级折返（Secondary Reaction）位置核验**：道氏次级折返通常回撤主要趋势幅度的 33%～66%（最常见为 50%），用以检验大级别浪 2 或浪 4 的回撤幅度是否符合宏观市场沉淀规律。
3. **高低点突破确认（DO5 反转机制）**：多头趋势的反转确认必须依赖“升破前一轮次级折返的高点”；空头反转必须依赖“跌破前一轮次级反弹的低点”。未出现 DO5 确认的波浪终结信号，不可过早给出 100% 趋势确立结论。
4. **相互验证原则（Mutual Confirmation）**：参考基准指数（如上证指数与深证成指）必须形成同向突破；若出现互证背离（指数分化），则表明当前波浪推进动能存在虚假成分，相应方案降权。

### 2.2 江恩理论（Gann Theory）几何角度线与时间窗验证

江恩理论通过几何比例与时间周期为波浪提供空间与时间的共振核验：
1. **1×1 几何角度线（True 45° Line）多空分水岭**：
   - 价格运行于从浪 1 起点或大级别重要底部引出的 1×1 角度线上方，印证强势多头推动格局；
   - 价格跌破 1×1 角度线，预示上升动能转弱，提示第 5 浪终结或大级别深幅调整来临；
   - 价格在 2×1、3×1 或 1×2 角度线获得精确几何支撑/阻力，强化波浪子浪端点的成立概率。
2. **江恩时间对称与斐波那契时间窗共振（预登记制度）**：
   - 严禁事后看图挑窗！所有江恩时间窗口必须在分析时基于基准历史转折点预先登记计算；
   - 当江恩方块周期（如 90、180、360 天/度数）与波浪斐波那契时间序列（21、34、55、89 周期）发生交叠重合时，形成**“时空共振窗口”**；
   - 处于时空共振窗口内的浪顶（浪 5、浪 C）或浪底（浪 2、浪 A）终结假设，获得高置信度加分。

### 2.3 蜡烛图（Candlestick）反转与持续信号确认

蜡烛图形态提供微观交易量价心理的即时佐证：
1. **浪顶与浪底反转形态配合**：
   - **波浪底部确认（浪 2、浪 4、浪 A、浪 C 终点）**：出现启明星（Morning Star）、看涨吞没（Bullish Engulfing）、刺透形态（Piercing Pattern）、锤子线（Hammer）或长下影探底回升，显著增加数浪低点确立概率；
   - **波浪顶部确认（浪 3、浪 5、浪 B 终点）**：出现黄昏星（Evening Star）、看跌吞没（Bearish Engulfing）、乌云盖顶（Dark Cloud Cover）、流星线（Shooting Star）或上吊线（Hanging Man），印证上升推动浪的动能耗竭。
2. **缺口理论配合（Gap Analysis）**：
   - **突破缺口（Breakaway Gap）**：落在浪 1 或大级别浪 3 启动点，确认新推动结构展开；
   - **持续/测量缺口（Runaway / Measuring Gap）**：落在浪 3 主升段中部，佐证延伸浪的强劲动力并可辅助测算目标位；
   - **竭尽缺口（Exhaustion Gap）**：落在第 5 浪末端并伴随快速回补，强力佐证终结形态。

### 2.4 事后行为验证（Neely Post-Constructive Verification）

依据 Glenn Neely 经典事后行为检验法，对已声明完成的波浪进行行为反推（作为置信度参考，不产生硬失效价位）：
- **Stage 1（时间速度穿线）**：推动浪结束后，后续走势必须在小于等于第 5 浪形成所耗费的时间内，反向彻底穿越 2-4 趋势线；超时未穿预示数法存在瑕疵或第 4 浪并未走完。
- **Stage 2（回撤深度分级）**：
  - 若浪 1 延长：后续调整通常回撤至浪 2 价格区域；
  - 若浪 3 延长：后续调整通常回撤至浪 4 价格区域；
  - 若浪 5 延长：后续调整通常至少快速回撤浪 5 全幅度的 61.8% 以上。

> **执行入口**：Stage 1/2 的数值判定统一调用 `scripts/post_constructive_check.py`；单浪归口（Neely Pre-Constructive）调用 `scripts/monowave_judge.py`。两者只给数值事实，形态、级别与完成状态仍由模型裁决。

## 三、跨流派冲突裁决引擎（Conflict Adjudication Engine）

当波浪结构、经典几何线条、道氏趋势、江恩时间窗与传统指标（MACD/RSI/均线）出现相互矛盾时，必须启动标准化仲裁程序，依据严格的宪法级顺位进行裁决。

### 3.1 仲裁最高宪法原则

技术分析诸流派的置信度与裁判权严格遵从以下优先级顺位：

$$\mathbf{波浪形态结构公理} \succ \mathbf{经典几何连线} \succ \mathbf{道氏趋势信号} \succ \mathbf{江恩时空线} \succ \mathbf{传统技术指标（MACD/RSI/均线）}$$

```
【最高裁判权】 波浪理论硬公理（Rules）：拥有绝对否决权，几何拓扑不合法直接判死
      │
      ▼
【几何约束层】 经典通道连线与趋势线（0-2线、2-4线、A-C/B-D线）：物理边界与翻越判定
      │
      ▼
【趋势大局层】 道氏理论主要趋势与阶段：宏观方向校准，提供先验概率
      │
      ▼
【时空测度层】 江恩角度线与时间共振窗口：辅助定位时空驻点，不改变形态合法性
      │
      ▼
【滞后参考层】 传统技术指标与均线系统：动量与平滑指标，仅作背离提示，永不覆盖结构
```

### 3.2 冲突类型与仲裁矩阵

| 冲突类型 | 典型场景 | 唯一法定裁决准则 |
| :--- | :--- | :--- |
| **Rule vs Rule 表面冲突** | 普通推动 R-IMP-10（重叠禁止）vs 斜纹浪 R-DIA-09（重叠为身份特征） | **先查例外前提条件**：核验直接父级位置（必须是浪 1/A 或浪 5/C）、子浪内部结构（R-DIA-04/05）与边界收敛性（R-DIA-11/12）。条件全部满足时适用斜纹浪合法例外；任一条件缺漏，坚决按 R-IMP-10 裁决为非法重叠。 |
| **Rule vs Guideline 冲突** | 06 R-IMP-09（浪 3 非最短，硬否决）vs 07 G-IMP-06（浪 1 最不常延长，仅概率） | **硬规则绝不妥协**：Guideline 仅描述概率偏离，绝对不得用来豁免硬规则的违规。概率上的"罕见"不能把几何上的"不可能"变成合法。 |
| **Guideline vs Guideline 冲突** | G-IMP-01 交替原则偏向方案 A vs G-IMP-04 比率典型偏向方案 B | **进入八因子量化加权**：准则间冲突不影响方案合法性，通过八因子量化评分卡综合计算总分，高分者为主方案，低分者为替代方案。 |
| **波浪结构 vs 道氏趋势** | 波浪数出浪 5/C 浪顶底反转，但道氏理论尚未出现 DO5 突破确认 | **降概率兼保留张力**：主方案保留波浪转向假设，但在报告中必须明确披露“形态筑顶/筑底 vs 道氏趋势未翻转”的结构张力；严禁因道氏未确认而直接废弃合法的波浪数法。 |
| **波浪结构 vs 江恩价位** | 江恩 1×1 线或 1/8 分割位显示强支撑，但波浪结构已有效击穿失效价位 | **失效价位绝对统治**：失效价位是全场最高权威！绝对禁止以“江恩在此处有角度线支撑”为借口，强行保留已被硬规则击穿的数浪方案。 |
| **江恩时间 vs 斐波那契时间** | 江恩周期日与波浪斐波那契时间窗指向不同日期 | **双窗口披露，交叠方计分**：在报告中如实列出两个时间窗口；仅当两体系窗口发生时间交叠（共振）时，方可计入“时间共振”满分，禁止事后择一报喜。 |

### 3.3 三大经典冲突场景专项裁决

#### 场景 1：指标顶背离 vs 波浪第 3 浪主升（MACD/RSI Divergence vs Wave 3 Impulse）
- **现象冲突**：市场处于波浪第 3 浪的主升或延伸阶段，但 15m/60m 乃至日线 MACD/RSI 出现持续的多重顶背离钝化。
- **裁决法门**：**波浪结构绝对优先！**
  - 在强劲的第 3 浪推动延伸中，动量指标常常出现“背离再背离”的指标钝化假象；
  - 严禁因指标背离而提前宣布波浪推动终结或在主升浪中逆势猜顶；
  - 传统指标的顶背离仅可作为子浪内部短线动能波动的参考，只要价格未跌破浪 1 顶（R-IMP-10）且浪 3 未完，必须坚决持有多头数浪立场。

#### 场景 2：均线多头排列 vs 终结斜纹浪 / 大 B 浪见顶（MA Golden Cross vs Ending Diagonal / Wave B Top）
- **现象冲突**：各周期移动平均线（MA5/10/20/60）呈现完美的多头排列与加速金叉，但波浪图表清晰走出 3-3-3-3-3 收敛的终结斜纹浪浪 5，或平台形奔走/扩张 B 浪的高位终结端点。
- **裁决法门**：**形态结构优先！**
  - 均线本质上是价格历史数据的加权平滑滞后指标；
  - 终结斜纹浪与大 B 浪诱多冲顶正是利用均线滞后性吸引跟风盘的经典主力行为；
  - 一旦波浪终结形态结构完整且触及预期反转区，必须立即启动最高级别防御机制，提示随时面临断崖式转折，不得被均线多头排列麻痹。

#### 场景 3：蜡烛图反转信号 vs 推动浪延伸推进（Reversal Candle vs Extended Impulse）
- **现象冲突**：在上行推进走势中，日 K 线收出标准的黄昏之星、看跌吞没或巨量长上影流星线，但波浪层级计算显示当前仅处于大浪 3 内部子浪 3 的第 1 或第 3 微浪。
- **裁决法门**：**同级主浪结构优先！**
  - 局部单个或组合 K 线的反转，不能对抗同级别主推动浪未完成的结构事实；
  - 裁决将该蜡烛图信号定性为“次级折返/内部子浪回调”的微观启动信号（例如子浪 3-2 或子浪 3-4），而非大级别推动浪见顶；
  - 严禁将微观 K 线信号作为颠覆宏观数浪方案的依据。

### 3.4 形态边界裁决固定顺序（五步法）

当走势在形态归属上出现分歧（如：单锯齿 vs 双锯齿、平台形 vs 三角形、终结斜纹 vs 推动失败）时，必须按以下固定五步顺序裁决：
1. **第一步：结构证据优先（Internal Structure）**：先按内部子浪计数裁决身份。锯齿形必须为 5-3-5，平台形必须为 3-3-5，三角形必须为 3-3-3-3-3。子浪内部驱动与调整属性是最高裁决证据。
2. **第二步：位置约束次之（Positional Eligibility）**：三角形绝不能作为推动浪独立的第 2 浪（R-IMP-05 要求浪 2 为锯齿/平台/联合；G-CT-06）；斜纹浪绝不能作为推动浪独立的第 3 浪（R-DIA-03 + R-IMP-03）。
3. **第三步：身份与方向自洽（Identity & Alternation）**：逆势修正浪（B、X、W、Y、Z）绝不能标记为推动浪；同级浪 2 与浪 4 必须展现形态或深度交替。
4. **第四步：八因子量化计分（Factor Scoring）**：若前三步审查后仍存在多种合法解释，带入八因子评分卡计算综合得分。
5. **第五步：多重数浪并列输出（Multi-Count Presentation）**：若两方案得分极度接近且逻辑皆完备，严禁主观硬猜单一方案，必须并列输出主方案与替代方案，各自划定独立失效红线，由市场后续数据仲裁。

## 四、八因子量化打分与概率排序体系

在所有合法方案中，杜绝凭直觉判断概率，必须依托基于 「01_知识库_knowledge/07_波浪准则_guidelines」（源文件） 建立的八因子评分卡，进行客观、量化的赋分计算。

### 4.1 八因子评分卡（唯一权威口径：defaults.md D12/D25 + scripts/score.py）

> **口径作废声明**：原「25% / 15% / 15% / 10% / 10% / 10% / 8% / 7% 百分制、因子含『交替原则典型度』与『通道平行线吻合度』」的评分卡**已整体作废**。八因子的因子集合、分制、权重与排序规则以 `references/defaults.md` D12/D25 与 `scripts/score.py` 为唯一真源。如确需改用百分制，必须先改代码并重发 defaults.md，禁止由文档单方面先行。

**因子集合与权重（2:1:1:1:1:1:1:1）**

| 序号 | 因子 | 权重 | 分制 |
| :---: | :--- | :---: | :--- |
| 1 | Guideline 得分 | ×2 | 原始累计整数（命中 +1 / 不适用 0 / 违反 −1），允许为负 |
| 2 | 结构完整度 | ×1 | 0 / 1 / 2 |
| 3 | 斐波那契共振 | ×1 | 0 / 1 / 2 |
| 4 | 道氏一致性 | ×1 | 0 / 1 / 2，或 NA（标的为大盘指数本身时剔除分母） |
| 5 | 江恩价格共振 | ×1 | 0 / 1 / 2 |
| 6 | 江恩时间共振 | ×1 | 0 / 1 / 2 |
| 7 | 蜡烛图信号 | ×1 | 0 / 1 / 2 |
| 8 | 失效距离 | ×1 | 0 / 1 / 2（D10：≥1.618×=2；0.618–1.618×=1；<0.618×=0） |

$$\text{Total Score} = 2 \times S_{\text{Guideline}} + \sum_{k=2}^{8} S_k \quad (S_k \in \{0,1,2\})$$

- **禁止百分制换算**：Guideline 命中数无上界，总分不设"满分"，因此本体系**不输出 0~100 分**，也不存在 ≥70 / ≥50 的绝对准入门槛（原著与代码均无此设定）。
- **禁止 0.5 分档**：「score」（源文件） 对非整数直接报错退出；文档、模板、案例一律使用 0 / 1 / 2。
- **各因子赋分口径**（与 「score」（源文件） docstring 逐字对齐）：结构完整度 2=细分清晰且级别嵌套自洽、1=基本清晰、0=部分待确认；斐波那契共振 2=关键比率命中 ≥2 个、1=1 个、0=0 个；道氏一致性 2=一致且互证成立、1=一致但互证背离、0=与道氏状态矛盾；江恩价格共振 2=落入江恩-斐波那契共振区、1=单体系命中、0=无；江恩时间共振 2=预登记时间窗与斐波那契时间带重叠、1=仅一体系、0=无；蜡烛图信号 2=方向一致的明确转折/确认、1=弱信号、0=无或矛盾；失效距离见 D10。

### 4.2 功率评级（Power Ratings）与势能评估

依据 Glenn Neely《Mastering Elliott Wave》第 10 章，对调整形态完成后的后续势能进行方向性评估。**功率评级作为方案结构势能与盈亏比评估的重要参考，不直接粗暴覆盖八因子总分，但在交易计划中指导仓位上限**：

1. **正负号严格表达方向性强弱**：
   - 向上完成取正值（+1 至 +3），代表多头蕴蓄爆发力；
   - 向下完成取负值（-1 至 -3），代表空头下泄动能强劲；
   - 绝对值代表形态内部累积的压缩能量等级。
2. **典型形态功率评级矩阵**：
   - **+3 / -3 级（极端爆发力）**：三重锯齿（Triple Zigzag）、三重联合（Triple Combination）、三重平台（Triple Flat）、奔走双重三浪（Running Double Three）；
   - **+2 / -2 级（强力）**：双重锯齿（Double Zigzag）、双重联合（Double Combination）、双重平台（Double Flat）；
   - **+1 / -1 级（中等偏强）**：延伸锯齿（Elongated Zigzag）、延伸平台（Elongated Flat）；
   - **0 级（中性基准）**：标准锯齿（Standard Zigzag）、标准平台（Common Flat）、B 浪失败（B-Failure）；
   - **-1 / +1 级（逆向微弱）**：C 浪失败（C-Failure）、不规则平台（Irregular Flat）；
   - **-3 / +3 级（顺大势爆发）**：奔走修正（Running Correction，预示主趋势极度强劲）。
3. **回撤预期戒律**：
   - 评级为 0 并不规定必须 100% 完全回撤，严禁将 0 误写为固定 100% 回撤目标；
   - 评级为 $\pm 1$ 通常回撤不超过 90%，$\pm 2$ 通常不超过 80%，$\pm 3$ 通常不超过 60%～70%；
   - 评级对象必须采用当前**最大已完成形态（Compaction）**，不得将局部末端子浪的评级错层套用于更大宏观级别。

> **执行入口**：`scripts/power_rating.py --type "<形态名>"` 查表输出评级与后势参考；脚本不识别形态，类型由模型数浪确定。

### 4.3 综合得分与主备排序（无绝对门槛，只有相对序位）

1. **计算**：$\text{Total Score} = 2 \times S_{\text{Guideline}} + \sum_{k=2}^{8} S_k$，直接调用 `scripts/score.py`，禁止手算。
2. **排序**：加权总分降序；同分按「失效距离」因子降序（更远者优先）；再同分按方案名升序。
3. **主方案（Primary Count）**：排序第一者，**不设 70 分准入门槛**。若全体候选总分普遍偏低，应在报告中如实披露"当前处于低置信度区、方案质量整体偏弱、交易计划按防守处理"，而不是用阈值把某方案抬为"合格"或把其余方案判死。
4. **替代方案（Alternate Count）**：排序第二（或第三）者，且必须满足 EG-03 的独立性要求。
5. **势均力敌判定（唯一口径 = D7）**：两方案**失效距离的相对差 < 当前价格的 10%** 时视为"失效距离相近"，转入「结构完整度」因子比较（更高者为主）；若结构完整度亦相同，判为**平权双方案并列推进**，各自保留独立失效线，留待下一数据周期仲裁。
   - **阈值作废声明**：原 03_03 的"分差 $\ge 15$ / $< 10$"、04_06 的"分差 $< 5.0$"、03_05 的"分差 $\ge 15$"三套分差阈值**全部作废**。加权总分是"2×Guideline + 7 个 0–2 整数"的合成量，其量纲依赖 Guideline 命中数，用固定分差做门槛缺乏数学依据；D7 的"失效距离相对差"是有量纲的经济意义判据，作为唯一仲裁口径。
6. **共振状态标签（按因子计数，不按总分区间）**：
   - 道氏一致性 = 0 → **背离**（强制观望闸门）；
   - 道氏 = 2、江恩价格 = 2、江恩时间 = 2 三项中计 2 分的项数 $\ge 3$ → **三共振**；
   - 计 2 分项数 $= 2$ → **双共振**；
   - 其余 → **单信号**。
7. **仓位闸门（本体系无独立编号，执行口径唯一在本文）**：
   - 三共振：允许在 04 生成报告的三档基础上再升一档（相对双共振，累计最多升两档）；
   - 双共振（含道氏一致）：升一档；双共振（不含道氏一致）：不干预；
   - 单信号：封顶轻仓试探；
   - 背离：强制观望，暂停单向押注。
   - **作废声明**：不得按总分区间直接映射仓位（原 04_06 的"85.0–100→60%~80%"等区间表已废止）；仓位只能由共振标签 + 04 的三档基础档位 + 功率评级上限共同约束。

## 二、ew_chart 专业波浪绘图与分层规范

图表是技术分析的核心视觉资产。必须调用技能专用绘图引擎 「06_技能_skill/scripts/ew_chart」（源文件） 绘制“K 线图 + 浪型标注”，严格遵守以下绘图与分层铁律。

### 2.1 全景图与方案隔离原则

1. **每图一方案（One Scheme Per Chart）**：每张图表仅展示一个独立的数浪方案，**绝对禁止将主方案与替代方案的标注混叠在同一张图表内**（严守 EG-02 标注符号门禁）。
2. **核心全景图数量**：日线全景图为法定核心交付图表，数量 = 候选方案数 $\times 1$（常规为主方案全景图 1 张 + 替代方案全景图 1 张；防御性单方案模式时仅输出主方案全景图 1 张）。
3. **起画点铁律（Start Point Benchmark）**：
   - 全景图必须从该方案**最大分析级别（大级别框架）结构的第 1 浪起点起画**（通过 `--start` 标定）；
   - **绝对禁止仅从当前操作级别的局部子浪起点截断起画**；
   - 若行情数据早于大级别起点，左侧部分仅作为背景参考，大级别波浪路径（如 1-2-3-4-5 或 A-B-C）必须完整连贯至最新价格。

### 2.2 图数矩阵与分钟分形层图组规范（Chart Matrix & Minute Fractal Layer）

**日线深度（3/4 层）与分钟分形层（启用/不启用）是两个正交维度**，图数按下列矩阵产出：

| 日线交付深度 | 分钟分形层 | 标准双方案 | 单方案防御 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 3 层 | 不启用 | 2 张（全景×2） | 1 张 | 日报默认形态 |
| 3 层 | 已询问-启用 | 8 张（全景×2 + 分钟×6） | 4 张（全景×1 + 分钟×3） | 分钟图组只允许全组或全不出 |
| 4 层（日线） | 不启用 | 2 张（全景×2，含第 4 层折线） | 1 张 | 大级别股指/长史板块 |
| 4 层（日线） | 已询问-启用 | 8 张（全景×2 + 分钟×6） | 4 张 | 两种增强同时生效 |

- **成组出图契约**：一旦启用分钟分形层，各方案必须**全量补齐 60m、30m、15m 分钟分形图各 1 张**；
- **缺张拒绝交付**：分钟图组只允许“全组生成”或“完全不启用”，漏画或缺张时内嵌流水线直接报错中断，拒绝交付；
- **记录↔图组一致（EG-07）**：「embed_report_images」（源文件） 会核对报告【分析前提】“分钟分形层”行与实际图组——记录为 `已询问-启用` 却无分钟图、或记录为不启用／未询问却有分钟图，均拒绝交付。

### 2.3 `--path` 分层拆分铁律（Layered Path Discipline）

为杜绝折线跨级别穿透造成的视觉混乱与逻辑失真，「ew_chart」（源文件） 实施硬性的 `--path` 参数分层拆分纪律：

$$\text{层级拆分} = \begin{cases} 
\text{第 1 层（大级别框架）} & \text{无连字符纯标签，独立单条 --path} \\
\text{第 2 层（中间子浪）} & \text{单连字符标签（如 1-1, 1-2），独立单条 --path} \\
\text{第 3 层（微观分形）} & \text{双连字符标签（如 1-1-1），每条父浪各自一条独立 --path} \\
\text{第 4 层（日线 4 层交付）} & \text{三连字符标签（如 1-1-1-1），每条父浪各自一条独立 --path}
\end{cases}$$

- **禁止混层违规**：**绝对禁止将不同层级的波浪标签混放在同一条 `--path` 参数中**！绘图工具箱内置强校验，一旦检测到跨层级混放，立即报错退出。
- **色彩分层标准**：
  - 第 1 层（大级别）：白色（深色底）/ 纯黑（浅色底）；
  - 第 2 层（子级别）：青色（Cyan）；
  - 第 3 层（细分级）：橙色（Orange）；
  - 第 4 层（日线第 4 层或分钟图路径第 4 级）：亮黄绿（Lime Green, `#AEEA00`，与 00 规范 §4.3 同值）；分钟图组为独立图表，配色沿用 `--path` 路径深度，**不表示“第 4 层＝分钟层”**。
- **实虚线规范（EG-06 契约）**：已确认完成的历史浪段绘制为实线；正在运行或暂定的末端浪段必须绘制为虚线，并标注暂定观察端点。

### 2.4 Y 轴视口锁定铁律（Viewport Lock）

为防止外推辅助线严重破坏 K 线图形的可读性，绘图引擎强制执行 Y 轴视口锁定：
- **定界基准**：主图坐标轴以 K 线实际真实极值（包含所有影线）以及临近的关键参考位（失效位、止损位，最大允许外扩 0.5 倍当前振幅跨度）为定界基础，上下各保留 8% 的观察缓冲；
- **外推线绝对不撑轴**：江恩 1×1 角度线、多空平行通道、外推斐波那契目标线等延伸线条，**只能在计算好的固定坐标系内被视口边缘裁切，绝对不得撑大 Y 轴坐标轴**！坚决杜绝因远期倾斜线将 K 线压成扁平细条的恶性交付缺陷。

### 2.5 失效价位与关键标识

- **失效价位红线**：每个方案图表中必须显式绘制该方案的硬规则失效价位（红色水平虚线），并在右侧清晰附注价格数值及对应规则编号（如 `Invalidation: 3180.50 (R-IMP-07)`）；
- **极端价位小十字**：各子浪波峰与波谷端点处，以含影线极值点为中心标注高亮小十字线；
- **图表元数据标注**：图表标题必须包含 `标的名称 + 标的代码 + 分析级别 + 方案名称（主方案/替代方案）+ 时间跨度`。

### 3.1 base64 自动注入流水线

1. **原图落盘**：「ew_chart」（源文件） 依据 `--out-auto` 参数，将渲染后的标准 PNG 图表输出至当前归档文件夹下的 `图表/` 子目录中（如 `主方案_全景.png`、`替代方案_全景.png`）。

3. **注入与转换机制**：
   - 读取 `图表/` 下的各方案 PNG 图片，生成标准 RFC 2397 base64 编码字符串：

## 一、失效性质严格二分法（Invalidation Taxonomy）

在动态跟踪过程中，必须严格将价格波动的异动区分为**“硬性规则失效”**与**“结构预期减弱 / 观察位击穿”**两类本质截然不同的事件，严禁混淆概念或机械处置。

```
                     ┌── 1. 硬性规则失效（Rule Invalidation） ── 触碰客观几何红线 ── 方案立即宣告死亡
市场价格变动审查 ──┤
                     └── 2. 结构预期减弱（Structural Invalidation） ── 观察位/通道击穿 ── 方案降为“观察中”
```

### 1.1 硬性规则失效（Rule Invalidation / Hard Invalidation）

1. **定义**：市场价格的真实极端点，直接触犯了波浪形态在数学几何拓扑上的客观存在公理（即 「06_波浪规则_rules」（源文件） 所列的 48 条硬性公理）。
2. **典型触发红线**：
   - 推动浪中，浪 2 价格跌破或触及浪 1 起点（触犯 R-IMP-07）；
   - 推动浪中，浪 4 价格区间与浪 1 发生重叠（触犯 R-IMP-10）。**【形态唯一例外原则】**：在波浪理论中，绝大多数推动浪（Impulse Wave）严禁浪 4 与浪 1 价格重叠；倾斜三角形（Diagonal Wave / 楔形 Wedge）是允许浪 4 与浪 1 重叠的唯一形态例外。凡声明为推动浪（Impulse）者一旦发生重叠，一票否决；
   - 推动浪中，浪 3 成为浪 1、3、5 中最短的一浪（触犯 R-IMP-09）；
   - 推动浪中，浪 3 未能超越浪 1 终点（触犯 R-IMP-08）；
   - 锯齿形中，浪 B 回撤超过浪 A 起点（触犯 R-ZZ-05）；
   - 失败第五浪假设中，价格重新超越第 3 浪终点（失败浪本身受 R-IMP-08 位移条件与 G-IMP-03 缩短前提双重约束，突破第 3 浪终点即证伪该假设）；
   - **状态机逆向破位红线（前序调整浪尚未终结）**：若已声明完成的前序调整浪（如第 4 浪或 4-C 浪）终点在后续行情中被击穿（如牛市驱动中出现低于已声明终点的价格，或熊市驱动中出现高于已声明终点的价格），前序调整浪事实上尚未终结，严禁提前声明完成并开启后续驱动浪。该状态机违规属于一票否决项，强制回退调整浪状态为“进行中”并重新定位真实极值终点。
   - **层级与术语规范（驱动 vs 推动）**：必须严格区分驱动浪（Motive Waves）与推动浪（Impulse Waves）。大级别第 2 浪、第 4 浪在宏观属性上永远是调整浪（Corrective Waves）；平台形或锯齿形中的 C 浪是调整浪内部的驱动子浪（Motive Subwave），在报告和数据模型中规范表述为“C浪驱动五浪 (Motive C-wave)”或“终结倾斜三角形 (Ending Diagonal C-wave)”，严禁单立宣称为“推动浪（Impulse）”或输出“第4浪推动结构一票否决”等概念倒错结论。
3. **判定标准与触发机制**：
   - **极端价位即时判定（盘中一票否决）**：采用 K 线的实际极端价位（含最高/最低影线，严守 EG-05 极端价位门禁）。**只要盘中有一笔成交价触及或击穿规则边界，该方案立即在几何拓扑上宣告死亡，绝不需要等待日线或周线收盘价确认**！
4. **处理后果**：
   - 触碰红线的数浪方案自始无效，立即从当前活跃方案池中彻底剔除；
   - 自动触发替代方案升级机制；若所有备选方案同时触犯硬规则，强制触发从零重新数浪。

### 1.2 结构预期减弱 / 观察位击穿（Structural Invalidation / Soft Invalidation）

1. **定义**：市场走势未违反任何波浪硬规则，但价格行为跌破了经典趋势通道、打破了形态预设几何收敛边界、或微观细分未能走出预期模式（如预期中的第 3 浪强延长未出现、平台形 C 浪走势疲软未走出完整 5 浪等）。
2. **典型触发场景**：
   - 上升推动浪决定性跌破 0-2 / 1-3 趋势通道下轨；
   - 收缩三角形走势向外刺破 A-C 连线或 B-D 连线；
   - 终结斜纹浪反向跌破 2-4 趋势线；
   - 预期强力反弹但反弹幅度不足该形态典型回撤比率的下限。
3. **判定标准与触发机制**：
   - **收盘价过滤机制（Confirmation Window）**：不能凭盘中单根毛刺或影线刺破即草率判死。除形态另有明确规定外，**统一以连续 2 根 K 线收盘价位于边界外侧**（项目默认契约 D1）作为有效击穿依据；单根影线刺破仅作风险标记，不改变方案状态。
4. **处理后果**：
   - **方案不立即死亡**：方案标记转为**“观察中（Under Observation）”**，在八因子评分卡中调低其准则命中分与通道契合分；
   - 启动替代方案的并行预警跟踪，但**绝不立即将替代方案粗暴升级为主方案**；
   - 只有后续走势进一步演化出确凿的硬规则反例时，才执行最终的方案淘汰。

## 二、形态演化四阶段状态机（Four-Stage State Machine）

为了彻底根治“只凭早期几根 K 线就提前预画完成形态”以及“看见行情暴跌才倒填见顶形态”等不严肃的数浪通病，所有波浪形态（推动浪、斜纹浪、锯齿形、平台形、三角形）在生命周期中必须严格遵循四阶段状态机演化。

```
┌────────────────┐     已有特征子浪呈现     ┌────────────────┐     全部子浪端点齐备     ┌────────────────┐     突破关键分水岭     ┌────────────────┐
│ 阶段 1: 候选   │ ──────────────────────► │ 阶段 2: 形成中 │ ──────────────────────► │ 阶段 3: 待核   │ ───────────────────► │ 阶段 4: 确认   │
│  (Candidate)   │                         │   (Forming)    │                         │  (Unconfirmed) │                      │  (Confirmed)   │
└────────────────┘                         └────────────────┘                         └────────────────┘                      └────────────────┘
```

### 2.1 状态机四阶段法定定义

| 演化阶段 | 准入证据门槛 | 允许的分析操作 | 绝对禁止的违规行为 |
| :--- | :--- | :--- | :--- |
| **阶段 1：候选**<br>*(Candidate)* | 1. 具备适配的直接父级位置与宏观背景依据；<br>2. 仅出现形态早期的局部启动线索（如推动浪仅走出 1-2 浪，调整浪仅走出 A 浪）。 | 列入潜在候选池；在报告中以文字进行情景推演与条件假设。 | **严禁在图表中绘制完整的形态边界或宣称形态成立**。 |
| **阶段 2：形成中**<br>*(Forming)* | 1. 形态特征子浪已逐步展开（如斜纹浪已走出 1-2-3-4 浪，三角形已走出 A-B-C-D 浪）；<br>2. 基于已有波浪端点的时间与价格坐标，几何趋势线已可明确构造。 | 连接已知端点绘制几何边界；以**虚线**绘制正在运行的末端子浪暂定路径。 | **严禁预画已完成的末端子浪实线（如把未走完的浪 5 或浪 E 画成确定性折线）**。 |
| **阶段 3：完成待核**<br>*(Unconfirmed Completed)* | 1. 所有子浪数量（5 浪或 3 浪）已全部走出；<br>2. 各子浪内部细分结构与极端价位已齐备；<br>3. 走势刚离开末端极值点，但尚未拉开安全距离。 | 方案标记为“完成待核”；计算潜在理论目标区与第一道防守止损位。 | **严禁宣称走势已获得正统趋势反转确认**。 |
| **阶段 4：确认完成**<br>*(Confirmed Completed)* | 1. 反向离开走势决定性击穿关键结构分水岭（如斜纹浪跌破 2-4 线、三角形突破 B-D 线）；<br>2. 价格以连续 2 根收盘价确立突破。 | 方案晋升为“正式确认完成”；全面建立顺势交易计划或调仓。 | **严禁在反向突破出现前，凭主观信仰提前按完成态下单**。 |

### 2.2 典型形态状态机流转细则

#### 1. 倾斜三角形（斜纹浪）状态机
- **阶段 1（候选）**：处于大浪 5 或大浪 C 末端，前序推动动能明显衰竭；
- **阶段 2（形成中）**：子浪 1、2、3、4 呈现收敛态势，浪 4 与浪 1 发生价格重叠（R-DIA-09），绘制 1-3 趋势线与 2-4 趋势线；浪 5 以虚线标注暂定目标；
- **阶段 3（完成待核）**：浪 5 内部 3 浪走完并在 1-3 线附近触顶回落（若发生顺势短暂越界刺破，标记为 Throw-over 翻越候选）；
- **阶段 4（确认完成）**：价格反向大跌，**决定性下穿 2-4 趋势线**（Neely Stage 1 穿线），形态宣告正统确认。

#### 2. 三角形（收缩型）状态机
- **阶段 1（候选）**：走势处于大浪 4 或大浪 B，走出前序 A 浪与 B 浪；
- **阶段 2（形成中）**：C 浪走出 3 浪且幅度小于 A 浪，D 浪走出 3 浪且幅度小于 B 浪；连接 A-C 与 B-D 构造收敛通道；浪 E 处于演进中，严禁预画浪 E 终点；
- **阶段 3（完成待核）**：浪 E 内部调整结构走完，价格在接近 A-C 趋势线处出现滞胀或探底回升；
- **阶段 4（确认完成）**：价格向三角形原始趋势方向发生爆发性突破，**连续 2 根 K 线收盘价突破 B-D 趋势线外侧**（Thrust 喷发），三角形宣告完成。

## 三、形态量化边界与失效触发口径（量化标准）

为了保证自动化脚本（如 「invalidation_check」（源文件））与人工判定口径的高度一致，针对各形态建立精确的量化边界标准。

### 3.1 量化口径适用优先级

$$\mathbf{形态专用量化口径} \succ \mathbf{系统默认口径（连续 2 根收盘突破）} \succ \mathbf{报告特异性披露口径}$$

1. 若形态本身在经典理论中有严格界定（如斜纹浪 2-4 线突破、三角形最宽处幅度），优先按形态特定口径执行；
2. 凡涉及结构线、趋势通道突破的判定，一律遵从系统默认口径：**价格突破（按极端价位判定）后，连续 2 根 K 线收盘价位于边界外侧**；
3. 分析师若针对特定复杂标的采用特异性参数（如 `--confirm-bars 3`），必须在分析报告中清晰披露其数理依据。

### 3.2 倾斜三角形（楔形）量化失效与演化细则

1. **边界构建**：连接浪 1 终点与浪 3 终点构成上轨（上升型），连接浪 2 终点与浪 4 终点构成下轨；端点必须使用含影线极值（EG-05）。
2. **翻越（Throw-over）量化处置**：
   - 上升收缩斜纹浪中，浪 5 顺势短暂刺破 1-3 上轨，属于经典的翻越假突破候选；
   - **量化观察窗**：若刺破后在 1～2 根 K 线内迅速跌回轨内，判定为翻越成功，形态进入阶段 3；
   - **形态失效红线**：若价格突破上轨后连续 2 根收盘价位于轨外，且伴随成交量急剧放大、呈现强劲单边拉升，**判定斜纹浪假设失效**——走势演化为第三浪或第五浪的强烈延伸，必须立即放弃斜纹浪计数。
3. **完成确认与失效终局**：
   - 反向跌破 2-4 趋势线（连续 2 根收盘价在下轨下方），确立阶段 4 反转完成；
   - 价格进一步跌破整个斜纹浪的起点（浪 1 起点），宣告斜纹浪行情彻底终结，后势进入更大级别演化。

### 3.3 三角形量化失效与演化细则

1. **边界构建**：连接 A 浪终点与 C 浪终点构成一条基线，连接 B 浪终点与 D 浪终点构成另一条基线。
2. **浪 E 欠冲与过冲处置**：
   - 浪 E 未触及 A-C 线即提前反转（欠冲）或短线刺破 A-C 线（过冲），均属于允许的准则偏离（G-CT-06 与第一章正文均承认浪 E 可未触及或超越 A-C 线），**严禁单凭浪 E 刺破或未到线就直接否决整个三角形**；
   - 核心裁决依据在于浪 E 内部是否严格细分为 3 浪调整（R-CT-01 的五浪要求 + R-CT-02 的子浪形态要求）。
3. **有效突破 vs 假突破量化鉴别**：
   - **有效突破确认**：价格向外突破 B-D 连线，且连续 2 根 K 线收盘价位于外侧，三角形形态确认完成；
   - **假突破与形态作废**：价格突破 B-D 线后，未能拉开距离且随后 2 根 K 线迅速倒戈跌回三角形最宽区间内部；或价格反向直接击穿 A 浪起点（**项目结构口径，非 06 硬公理**——06 的 R-CT-03 只约束 C/A、D/B、E/C 三组极值，未规定 E 之后不得破 A 起点；故此项只能作为"结构失效"降为观察中，不得据此宣称规则失效）。

### 3.4 推动浪平行通道量化失效

1. **通道构建**：连接浪 1 与浪 3 终点画出主趋势线，通过浪 2 终点画平行线构成目标通道下轨（07 准则）；
2. **决定性突破判定**：价格跌破通道下轨且连续 2 根收盘价未收回，判定为**通道决定性突破**；
3. **处置动作**：触发 S4 软复评机制——重新绘制第 4 浪修正通道，在评分表中调低通道拟合度，并全面复核是否存在第 4 浪进浪 1 的 R-IMP-10 违规。若未触及浪 1 顶，原方案降分保留，不自动升级替代。

## 四、方案动态更新与平滑演化流水线

当市场产生增量行情时，必须执行流水线式的动态维护，杜绝主观臆断与情绪化重数。

```
最新 K 线数据接入（含极端价位）
        │
        ▼
执行 invalidation_check.py 自动化监控
        │
        ├─────────────────────────────────────────────────────┐
        │                                                     │
   [未触及失效位]                                       [触及失效位]
        │                                                     │
        ▼                                                     ▼
检查是否触发软性/硬性重数条件                            判定失效性质（二分法）
        │                                                     │
        ├── 无触发 ──► 维持原计数，推进状态机阶段             ├── 硬规则失效 ──► 主方案死亡，替代方案升级
        └── 软性触发 ──► 执行局部微调与重评分                 └── 结构失效 ──► 主方案转观察中，替代并行
                                                              │
                                                              ▼
                                               写回原归档目录第 8 章变更日志
```

### 4.1 重新数浪触发条件分类（硬性 vs 软性）

**更新轮不重问深度与分钟层（复用规则）**：同一标的的 05 更新默认沿用上一份报告的 `细分深度来源`（3 层或日线 4 层）与“分钟分形层”答复，写回时保留原值、不重复发起门禁 A／门禁 B 询问；只有用户显式要求变更（如“这次加分钟验证”“这次改 4 层”）才重新询问并改写记录。触发 H1~H4 退回 02 重数时，同样先复用上次答复；若重数改变了框架起点或活跃浪 `T_d0`，而分钟层已启用，须重新执行分钟切片并在变更日志登记新的 `T_d0`。

#### 1. 硬性触发条件（Hard Triggers —— 必须强制退回 02 重新数浪）
- **H1 推动浪三铁律客观违规**：最新极值使浪 2 破浪 1 起点（R-IMP-07）、浪 4 与浪 1 重叠且非斜纹（R-IMP-10）、或浪 3 沦为最短浪（R-IMP-09）；
- **H2 级别嵌套分形崩溃**：大级别推动浪在次级别或分钟级别上，无法分解为任何合法的分形子结构（触犯工程门禁 EG-04 的细分深度要求；理论侧对应 R-IMP-01 的五浪可分性）；
- **H3 候选方案全军覆没**：主方案与所有备选方案的硬规则失效价位同时被市场价格贯穿；
- **H4 失败第五浪假设被证伪**：被标记为“第 5 浪失败”的走势，后续价格强行突破了第 3 浪终点，且无法归入延长浪。

#### 2. 软性触发条件（Soft Triggers —— 仅触发重新评估与评分，不强制重数）
- **S1 时空比例严重失衡**：子浪运行时间或幅度严重背离常见斐波那契比率达 3 倍以上；
- **S2 调整形态细分持续不符**：假设为平台形的调整浪，经过 3 个以上观测周期后仍无法数出 3-3-5 构型；
- **S3 复合调整结构显现**：单锯齿走势演变为 W-X-Y 双锯齿，或出现罕见三重三浪线索；
- **S4 关键通道决定性突破**：主平行通道被连续 2 根收盘价击穿，需重画通道并重测目标。

### 4.2 替代方案升级与裁决树

当主方案遭遇硬规则失效死亡时，启动替代方案晋升机制：
1. **重新计算各替代方案的八因子加权得分（Total Score）**；
2. **排序与仲裁（唯一口径 = 03_03 §4.3 + D7）**：
   - 先按 「score」（源文件） 重算加权总分降序，最高分者为候选新主方案（**不设分差门槛**，分差本身不构成裁决依据）；
   - 若候选与次优方案的**失效距离相对差 < 当前价格的 10%**（D7 判定带），进入**结构完整度仲裁**：内部子浪细分更清晰、已确认段落更多者晋升；
   - 若失效距离相对差 $\ge 10\%$，**失效距离更远者**（安全边际更高）优先于总分更高者晋升，并在报告中披露"总分让位于安全边际"的理由；
   - 若依然无法分出高下：两方案作为"平权双方案"并列推进，各自保留独立失效线，留待下一数据周期仲裁。
   - **作废声明**："分差 $\ge 15$ 分立即晋升"的旧规则废止——加权总分是"2×Guideline + 7 个 0–2 整数"的合成量，固定分差没有量纲意义。
3. **升级后闭环检验**：任何升级为新主方案的数法，必须重新完整执行一次 `03_多流派综合验证` 的双轨门禁审查与交叉印证。

### 4.3 报告原地版本化写回与变更日志（Change Log）

更新轮次的交付必须严格保持历史血统的一致性：
1. **原地写回纪律**：更新产生的所有分析结论、图表与网页，**一律直接写回同一标的的既有归档文件夹（`分析输出/<标的名称_代码_YYYYMMDD_HHMM>/`）**，绝对禁止另起炉灶创建碎片化文件夹；
2. **生命周期变更日志（Change Log）**：
   - 在既有分析报告的【8. 更新与跟踪】章节末尾，以追加方式记录本次更新详情；
   - 记录要素包含：`更新时间戳 + 触发事件（如触及失效价/通道突破）+ 方案状态演变（主方案死亡/替代方案升级）+ 引用规则编号 + 后续交易调整建议`；
3. **重大重构标识**：若因大级别崩溃而不得不彻底重开新周期分析，必须新建带新时间戳的归档文件夹，并在旧归档文件夹的第 8 章明确登记：`“本标的历史周期已终结，全新宏观数浪已移交至新文件夹：<新文件夹名称>”`。
