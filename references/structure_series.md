# 结构阶梯（Structure & Degree Ladder）—— Neely 分组与证据流程

> 依据本地《Mastering Elliott Wave》文字版 ch02–ch04、ch07–ch08。原书页码随各节注明；文字版由 DJVU 导出，图表与 OCR 有局限。本文是教学整理，不是完整 Neely 自动判定器。项目硬规则以 06 为准，最终图表遵守 R23。

## 1. 结构阶梯与波浪级别分开记录

单浪（Monowave）是分析数据上分出的基本运动单元；多浪（Polywave）由单浪按结构关系组合；复杂多浪（Complex Polywave）、复合多浪（Multiwave）与宏浪（Macrowave）需按细分组成进一步区分。这些名称描述组合复杂度，不能直接等同于 Minute、Minor 等波浪级别，也不能由日 K／周 K 自动决定。

原书ch08页8-1–8-2、8-16–8-18对标准型结构阶梯有具体界线：只有调整组成细分成Polywave，且`:5`组成仍是单浪时，可保留Complex Polywave；若`:5`组成细分成Polywave，则进入Multiwave或更高层，记录原结构复杂度，不能以压缩后的外观抹去内部层级。Multiwave还须分别核对驱动／调整的组成条件，不能把“一项`:5`细分”当成完整充分条件。Macrowave进一步涉及Multiwave与Polywave的组合，不能仅由波幅更大来命名。

原书 ch04 页 4-1 指出：调整多浪至少包含三个单浪，驱动多浪至少五个；这只是必要的分组数量，不是“数到三／五段即通过”的充分条件。还须核实结构序列、位置、相邻关系、完成证据与父级归属。

项目采用 R20 的 OHLC 含影线端点和现有摆动工具；不声称它复现了原书全部绘图、单浪划分与 Neutrality 处理。原书中价格记录方式的差异应披露，不能无说明地混入一份分析。

## 2. 结构标签、位置指示与结构序列

原书 ch02 页 2-5 与 ch03 页 3-60–3-64 区分如下：

| 记法 | 含义 | 常见误用 |
| --- | --- | --- |
| `:3` / `:5` | 调整／驱动的基础结构标签 | 把它当成波浪第 3／第 5 浪的位置编号 |
| `:F3` | First three，带位置指示的三浪结构 | F 不是“非标准”；不能把 F3 本身当成复合调整 |
| `:c3` | Center three，序列中间的三浪结构 | 直接当成整个序列的开始或结束 |
| `:L5` | Last five，结束较大形态的五浪结构 | 标签写了 L 就假定末段已获后势确认 |
| `-` / `++` | 同一标准序列内连接／与连接浪有关的组合边界 | 与项目图表的父子路径分隔符混为一谈 |

`5-3-5`、`3-3-5` 等可作粗略组成摘要，但不能替代完整 Positioned Structure Labels 的位置检查。同为五个调整组成，Triangle 与 Terminal 仍须按父级位置和几何区分；不能凭一串数字决定唯一形态。

单浪归口由项目 R33、D33/D34 承接。先按原书观察规则取得m0/m2，二者可由一个或奇数个单浪组成；突破与转向尚未确认时，只能记录暂定范围及条件比例。`monowave_judge.py` 只计算给定端点的条件回撤分档，不确认观察段端点或整体行为期，**不生成完整 Condition / Category 或全部结构标签**；缺少相邻浪、前后序列时，不可据其输出补写 `R-4a-i` 等未验证标签。Neely 的 Rule 1–7 与项目 R1–R7 是两个编号体系，报告须注明所属体系。

### 观察段教学例：一次回撤不等于完整m2

假定m1为100→200，之后依次为200→160→190→120→210。未越过m1边界之前，不能因为160处反弹就确认m2终点；依原书图3-20a／3-21a的向上突破情景，后续突破200后，m2观察段终点取中间最低120，含三个单浪，m2/m1=80%，进入Rule4。若提前只取200→160，会得到40%、Rule2。这里的两个算式均可计算，但前者是后续确认后才能取得的观察段；不能把120回写成160时已经知道的端点。反向场景按原书同一观察规则处理。

## 3. 进度标签（Progress Labels）不是完成状态标签

原书 ch02 页 2-5–2-6、ch11 页 11-1：Progress Labels 表示浪在形态中的位置，即 `1,2,3,4,5` 或 `a,b,c,d,e,x` 等。它不是一套与普通数字字母不同的“已确认／未确认”符号。

项目最终报告仍使用 R23 标准数字／字母及父级路径。形成中、待确认、已完成等状态另列文字，结构标签作为推理记录，不混进同一条图形浪链。为某段标为第 3 浪，意味着需要相应的前序及内部证据，不是给端点取一个名字就成立。

## 4. 从局部归口到完整候选

| 步骤 | 记录 | 缺证时的处理 |
| --- | --- | --- |
| 划分 | 截止时间、m1及m0/m2观察段、单浪／单浪组身份、端点来源和确认时刻 | 观察尚未结束则仅条件演算；输入不连续或分母为零先修正 |
| 初筛 | m2/m1、必要的 m0/m1 等及 Rule 分档 | 保留多个可能身份，不让分档代替形态识别 |
| 组合 | 结构标签序列、每项前提、候选父级位置 | 不够完整时只列候选，不压缩成已确认结构 |
| 复核 | 相似性、形态规则、通道与完成证据 | 反例排除该具体分组；缺证登记待确认 |
| 压缩 | 将已核验组成概括为基础结构，并保留原子段映射 | 压缩不能删除内部反例，也不能改变原级别以凑图 |
| 压缩后复核 | 按ch07页7-2重新检查基础结构及左右两侧单浪／波组，随后重新分组 | 与原形态性质冲突时记录疑点并复核；先检查下述例外，不强行改标签 |

压缩（Compaction）是保留可追溯内部证据后的概括，不是切换图表周期或肉眼忽略小波动。原书 ch04 的 Rounds 1–3 描述反复分组、验证、压缩及继续观察的过程；不把“做过三轮”当成自动通过。

原书ch07页7-2要求将压缩形态视为单浪返回ch03重新检查，再检查其两侧波段，并回到ch04重新分组。例外见ch03页3-68：若形态在自身结束前越过自身起点，原书要求保留其调整基础结构`:3`，不在这次重新检查中套用Pre-Constructive规则推翻它。例外须有内部路径证据；不能只凭一对端点或当前整体涨跌判定。

## 5. 相似与平衡（Similarity and Balance）

原书 ch04 页 4-3–4-4：相邻候选浪比较价格幅度及持续时间，较小者／较大者在**价格或时间至少一个维度达到 1/3**才有相似性支持，不要求两者同时达到。即便满足，也只说明可能同级，不证明同级。

教学例：甲幅度 90、用时 12；乙幅度 20、用时 5。价格比 20/90≈0.222，时间比 5/12≈0.417，时间维度支持继续检查。若乙用时仅 3，则两者都小于 1/3，应复查分组／压缩，不能直接宣布整个经典波浪数法失效。

此处是已存在 Neely 相似性方法的明确化，不新增项目 Rule 编号或评分。零幅度／零时长不参与除法；必须采用同一价格与时间计量口径。原书的 Zigzag DETOUR 需完整序列及图示上下文，本项目不从名称推造一条通用快捷规则。
