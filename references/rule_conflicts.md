# 规则冲突与跨流派仲裁

## 三、跨流派冲突裁决引擎（Conflict Adjudication Engine）

当波浪结构、经典几何线条、道氏趋势、江恩时间窗与传统指标（MACD/RSI/均线）出现相互矛盾时，必须启动标准化仲裁程序，依据严格的宪法级顺位进行裁决。

### 3.1 仲裁最高宪法原则

技术分析诸流派的置信度与裁判权严格遵从以下优先级顺位：

$$\mathbf{波浪形态结构公理} \succ \mathbf{经典几何连线} \succ \mathbf{道氏趋势信号} \succ \mathbf{江恩时空线} \succ \mathbf{传统技术指标（MACD/RSI/均线）}$$

```
【最高裁判权】 波浪理论硬公理（Rules）：拥有绝对否决权，几何拓扑不合法直接判死
      │
      ▼
【几何约束层】 经典通道连线与趋势线（0-2线、2-4线、A-C/B-D线）：物理边界与翻越判定
      │
      ▼
【趋势大局层】 道氏理论主要趋势与阶段：宏观方向校准，提供先验概率
      │
      ▼
【时空测度层】 江恩角度线与时间共振窗口：辅助定位时空驻点，不改变形态合法性
      │
      ▼
【滞后参考层】 传统技术指标与均线系统：动量与平滑指标，仅作背离提示，永不覆盖结构
```

### 3.2 冲突类型与仲裁矩阵

| 冲突类型 | 典型场景 | 唯一法定裁决准则 |
| :--- | :--- | :--- |
| **Rule vs Rule 表面冲突** | 普通推动 R-IMP-10（重叠禁止）vs 斜纹浪 R-DIA-09（重叠为身份特征） | **先查例外前提条件**：核验直接父级位置（必须是浪 1/A 或浪 5/C）、子浪内部结构（R-DIA-04/05）与边界收敛性（R-DIA-11/12）。条件全部满足时适用斜纹浪合法例外；任一条件缺漏，坚决按 R-IMP-10 裁决为非法重叠。 |
| **Rule vs Guideline 冲突** | 06 R-IMP-09（浪 3 非最短，硬否决）vs 07 G-IMP-06（浪 1 最不常延长，仅概率） | **硬规则绝不妥协**：Guideline 仅描述概率偏离，绝对不得用来豁免硬规则的违规。概率上的"罕见"不能把几何上的"不可能"变成合法。 |
| **Guideline vs Guideline 冲突** | G-IMP-01 交替原则偏向方案 A vs G-IMP-04 比率典型偏向方案 B | **进入八因子量化加权**：准则间冲突不影响方案合法性，通过八因子量化评分卡综合计算总分，高分者为主方案，低分者为替代方案。 |
| **波浪结构 vs 道氏趋势** | 波浪数出浪 5/C 浪顶底反转，但道氏理论尚未出现 DO5 突破确认 | **降概率兼保留张力**：主方案保留波浪转向假设，但在报告中必须明确披露“形态筑顶/筑底 vs 道氏趋势未翻转”的结构张力；严禁因道氏未确认而直接废弃合法的波浪数法。 |
| **波浪结构 vs 江恩价位** | 江恩 1×1 线或 1/8 分割位显示强支撑，但波浪结构已有效击穿失效价位 | **失效价位绝对统治**：失效价位是全场最高权威！绝对禁止以“江恩在此处有角度线支撑”为借口，强行保留已被硬规则击穿的数浪方案。 |
| **江恩时间 vs 斐波那契时间** | 江恩周期日与波浪斐波那契时间窗指向不同日期 | **双窗口披露，交叠方计分**：在报告中如实列出两个时间窗口；仅当两体系窗口发生时间交叠（共振）时，方可计入“时间共振”满分，禁止事后择一报喜。 |

### 3.3 三大经典冲突场景专项裁决

#### 场景 1：指标顶背离 vs 波浪第 3 浪主升（MACD/RSI Divergence vs Wave 3 Impulse）
- **现象冲突**：市场处于波浪第 3 浪的主升或延伸阶段，但 15m/60m 乃至日线 MACD/RSI 出现持续的多重顶背离钝化。
- **裁决法门**：**波浪结构绝对优先！**
  - 在强劲的第 3 浪推动延伸中，动量指标常常出现“背离再背离”的指标钝化假象；
  - 严禁因指标背离而提前宣布波浪推动终结或在主升浪中逆势猜顶；
  - 传统指标的顶背离仅可作为子浪内部短线动能波动的参考，只要价格未跌破浪 1 顶（R-IMP-10）且浪 3 未完，必须坚决持有多头数浪立场。

#### 场景 2：均线多头排列 vs 终结斜纹浪 / 大 B 浪见顶（MA Golden Cross vs Ending Diagonal / Wave B Top）
- **现象冲突**：各周期移动平均线（MA5/10/20/60）呈现完美的多头排列与加速金叉，但波浪图表清晰走出 3-3-3-3-3 收敛的终结斜纹浪浪 5，或平台形奔走/扩张 B 浪的高位终结端点。
- **裁决法门**：**形态结构优先！**
  - 均线本质上是价格历史数据的加权平滑滞后指标；
  - 终结斜纹浪与大 B 浪诱多冲顶正是利用均线滞后性吸引跟风盘的经典主力行为；
  - 一旦波浪终结形态结构完整且触及预期反转区，必须立即启动最高级别防御机制，提示随时面临断崖式转折，不得被均线多头排列麻痹。

#### 场景 3：蜡烛图反转信号 vs 推动浪延伸推进（Reversal Candle vs Extended Impulse）
- **现象冲突**：在上行推进走势中，日 K 线收出标准的黄昏之星、看跌吞没或巨量长上影流星线，但波浪层级计算显示当前仅处于大浪 3 内部子浪 3 的第 1 或第 3 微浪。
- **裁决法门**：**同级主浪结构优先！**
  - 局部单个或组合 K 线的反转，不能对抗同级别主推动浪未完成的结构事实；
  - 裁决将该蜡烛图信号定性为“次级折返/内部子浪回调”的微观启动信号（例如子浪 3-2 或子浪 3-4），而非大级别推动浪见顶；
  - 严禁将微观 K 线信号作为颠覆宏观数浪方案的依据。

### 3.4 形态边界裁决固定顺序（五步法）

当走势在形态归属上出现分歧（如：单锯齿 vs 双锯齿、平台形 vs 三角形、终结斜纹 vs 推动失败）时，必须按以下固定五步顺序裁决：
1. **第一步：结构证据优先（Internal Structure）**：先按内部子浪计数裁决身份。锯齿形必须为 5-3-5，平台形必须为 3-3-5，三角形必须为 3-3-3-3-3。子浪内部驱动与调整属性是最高裁决证据。
2. **第二步：位置约束次之（Positional Eligibility）**：三角形绝不能作为推动浪独立的第 2 浪（R-IMP-05 要求浪 2 为锯齿/平台/联合；G-CT-06）；斜纹浪绝不能作为推动浪独立的第 3 浪（R-DIA-03 + R-IMP-03）。
3. **第三步：身份与方向自洽（Identity & Alternation）**：逆势修正浪（B、X、W、Y、Z）绝不能标记为推动浪；同级浪 2 与浪 4 必须展现形态或深度交替。
4. **第四步：八因子量化计分（Factor Scoring）**：若前三步审查后仍存在多种合法解释，带入八因子评分卡计算综合得分。
5. **第五步：多重数浪并列输出（Multi-Count Presentation）**：若两方案得分极度接近且逻辑皆完备，严禁主观硬猜单一方案，必须并列输出主方案与替代方案，各自划定独立失效红线，由市场后续数据仲裁。
