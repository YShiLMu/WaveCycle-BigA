# 蜡烛图（Candlestick / Japanese Candlestick）——信号层：K 线形态与转折确认

> **本文件定位**：日本蜡烛图是本仓库技术分析融合分层中的**信号层**——蜡烛图管"转折是否确认"（K 线信号），只做概率加分与转折/持续信号的交叉确认。优先级铁律：**波浪 Rule > 道氏 > 江恩 ≈ 蜡烛图**；蜡烛图信号一律为 Guideline 级证据，永不否决数法、永不覆盖失效价位（裁决见 `references/rule_conflicts.md`）。
>
> **编号约定**：蜡烛图信号用 CS 系列（CS1、CS2……）；校验清单条目用带连字符的 CS-x（见 `references/checklists.md（蜡烛图）`）。
>
> **术语口径**：所有形态术语统一「中文（English）」格式；形态判定一律按**极端价位（含影线）**（references/rules.md R20），不以收盘/实体替代影线触及。
>
> **边界约定**：本文件只写蜡烛图形态库与信号口径（Guideline 级），不写 Rule；蜡烛图信号只进入 references/guidelines.md G21 八因子评分的「蜡烛图信号」因子（权重 ×1，见 references/defaults.md D25），不产生、不覆盖任何波浪失效价位。
>
> **形态分类**：蜡烛图形态分两类——**反转形态（Reversal Patterns）**（顶/底转折）与**持续形态（Continuation Patterns）**（趋势中继）。第 1–3 节（单根/双根/三根）属反转形态；第 4.5 节（三法/跳空二法）属持续形态；第 4 节缺口中的"持续缺口"也是持续信号。持续形态用于确认第 3 浪加速/趋势中继，反转形态用于确认第 5 浪/C 浪末端转折。

## 1. 单根 K 线形态（Single-Candle Patterns）

单根形态的判定取决于**实体与影线的相对关系**，以及所处**趋势位置**；同一根 K 线在不同位置含义相反（如锤子线 vs 上吊线）。

- **大阳线 / 大阴线（Marubozu，光头光脚）**：开盘即最低（大阳）或最高（大阴）、收盘即最高（大阳）或最低（大阴），实体长、上下影线极短或无。代表单边力量强劲，常出现在推动浪的主升/主跌段。
- **锤子线（Hammer）**：出现在**下降趋势末端**；下影线 ≥ 实体的 2 倍、上影线极短、实体位于整根 K 线上部。是潜在底部反转信号。
- **上吊线（Hanging Man）**：形似锤子线（下影线长、实体小），但出现在**上升趋势末端**。是潜在顶部警示信号——形态相同、位置决定含义。
- **流星线（Shooting Star）**：出现在**上升趋势末端**；上影线 ≥ 实体的 2 倍、下影线极短、实体位于整根 K 线下部。是顶部反转警示。
- **倒锤子（Inverted Hammer）**：形似流星线（上影线长、实体小），但出现在**下降趋势末端**。是潜在底部反转信号（需后续阳线确认）。
- **十字星（Doji）**：开盘价 ≈ 收盘价，实体极短（近似一条横线）。按影线形态细分——**长腿十字星（Long-Legged Doji）**（上下影线均长，方向不明）、**墓碑十字星（Gravestone Doji）**（上影线长、下影线极短，顶部警示）、**蜻蜓十字星（Dragonfly Doji）**（下影线长、上影线极短，底部信号）。十字星本身是"多空势均力敌"信号，只有出现在趋势末端且被后续 K 线确认才有转折意义。
- **纺锤线（Spinning Top）**：实体短、上下影线均长，多空分歧、方向不明，属**弱信号**（references/guidelines.md G21 蜡烛图信号因子计 1 分的典型形态）。

## 2. 双根 K 线形态（Two-Candle Patterns）

双根形态的关键是**第二根对第一根的吞没/穿越关系**：

- **看涨吞没（Bullish Engulfing）**：下降趋势中，第二根阳线实体完全吞没第一根阴线实体（实体比较，不看影线）。是底部反转信号。
- **看跌吞没（Bearish Engulfing）**：上升趋势中，第二根阴线实体完全吞没第一根阳线实体。是顶部反转信号。
- **乌云盖顶（Dark Cloud Cover）**：上升趋势中，第一根为大阳线，第二根阴线开盘高于第一根收盘、但收盘深穿入第一根阳线实体内部（超过实体的 50% 更可靠）。是顶部反转信号。
- **曙光初现（Piercing Line）**：下降趋势中，第一根为大阴线，第二根阳线开盘低于第一根收盘、但收盘深穿入第一根阴线实体内部（超过 50% 更可靠）。是底部反转信号。

> 吞没以**实体**为准（不含影线），穿越以**收盘**穿入幅度为准；两者都是"第二根反攻第一根"的力度比较。

- **孕线（Harami）**：第二根实体完全被第一根实体包含（第一根大、第二根小，形如"孕"）。**看涨孕线（Bullish Harami）**出现在下降末端（第一根大阴线 + 第二根小实体）；**看跌孕线（Bearish Harami）**出现在上升末端（第一根大阳线 + 第二根小实体）。是潜在反转信号，力度弱于吞没、需后续确认。
- **十字孕线（Harami Cross）**：孕线中第二根为**十字星（Doji）**（实体极短）时，反转信号强于普通孕线。
- **镊子顶 / 镊子底（Tweezers Top / Bottom）**：两根（或以上）K 线的**最高价相同**（镊子顶）或**最低价相同**（镊子底），出现在趋势末端构成顶部/底部反转信号；等高按**极端价位（含影线）**判定（references/rules.md R20）。
- **分手线（Separating Lines）**：双根 K 线**开盘价相同（或接近）但方向相反**——上升趋势中第一根阴线、第二根阳线自同开盘价向上（看涨持续）；下降趋势中第一根阳线、第二根阴线自同开盘价向下（看跌持续）；出现在末端亦可作反转确认，属方向延续/反转两用信号。

## 3. 三根 K 线形态（Three-Candle Patterns）

- **启明星（Morning Star）**：下降趋势末端，依次为大阴线 → 小实体星线（可与两侧实体分离，形成跳空）→ 大阳线，第三根阳线收盘穿入第一根阴线实体过半。是底部反转信号。
- **黄昏星（Evening Star）**：上升趋势末端，依次为大阳线 → 小实体星线 → 大阴线，第三根阴线收盘穿入第一根阳线实体过半。是顶部反转信号。
- **十字启明星 / 十字黄昏星（Doji Morning/Evening Star）**：启明星/黄昏星中间那根星线为**十字星（Doji）**时，反转信号更强（十字星强化了"势均力敌后反转"的力度）。
- **三只乌鸦（Three Black Crows）**：上升趋势末端，连续三根阴线，每根收盘均低于前一根、且每根开盘均位于前一根实体之内或附近。是强烈的顶部反转信号。
- **三个白兵（Three White Soldiers）**：下降趋势末端，连续三根阳线，每根收盘均高于前一根、且每根开盘均位于前一根实体之内或附近。是强烈的底部反转信号。
- **三星（Three Stars）**：三根**十字星（Doji）**连续（或近似连续）出现，多空在极端位置三次势均力敌，是极强的顶部/底部反转信号（顶部三星 vs 底部三星按出现位置区分）。
- **塔形顶 / 塔形底（Tower Top / Bottom）**：多根 K 线渐变式反转——上升末端先多根小阳缓涨（塔身）再一根或多根大阴急跌（塔尖转势）构成塔形顶；下降末端对称构成塔形底。属**多根渐变式反转**形态（非严格三根）。

## 4. 缺口（Gap）

缺口是相邻两根 K 线之间未被交易覆盖的价格区间（上/下沿按**极端价位**，references/rules.md R20）。按位置与性质分四类：

- **普通缺口（Common Gap）**：出现在震荡/横盘区，方向意义弱，通常很快回补。属**弱信号**。
- **突破缺口（Breakaway Gap）**：价格突破关键区间/技术分析锚点（趋势线、前高前低、横盘边界）时留下、且未回补。是趋势启动/推动浪确认的强信号。
- **持续缺口（Runaway / Measuring Gap）**：趋势中途（常在第 3 浪加速段）留下，量度趋势延续。是趋势持续的确认信号。
- **衰竭缺口（Exhaustion Gap）**：趋势末端（常在第 5 浪冲刺段）留下，随后快速回补。是趋势衰竭的警示信号。
- **岛形反转（Island Reversal）**：一段孤立的价格区域，两侧被两个方向相反的缺口包围（如上升末端：向上衰竭缺口 + 向下突破缺口）。是强烈的趋势反转信号。

## 4.5 持续形态（Continuation Patterns）

持续形态是趋势中继信号，用于确认第 3 浪加速 / 趋势延续，而非顶/底转折：

- **上升三法（Rising Three Methods）**：上升趋势中，先一根**大阳线** → 随后 2–3 根小阴线回撤（每根都落在第一根大阳线的**实体范围**内，且收盘不低于第一根开盘）→ 再一根**大阳线**创出新高。整体是"回调洗盘后继续上攻"，持续看涨。
- **下降三法（Falling Three Methods）**：下降趋势中，先一根**大阴线** → 随后 2–3 根小阳线反弹（都落在第一根大阴线实体范围内）→ 再一根**大阴线**创出新低。持续看跌。
- **向上跳空二法（Upside Tasuki Gap）**：上升趋势中，跳空大阳线 → 次日阴线回补部分缺口（未回补完）→ 第三根阳线延续原趋势创新高。持续看涨。
- **向下跳空二法（Downside Tasuki Gap）**：下降趋势中，跳空大阴线 → 次日阳线回补部分缺口 → 第三根阴线延续原趋势创新低。持续看跌。

> 三法/跳空二法都属于**趋势中继**：回撤/回补不破坏原趋势结构（小实体均被第一根实体包裹、或仅回补部分缺口），随后原方向再创新高/新低。与第 4 节的"持续缺口"同属持续信号，落位见第 5 节。

## 5. 与波浪的配合（Wave-Candlestick Integration）

蜡烛图信号必须**落到波浪位置**才有意义——同一形态在不同浪位含义不同：

- **第 5 浪末端出现上吊线 / 流星线 / 黄昏星 / 看跌吞没 / 乌云盖顶 / 看跌孕线 / 十字孕线 / 镊子顶 / 三星 / 塔形顶 / 衰竭缺口** → **顶部警示**：第 5 浪（或终结楔形末端）见顶概率上升，提示关注后续 A 浪调整或趋势反转。
- **C 浪末端出现锤子线 / 倒锤子 / 启明星 / 看涨吞没 / 曙光初现 / 看涨孕线 / 十字孕线 / 镊子底 / 塔形底 / 蜻蜓十字星** → **底部信号**：调整浪 C 浪（或 B 浪回撤末端）见底概率上升，提示推动浪可能重启。
- **突破缺口 / 岛形反转 / 三个白兵（或三只乌鸦）出现在推动浪起点** → **推动浪启动确认**：佐证第 1 浪启动或调整结束后的新推动。
- **上升三法 / 下降三法 / 向上跳空二法 / 向下跳空二法 / 持续缺口出现在第 3 浪加速段（或趋势中继）** → **趋势持续确认**：佐证推动浪未走完、第 3 浪仍在延伸。
- **十字星 / 纺锤线 / 普通缺口** 出现在趋势中段或无明确浪位 → 弱信号，仅计 1 分或不计分，不作为转折依据。

**铁律**：蜡烛图信号**只确认、不裁决**——即使出现顶部/底部蜡烛形态，只要波浪 Rule 未触发失效，就不得据此改判数法（优先级见 `references/rule_conflicts.md`）。蜡烛图信号方向与数浪方向矛盾时，只在 references/guidelines.md G21 蜡烛图信号因子计 0 分并披露，不改数法。
