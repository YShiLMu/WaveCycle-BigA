# 10 蜡烛图（Candlestick）——信号层：K 线形态与转折确认

> **文献真源与溯源声明**  
> - **理论属性**：蜡烛图是技术分析融合分层中的**信号层**——只管「转折是否确认」，只做概率加分与转折/持续信号的交叉确认。  
> - **铁律**：**波浪 Rule > 道氏 > 江恩 ≈ 蜡烛图**；蜡烛图信号一律为 Guideline 级证据，**永不否决数法、永不覆盖失效价位**（裁决见 `references/rule_conflicts.md`）。  
> - **编号约定**：蜡烛图信号用 CS 系列（CS1、CS2……）；校验清单条目用 CS-x（见 `references/checklists.md` 的 CK-CS-xx）。  
> - **形态判定**：一律按**极端价位（含影线）**（EG-05），不以收盘/实体替代影线触及。  
> - **落点**：只进入八因子中的**「蜡烛图信号」因子（权重 ×1，D25）**，不产生、不覆盖任何波浪失效价位。  
> - **形态分类**：**反转形态**（顶/底转折，第 1–3 节）与**持续形态**（趋势中继，第 4.5 节的二法/三法）。持续形态用于确认第 3 浪加速，反转形态用于确认第 5 浪/C 浪末端转折。

---

## 1. 单根 K 线形态（Single-Candle Patterns）

单根形态的判定取决于**实体与影线的相对关系**与所处**趋势位置**；同一根 K 线在不同位置含义相反（锤子线 vs 上吊线）。

- **大阳线 / 大阴线（Marubozu，光头光脚）**：开盘即最低（大阳）或最高（大阴）、收盘即最高（大阳）或最低（大阴），实体长、影线极短或无。单边力量强劲，常见于推动浪主升/主跌段。
- **锤子线（Hammer）**：出现在**下降趋势末端**；下影线 ≥ 实体 **2 倍**、上影线极短、实体位于整根 K 线上部。潜在底部反转。
- **上吊线（Hanging Man）**：形似锤子线，但出现在**上升趋势末端**。潜在顶部警示——形态相同、位置决定含义。
- **流星线（Shooting Star）**：出现在**上升趋势末端**；上影线 ≥ 实体 **2 倍**、下影线极短、实体位于下部。顶部反转警示。
- **倒锤子（Inverted Hammer）**：形似流星线，但出现在**下降趋势末端**。潜在底部反转（需后续阳线确认）。
- **十字星（Doji）**：开盘 ≈ 收盘，实体极短。细分：**长腿十字星**（上下影线均长，方向不明）、**墓碑十字星**（上影长、下影极短，顶部警示）、**蜻蜓十字星**（下影长、上影极短，底部信号）。十字星本身是「势均力敌」，**只有出现在趋势末端且被后续 K 线确认**才有转折意义。
- **纺锤线（Spinning Top）**：实体短、上下影线均长，多空分歧，属**弱信号**（「蜡烛图信号」因子计 1 分的典型形态）。

## 2. 双根 K 线形态（Two-Candle Patterns）

关键是**第二根对第一根的吞没/穿越关系**：

- **看涨吞没（Bullish Engulfing）**：下降趋势中，第二根阳线**实体**完全吞没第一根阴线实体（不看影线）。底部反转。
- **看跌吞没（Bearish Engulfing）**：上升趋势中，第二根阴线实体完全吞没第一根阳线实体。顶部反转。
- **乌云盖顶（Dark Cloud Cover）**：上升趋势中，第一根大阳线，第二根阴线开盘高于第一根收盘、收盘**深穿入第一根阳线实体过半**。顶部反转。
- **曙光初现（Piercing Line）**：下降趋势中，第一根大阴线，第二根阳线开盘低于第一根收盘、收盘**深穿入第一根阴线实体过半**。底部反转。
- **孕线（Harami）**：第二根实体完全被第一根实体包含。看涨孕线（下降末端：大阴 + 小实体）、看跌孕线（上升末端：大阳 + 小实体）。力度弱于吞没、需后续确认。
- **十字孕线（Harami Cross）**：孕线中第二根为**十字星**时，反转信号强于普通孕线。
- **镊子顶 / 镊子底（Tweezers）**：两根（或以上）最高价相同（镊子顶）或最低价相同（镊子底），出现在趋势末端构成反转信号；**等高/等低按极端价位（含影线）判定**。
- **分手线（Separating Lines）**：两根**开盘价相同（或接近）但方向相反**——上升趋势中「阴→阳」自同开盘向上（看涨持续），下降趋势中「阳→阴」自同开盘向下（看跌持续）；末端亦可作反转确认。

## 3. 三根 K 线形态（Three-Candle Patterns）

- **启明星（Morning Star）**：下降末端，大阴线 → 小实体星线（可与两侧实体跳空）→ 大阳线，第三根收盘穿入第一根实体过半。底部反转。
- **黄昏星（Evening Star）**：上升末端，大阳线 → 小实体星线 → 大阴线，第三根收盘穿入第一根实体过半。顶部反转。
- **十字启明星 / 十字黄昏星**：中间星线为十字星时信号更强。
- **三只乌鸦（Three Black Crows）**：上升末端，连续三根阴线，每根收盘低于前一根、开盘位于前一根实体内或附近。强烈顶部反转。
- **三个白兵（Three White Soldiers）**：下降末端，连续三根阳线，每根收盘高于前一根、开盘位于前一根实体内或附近。强烈底部反转。
- **三星（Three Stars）**：三根十字星连续（或近似）出现，多空三次势均力敌。极强反转（按位置分顶/底）。
- **塔形顶 / 塔形底（Tower Top / Bottom）**：多根渐变式反转——上升末端先多根小阳缓涨（塔身）再大阴急跌（塔尖）；下降末端对称。属多根渐变形态，非严格三根。

## 4. 缺口（Gap）

缺口是相邻两根 K 线之间未被交易覆盖的价格区间（**上下沿按极端价位**）。按位置与性质分四类：

- **普通缺口（Common Gap）**：出现在震荡/横盘区，方向意义弱，通常很快回补。**弱信号**。
- **突破缺口（Breakaway Gap）**：突破关键区间/锚点（趋势线、前高前低、横盘边界）时留下且未回补。**趋势启动/推动浪确认的强信号**。
- **持续缺口（Runaway / Measuring Gap）**：趋势中途（常第 3 浪加速段）留下，量度趋势延续。
- **衰竭缺口（Exhaustion Gap）**：趋势末端（常第 5 浪冲刺段）留下，随后快速回补。**衰竭警示**。
- **岛形反转（Island Reversal）**：孤立价格区被两个方向相反的缺口包围（如上升末端：向上衰竭缺口 + 向下突破缺口）。强烈反转信号。

## 4.5 持续形态（Continuation Patterns）

- **上升三法（Rising Three Methods）**：大阳线 → 2–3 根小阴线回撤（每根落在第一根**实体范围**内、收盘不低于第一根开盘）→ 大阳线创新高。持续看涨。
- **下降三法（Falling Three Methods）**：大阴线 → 2–3 根小阳线（落在第一根实体内）→ 大阴线创新低。持续看跌。
- **向上跳空二法（Upside Tasuki Gap）**：跳空大阳 → 次日阴线回补部分缺口（未补完）→ 第三根阳线创新高。持续看涨。
- **向下跳空二法（Downside Tasuki Gap）**：跳空大阴 → 次日阳线回补部分缺口 → 第三根阴线创新低。持续看跌。

## 5. 与波浪的配合（位置决定含义）

- **第 5 浪末端**出现上吊线 / 流星线 / 黄昏星 / 看跌吞没 / 乌云盖顶 / 看跌孕线 / 十字孕线 / 镊子顶 / 三星 / 塔形顶 / 衰竭缺口 → **顶部警示**：见顶概率上升，关注后续 A 浪调整。
- **C 浪末端**出现锤子线 / 倒锤子 / 启明星 / 看涨吞没 / 曙光初现 / 看涨孕线 / 十字孕线 / 镊子底 / 塔形底 / 蜻蜓十字星 → **底部信号**：调整见底概率上升。
- **突破缺口 / 岛形反转 / 三个白兵（或三只乌鸦）出现在推动浪起点** → **推动浪启动确认**。
- **上升三法 / 下降三法 / 向上/向下跳空二法 / 持续缺口出现在第 3 浪加速段** → **趋势持续确认**。
- **十字星 / 纺锤线 / 普通缺口**出现在中段或无明确浪位 → 弱信号，仅计 1 分或不计分。

**铁律**：蜡烛图**只确认、不裁决**——即使出现顶/底形态，只要波浪 Rule 未触发失效，不得据此改判数法；方向矛盾时只在「蜡烛图信号」因子计 0 分并披露。

## 7. 短期执行规则（Execution）

> 执行层受三条铁律约束：**永不否决波浪数法、永不覆盖波浪失效价位、方向必须与主要趋势一致**。蜡烛图只负责「什么时候动手、什么时候了结、更紧的止损放哪」；数法有效性与失效价位的最终裁决权仍在波浪。

### 7.1 三条执行闸门

1. **方向闸门**：执行信号方向必须与主要趋势（数浪方向）一致。上升趋势中：看涨信号 = 买入触发，看跌信号 = 了结多头，**不是做空**；下降趋势对称。与主要趋势相反的中段信号一律不触发。
2. **验证闸门**：反转形态须经**次日验证**——上吊线：次日开市低于实体，或次日阴线收市低于其阴线实体…；倒锤子：次日跳空高开超过实体，或次日阳线收于高位；十字星/十字黄昏星：需 1–2 根后续确认。未验证的反转形态只打分、不触发买卖。
3. **落位闸门**：信号必须落在**有效价位区**——趋势线、前高/前低、50%/38%/62% 回撤位、斐波那契共振区。漂浮在中段、无价位依据的信号不触发执行。

### 7.2 买点 / 卖点

- **买点**：上升趋势中，看涨反转信号落在支撑位且次日验证通过 → 触发价位 = 该支撑位或信号 K 线收盘价。
- **卖点/了结**：上升趋势中，看跌反转信号落在阻力位且验证通过 → 了结多头。**顶部信号是了结信号，不是做空凭据**。

### 7.3 双层止损

1. **形态止损**：设在触发信号极值**外侧**（多头：锤子低点/吞没低点/启明星低点/趋势线之下；空头对称）。更紧、更早离场。
2. **波浪失效价位**：最终裁决，永不覆盖。
3. **取舍**：形态止损**只能比失效价位更紧**；若落在失效价位外侧（更远），改用失效价位。禁止以形态止损放宽失效价位。

### 7.4 假突破

- **破高反跌（Bull Trap）**：向上假突破阻挡位、收盘收回阻挡之下 → 了结多头/做空参考；止损设假突破新高之上。
- **破低反涨（Bear Trap）**：向下假突破支撑位、收盘收回支撑之上 → 买入参考；止损设当日低点之下。
- 假突破方向与主要趋势一致时信号更强。

### 7.5 极性转换（Polarity）

旧支撑跌破后转**新阻挡**、旧阻挡突破后转**新支撑**，用于推演下一目标位与防守位（如突破 1.85 后旧阻挡转支撑，下一支撑 1.65 = 50% 回撤 + 旧阻挡转支撑）。

### 7.6 背离佐证

- **摆动指数背离**：价创新高而 RSI/随机/动力未创新高 = 看跌背离；价创新低而指标未创新低 = 看涨背离（RSI 14 / 随机 9 / 动力 10，本地计算）。
- **成交量背离（OBV）**：价涨而 OBV 走平/下降 = 买力减弱；价跌而 OBV 走平/上升 = 卖压减弱。
- 背离方向与数浪方向矛盾时，「蜡烛图信号」因子计 0 分并披露，不改数法。

## 8. 与八因子的对应关系

| 蜡烛图证据 | 落入的因子 | 分值口径 |
| --- | --- | --- |
| 强反转组合（双/三根标准形态 + 反向长影线 + 放量） | **蜡烛图信号** | 2 |
| 单根 Pinbar / 弱十字星 / 普通缺口 | 同上 | 1 |
| 无信号，或与数浪方向相反 | 同上 | 0 |

蜡烛图**不产生独立因子**，也不进入「结构完整度」以外的任何加权项；`CS7–CS12` 属于执行层规则，只影响交易计划的触发与止损，不影响因子分。
