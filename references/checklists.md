## 1. 推动浪校验

> **本文件定位**：校验清单核心文件之一，供 `references/workflow.md（第 2 步）` 的 Rule Check / Guideline Check 与 `references/workflow.md（第 3 步）` 的 Rule/Guideline 复核逐条执行。只校验被标为"推动浪（Impulse）"的候选方案（含延长浪与失败浪），不重新数浪、不展开理论；发现违反时退回第 2 步 修正。
>
> **前置依赖**：术语见 `references/terminology.md`，推动浪识别见 `references/patterns.md（推动浪）`，规则见 `references/rules.md`，概率经验见 `references/guidelines.md`，复核接口见 `references/workflow.md（第 3 步）`。

### 1. 使用说明与输入

#### 1.1 输入

本清单以 02 数浪移交的"候选方案标注 + 该方案的 Rule Check / Guideline Check 结果"为输入（02 第 7.1 节）。每个方案独立使用一张清单。

#### 1.2 使用前提

- 先确认方案确实被标为**推动浪（Impulse）**（references/rules.md R1、R2、R21）；
- 调整浪（A-B-C / W-X-Y）→ 转交同目录 `references/checklists.md（调整浪）`；
- 楔形（含重叠的驱动浪、终结三角形及其作用浪例外）→ 转交同目录 `references/checklists.md（楔形）`。

#### 1.3 校验原则

- 本清单只做"检查员"：逐条勾选后输出结论（通过/不适用/违反），不得现场修改数法；
- 结论三态：**通过 / 不适用 / 违反**。"不适用"包括两类——①检查项与方案无关；②前提未证实（数据不足、结构未完成），两种情形都必须在备注写明原因；前提未证实的不适用由变更日志跟踪，条件满足后经 03 验证数浪复核更新结论。本清单结论态仅三态，不存在模糊判定态；涉及清单间裁定的检查项判"不适用"，最终结论以承接清单为准。
- 任何 Rule 违反即方案失效，退回第 2 步 修正（references/rules.md R19）；
- Guideline 只计分，不影响合法性（references/guidelines.md G21）。

### 2. 结构身份与级别校验

- [ ] **C2-1 五浪结构**（Rule，references/rules.md R1）
  - 判定标准：该推动区间的 1-2-3-4-5 子结构是否有证据、1/3/5 是否与该推动整体同向？已核验 → 通过；进行中或内部资料不足 → 不适用（前提未证实，列复核条件）；已完成结构有反例却仍标普通推动 → 违反。只有六个端点不能代替内部检查；该推动若属于更大调整的 A/C，不因其与再上一级趋势反向而否定（references/rules.md R31）。
- [ ] **C2-2 身份一致**（Rule，references/rules.md R2、R21）
- 判定标准：该结构是否被误数成三浪调整？驱动浪是否确为五浪展开？确为五浪推动 → 通过；实为楔形（Diagonal，属驱动浪但非推动浪）→ 不适用（已转交 `references/checklists.md（楔形）`，结论以楔形清单为准）；实为三浪调整或非驱动浪 → 违反（references/rules.md R2、R21；references/terminology.md 1.1.4、1.3.4）。
- [ ] **C2-3 级别嵌套**（Rule，references/rules.md R4；references/terminology.md 1.2.3）
  - 判定标准：已观察的子结构是否符合父浪身份，父子区间与端点衔接是否一致，是否把父浪与其子浪混排为同级？可核验且自洽 → 通过；未走完或分辨率不足 → 不适用（前提未证实，备注注明区间、待补资料与复核条件）；已有跨级混排、端点矛盾或不符合父浪身份的结构证据 → 违反。完整父浪检查首尾闭合，进行中父浪不预补尾段（references/rules.md R34）。仅绝对级别名称待定不自动违反 R4。
- [ ] **C2-4 计数等效**（Rule，references/rules.md R18；references/terminology.md 1.3.7）
  - 判定标准：延长浪产生的九浪序列是否被正确视为一个五浪，而不是拆成两个同级推动浪？未拆分 → 通过；拆分 → 违反。
- [ ] **C2-5 父级框架声明与依据**（Rule，references/rules.md R31；references/terminology.md 1.2.6）
  - 判定标准：是否声明父级形态与位置、前序依据及尚缺证据？声明完整，或多个暂定框架及复核条件均明确 → 通过（仅指声明要求，不等于父级身份已确认）；遗漏框架或明知前序缺失仍宣称唯一确认 → 违反该流程要求。资料未能证实的具体结构项分别判不适用，不凭换周期或改级别名称判其通过。

本节只细化既有 R1/R4/R31 的证据检查，不新增理论规则与分数。主备是否有实质区别交由 C6-3；父级身份待确认不妨碍分别检查已经可见的局部结构。

### 3. 推动浪三铁律校验

- [ ] **C3-1 第 2 浪回撤**（Rule，references/rules.md R5）
  - 判定标准：上升推动中，第 2 浪最低点是否越过第 1 浪起点？下降推动中，第 2 浪最高点是否越过第 1 浪起点？未越过 → 通过；越过 → 违反。
- [ ] **C3-2 第 3 浪长度**（Rule，references/rules.md R6）
  - 判定标准：第 3 浪价格区间是否同时小于第 1 浪与第 5 浪（按绝对价格区间比较，不计时间）？否 → 通过；是 → 违反；第 3 浪尚未完成且当前区间已小于第 1 浪 → 不适用（结构性约束：若第 3 浪完成后短于第 1 浪，第 5 浪长度须不超过第 3 浪；不能在第 5 浪缺失时提前判 R6 违反，当前不得判通过；第 5 浪未完成时同理）。
- [ ] **C3-3 第 4 浪重叠**（Rule，references/rules.md R7）
  - 判定标准：上升推动中，第 4 浪最低点是否跌破第 1 浪最高点？下降推动中，第 4 浪最高点是否升破第 1 浪最低点？未进入 → 通过；进入 → 不适用（重叠存在，转 C3-5，由楔形清单裁定是否合法）。
- [ ] **C3-4 极端价位判定**（Rule，references/rules.md R20）
  - 判定标准：C3-1 至 C3-3 是否全部按含影线的最高/最低价（盘中极端点）判定？盘中满足对应规则比较符即构成违反、不以收盘确认？是 → 通过；以收盘价替代 → 违反。
- [ ] **C3-5 重叠例外转交**（Rule，references/rules.md R8、R11）
  - 判定标准：C3-3 未出现重叠 → 不适用（与方案无关）；出现重叠且已转交 `references/checklists.md（楔形）` 检查 R8、R9、R10、R11 → 不适用（已转交，最终结论以楔形清单为准，本清单不直接判 C3-3 违反）；出现重叠但未转交 → 违反（references/rules.md R8、R11）。

### 4. 延长浪与失败浪校验

- [ ] **C4-1 延长浪内部**（Rule，references/rules.md R26）
  - 判定标准：延长浪（第 1/3/5 浪中的延长）内部是否为满足 R5、R6、R7 的完整五浪？是 → 通过；内部未走完 → 不适用（前提未证实，备注注明待复核子浪）；内部出现重叠/第 3 浪最短/第 2 浪越起点 → 违反。
- [ ] **C4-2 失败浪判定前提**（Rule，references/rules.md R17、R29）
  - 判定标准：第 5 浪内部是否已确认完整五浪结构、且终点未超过第 3 浪终点？条件齐备且未提前标失败 → 通过；结构未完成 → 不适用（前提未证实，不得判通过，也不得提前判失败）；结构未完成却标失败 → 违反；无失败浪 → 不适用（与方案无关）。备注：结构未完成即标失败是常见错误（references/guidelines.md G12）；该项为 Rule 检查，G12 不再单独计分。
- [ ] **C4-3 失败浪失效条件**（Rule，references/rules.md R29）
  - 判定标准：无失败浪 → 不适用；价格未突破第 3 浪终点（按极端价位）→ 通过（失败假设仍有效）；价格已突破第 3 浪终点 → 方案已标记失败假设失效（如已切换方案）→ 通过；已突破却仍标失败 → 违反（references/rules.md R29）。

### 5. 指导原则校验（概率加分项，不影响合法性）

- [ ] **G-1 交替**（Guideline，references/guidelines.md G1）
  - 判定标准：第 2 浪与第 4 浪调整类型是否不同（陡直型 vs 横向型）？是 → 命中 +1；否 → 违反 −1。
- [ ] **G-2 等长**（Guideline，references/guidelines.md G2）
  - 判定标准：第 3 浪延长时，第 5 浪长度是否落在第 1 浪长度的 0.618–1.0 倍区间（含端点，按极端价位计）？是 → 命中 +1；区间外 → 未命中 0；第 3 浪未延长 → 不适用 0。（本条目无 −1 状态，长度不符不构成违反。）
- [ ] **G-3 通道目标**（Guideline，references/guidelines.md G3）
  - 判定标准（量化口径，通道宽度 W = 上轨与下轨的垂直距离）：a) 第 5 浪终点（极端价位）与上轨距离 ≤ 0.382×W → 命中；b) 失败浪终点与下轨距离 ≤ 0.382×W → 命中。满足任一 → 命中 +1；均不满足 → 未命中 0；未建立通道或无第 5 浪/失败浪 → 不适用 0。（本条目无 −1 状态。）
  - 阈值注册于 `references/defaults.md` D20；调整须同步 D20 并在报告中披露。
- [ ] **G-4 通道突破处理**（Guideline，references/guidelines.md G4）
- 判定标准：通道边界被决定性突破（连续 2 根收盘价位于边界外侧，references/workflow.md 第 5 步第 2 节（失效价位监控）默认口径）后，价格是否出现可重画通道的新摆动结构（新的同向摆动点形成，可重新连接基线）？是 → 命中 +1（按 G4：重画/复查通道，数法不自动失效）；否 → 未命中 0（通道假设失效，触发数法复查）；未突破 → 不适用 0。（本条目无 −1 状态。）
- [ ] **G-5 延长频率**（Guideline，references/guidelines.md G9）
  - 判定标准：一个推动浪是否被数出两个延长浪？否 → 命中 +1；候选性延长（尚未确认）→ 未命中 0；确认两个延长 → 违反 −1。
- [ ] **G-6 双回撤**（Guideline，references/guidelines.md G11）
- 判定标准：第 5 浪延长确认后，当前价格是否已走出第一轮回撤并出现反弹（价格离开第一轮回撤终点 ≥ 2 根当前周期 K 线收盘）？是 → 命中 +1（双回撤结构迹象，第二轮回撤待跟踪）；否 → 未命中 0；无延长 → 不适用 0。（本条目无 −1 状态。）
- [ ] **G-7 失败浪位置与处理**（Guideline，references/guidelines.md G22）
  - 判定标准（量化口径，分支互斥，最多 +1 分）：趋势末端 = 满足以下任一——a) 第 5 浪长度达到第 1 浪长度的 0.618–1.618 倍目标区（references/fibonacci.md 第 1.1 节）；b) 第 5 浪终点位于通道上轨 0.382×W 范围内（本清单 G-3 口径）。弱势环境 = 第 5 浪长度 < 第 3 浪长度的 0.618 倍且未突破通道上轨。
    - 分支 1：失败浪处于趋势末端或弱势环境 → 命中 +1（"优先检视"要求不适用）；
    - 分支 2：失败浪处于趋势中段（不满足分支 1）→ 方案已优先检视延长浪或级别误判 → 命中 +1；未检视 → 未命中 0；
    - 无失败浪 → 不适用 0。（本条目无 −1 状态。）
**评分规则**：每条 Guideline 按各自判定标准给出结论：命中 +1 / 未命中 0 / 明确违反 −1（仅当该条目判定标准定义了违反条件时，如 G-1、G-5）；未定义违反条件的条目（G-2、G-3、G-4、G-6、G-7）只有命中与未命中两态，不得自行加 −1。得分汇总进入概率排序（references/guidelines.md G21；本清单即 references/guidelines.md G21 所指评分细则的落地处）。斐波那契比率条目（回撤/延伸/共振，references/guidelines.md G5–G8）转交同目录 `references/checklists.md（斐波那契）`；作用浪例外（终结三角形中的 1/3/5，references/guidelines.md G13）属楔形范畴，由 `references/checklists.md（楔形）` 承接，不在本清单校验。

### 6. 输出完整性校验

- [ ] **C6-1 级别声明**（Rule，references/rules.md R22）
  - 判定标准：该方案是否声明了分析级别（含标注符号与当前浪段）？是 → 通过；否 → 违反。
- [ ] **C6-2 标注规范**（Rule，references/rules.md R23；references/terminology.md 1.2.4）
  - 判定标准：同一张图是否混用两套标注符号（数字/字母）？未混用 → 通过；混用 → 违反。
- [ ] **C6-3 主备方案**（Rule，references/rules.md R24）
  - 判定标准：是否同时给出主方案与至少一个替代方案，且各自独立标注失效价位？是 → 通过；未标明防御模式的单方案 → 不完整；明确单方案原因且强制观望时按 R24 防御模式检查。共享规则边界不等于省略各方案独立判定，须披露各自成立条件。仅换浪级名称、或一个宽泛解释包含另一个解释时，检查是否按 R24 显著披露非独立解释及理由；未披露不能按两个独立方案验收。前序与后续预期的比较记录随方案说明交接，不另加分。
- [ ] **C6-4 禁止预标未完成结构**（Rule，references/rules.md R34；判据见 09 D39；通用条目，适用全部形态）
  - 判定标准：数浪与绘图是否只实线标注已确认完成的子浪/浪段（终点为 swings 摆动点且其后出现反向摆动），进行中段用虚线+"进行中"、未预标未发生的子浪？是 → 通过；预标未完成结构 → 违反。

#### 7.2 结论规则

- **校验通过**：全部 Rule 通过 → 结论表（含 Guideline 得分）移交 02 数浪用于概率排序（02 第 5–6 节），并随方案移交 03 验证数浪复核（03 验证数浪第 3–4 节）；
- **校验不通过**：任一 Rule 违反 → 标记"规则失效"，结论表退回第 2 步（references/rules.md R19）；主方案失效时检查替代方案是否可启用；
- Guideline 得分汇总进入概率排序，不影响合法性（references/guidelines.md G21）。

## 2. 楔形校验

> **本文件定位**：校验清单之一，专用于楔形（前置三角形 Leading Diagonal / 终结三角形 Ending Diagonal）候选方案的逐条校验；是"第 4 浪与第 1 浪重叠例外条款"（R8、R9、R10、R11）的唯一落地检查表。不重新数浪、不展开理论；发现违反时退回第 2 步 修正。
>
> **前置依赖**：术语见 `references/terminology.md`，楔形识别见 `references/patterns.md（楔形）`，规则见 `references/rules.md`，概率经验见 `references/guidelines.md`，复核接口见 `references/workflow.md（第 3 步）`。

### 1. 使用说明与输入

#### 1.1 启用条件

本清单在以下两种情况下启用：

1. 02 数浪直接将方案标为楔形；
2. 推动浪校验中发现第 4 浪与第 1 浪重叠，转交本清单核查（references/rules.md R8；`references/checklists.md（推动浪）` 第 3 节 C3-5）。

#### 1.2 使用前提

- 先确认楔形属于**驱动浪（Motive Wave）**而非调整浪（references/rules.md R21、R2；references/terminology.md 1.1.4、1.3.4）；
- 调整浪三角形（A-B-C-D-E）→ 转交 `references/checklists.md（调整浪）`，不在本清单校验。

#### 1.3 校验原则

- 本清单只做"检查员"：逐条勾选后输出结论（通过/不适用/违反），不得现场修改数法；
- 结论三态：**通过 / 不适用 / 违反**。"不适用"包括两类——①检查项与方案无关；②前提未证实（数据不足、结构未完成），两种情形都必须在备注写明原因；前提未证实的不适用由变更日志跟踪，条件满足后经 03 验证数浪复核更新结论。本清单结论态仅三态，不存在模糊判定态；涉及清单间裁定的检查项判"不适用"，最终结论以承接清单为准。
- 楔形的位置或子浪结构任一不符，即不得享受重叠例外（references/rules.md R11）；
- 重叠例外被否决时，推动浪清单的 C3-3 同步恢复为"违反 R7"判定（references/rules.md R11、R19）。

### 2. 位置校验

- [ ] **D2-1 前置三角形位置**（Rule，references/rules.md R9）
  - 判定标准：该楔形是否只出现在第 1 浪或 A 浪位置？是 → 通过；否 → 违反。
- [ ] **D2-2 终结三角形位置**（Rule，references/rules.md R10）
  - 判定标准：该楔形是否只出现在第 5 浪或 C 浪位置？是 → 通过；否 → 违反。
- [ ] **D2-3 位置不符处理**（Rule，references/rules.md R11）
  - 判定标准：出现在其他位置（如第 2 浪、第 3 浪内部）的"楔形"，是否被标记为违反 R7？是 → 通过（处理正确）；否（仍享受例外）→ 违反。

### 3. 子浪结构校验

- [ ] **D3-1 前置三角形结构**（Rule，references/rules.md R9）
  - 判定标准：内部是否为 5-3-5-3-5 结构（1、3、5 子浪为五浪，2、4 子浪为三浪）？是 → 通过；内部子浪结构未确认（数据不足）→ 不适用（前提未证实，备注注明待复核子浪）；否 → 违反。备注：假设数据**显式设定**内部结构时可判"通过（数据设定）"并注明"非真实复核"；未逐子浪展示内部结构时按"不适用（前提未证实）"。
- [ ] **D3-2 终结三角形结构**（Rule，references/rules.md R10）
  - 判定标准：内部是否为 3-3-3-3-3 结构（五个子浪全部为三浪）？是 → 通过；内部子浪结构未确认（数据不足）→ 不适用（前提未证实，备注注明待复核子浪）；任一子浪为五浪 → 违反。备注：终结三角形中的 1/3/5 是作用浪但以调整形态（三浪）展开（references/guidelines.md G13），误标为推动浪即子浪结构不符，已由本项覆盖，不单独计分；假设数据**显式设定**内部结构时可判"通过（数据设定）"，未逐子浪展示时按"不适用（前提未证实）"。
- [ ] **D3-3 子浪数量**（Rule，references/rules.md R1、R21）
  - 判定标准：五个子浪是否齐全？是否被数成其他数量（如四浪、六浪）？五子浪齐全 → 通过；数量不符 → 违反。
### 4. 重叠与极端价位校验

- [ ] **D4-1 重叠合法性**（Rule，references/rules.md R7、R8）
  - 判定标准：第 4 浪与第 1 浪的重叠是否确实存在，且方案已按楔形申请豁免？重叠不存在 → 不适用；重叠存在、已申请豁免 → 通过（豁免是否成立由 D2/D3 在本表内裁决，非转交）；重叠存在、未申请豁免且未按 R7 违规处理 → 违反；重叠存在、未申请豁免但已按 R7 违规处理 → 通过（无需本清单介入）。
- [ ] **D4-2 边界判定**（Rule，references/rules.md R20）
  - 判定标准：楔形通道边界（收敛/扩张）是否按极端价位（含影线、盘中极端点）画定，而非按收盘价？是 → 通过；否 → 违反。
- [ ] **D4-3 越界重叠**（Rule，references/rules.md R11）
  - 判定标准：不符合 R9/R10 位置或子浪结构的重叠，是否仍按违反 R7 处理？是 → 通过（处理正确）；否 → 违反。

- [ ] **C3-1 锯齿形**（Rule，references/rules.md R12；references/terminology.md 1.4.3）

- [ ] **C3-2 双/三锯齿形**（Rule，references/rules.md R13；references/terminology.md 1.4.4、1.4.5）
  - 判定标准：W、Y（及 Z）是否各为锯齿形并由 X 浪连接？符合 → 通过；组成浪内部结构未确认 → 不适用（前提未证实，备注注明待复核子浪）；任一组成浪非锯齿形 → 违反；非复合锯齿 → 不适用（与方案无关）。

### 4. 平台形校验

- [ ] **C4-1 平台形**（Rule，references/rules.md R14；references/terminology.md 1.4.6）
  - 判定标准：A 浪与 B 浪是否为三浪，C 浪是否为五浪（3-3-5）？符合 → 通过；C 浪未完成 → 不适用（前提未证实，备注注明待复核子浪）；任一子浪数不符 → 违反；非平台形 → 不适用（与方案无关）。
- [ ] **C4-2 变体分类**（Rule，references/rules.md R28；references/terminology.md 1.4.7）
  - 判定标准（三变体分类条件必须同时满足；量化口径以 0.382×A 长度界定"大致/略/明显"，项目默认并须披露，见 references/defaults.md D8）：
    - 规则平台形：|B 终点 − A 起点| ≤ 0.382×A 长度，且 C 终点低于 A 终点、超出幅度 ≤ 0.382×A 长度；
    - 扩张平台形：B 终点 > A 起点，且 C 终点低于 A 终点 − 0.382×A 长度（明显超出）；
    - 奔走平台形：B 终点 > A 起点，且 C 终点 > A 终点（未到达）。
  - 所标变体的两个条件均满足 → 通过；B 条件已满足但 C 终点条件未决（C 未完成）→ 不适用（前提未证实，备注注明待 C 完成后复核）；任一条件不满足 → 违反；非平台形 → 不适用（与方案无关）。

### 5. 三角形与联合形校验

- [ ] **C5-1 三角形结构**（Rule，references/rules.md R15、R27；references/terminology.md 1.4.8）
  - 判定标准：是否由 A-B-C-D-E 五个子浪构成，五个子浪全部为三浪（不得出现五浪子浪，references/rules.md R27），子浪 4 与子浪 1 重叠？符合 → 通过；D/E 未完成或子浪结构未确认 → 不适用（前提未证实，备注注明待复核子浪）；子浪数、子浪结构或重叠任一不符 → 违反；非三角形 → 不适用（与方案无关）。备注：假设数据**显式设定**内部结构（如注明 3-3-3-3-3 已设定）时可判"通过（数据设定）"并在备注注明"非真实复核"；假设数据未逐子浪展示内部结构时按"不适用（前提未证实）"。
- [ ] **C5-2 三角形位置**（Rule，references/rules.md R15；references/guidelines.md G19）
  - 判定标准：是否作为独立形态出现在第 2 浪位置？否 → 通过；是 → 违反（应优先检视为奔走型调整、联合形组成部分或其他数法，references/guidelines.md G19）；非三角形 → 不适用。
- [ ] **C5-3 联合形**（Rule，references/rules.md R16、R13）
  - 判定标准：组成形态是否均为调整形态并经 X 连接？两个锯齿形直接相连是否被错误标成联合形而非双锯齿形？符合 → 通过；组成含非调整形态、无 X 连接、或双锯齿误标联合形 → 违反；非联合形 → 不适用（与方案无关）。备注：假设数据**显式设定**组成形态时可判"通过（数据设定）"并注明"非真实复核"；未逐子浪展示组成内部结构时按"不适用（前提未证实）"。

## 4. 斐波那契校验

> **本文件定位**：校验清单之一，专用于比率目标（回撤、延伸、比率关系）与共振区（Confluence）的计算基准、刻度与独立性的逐条校验；是 references/guidelines.md G5–G8 与 `references/fibonacci.md` 的落地检查表。不重新数浪、不展开理论；发现计算错误时退回第 2 步 修正。
>
> **前置依赖**：术语见 `references/terminology.md`，比率表与公式见 `references/fibonacci.md`，规则见 `references/rules.md`，概率经验见 `references/guidelines.md`，复核接口见 `references/workflow.md（第 3 步）`。

### 1. 使用说明与输入

#### 1.1 输入

本清单以 02 数浪输出的"各方案关键比率目标 + 共振区"为输入（02 第 3 节；比率表以 `references/fibonacci.md` 为准，50% 刻度说明见 references/guidelines.md G5 注）。

#### 1.2 校验原则

- 比率目标属于 Guideline（G5–G8）：计算错误只影响概率排序，**不使数法失效**（references/guidelines.md G21）；
- 但计算基准错误会导致目标区失真，必须退回第 2 步 修正后重新评分（references/guidelines.md G21）；
- 本清单只做"检查员"：发现错误时退回第 2 步，不现场改数；结论三态（通过/不适用/违反）——"不适用"包括检查项与方案无关或数据不足/前提未证实，须在备注写明原因；前提未证实的不适用由变更日志跟踪，条件满足后经 03 验证数浪复核更新结论。

### 2. 基准浪校验

  - 判定标准：回撤比率是否以"被回撤浪的极端价位区间"为基准计算——上升回撤目标 = 被回撤浪终点 − 长度×率，长度 = |终点 − 起点|（如第 1 浪终点→起点、A 浪范围）？是 → 通过；基准浪选错（如用第 2 浪起点代替第 1 浪起点）→ 违反。
- [ ] **F2-2 延伸基准**（Guideline，references/fibonacci.md 第 2.2 节；references/guidelines.md G6）
- 判定标准：延伸目标是否以"前置推动浪的完整长度"为基准、自**目标浪起点**投射（如第 5 浪目标从第 4 浪终点/第 5 浪起点起算）？是 → 通过；基准浪不完整或投射起点错误 → 违反。
- [ ] **F2-3 比率关系基准**（Guideline，references/fibonacci.md 第 1 节；references/guidelines.md G7）
  - 判定标准：C/A 是否用 A 浪长度、5/1 是否用第 1 浪长度、B/A 是否用 A 浪长度？对应正确 → 通过；张冠李戴 → 违反。
- [ ] **F2-4 极端价位**（Rule，references/rules.md R20）
  - 判定标准：所有长度计算是否按含影线的最高/最低价（盘中极端点）取值，不以收盘/开盘价计算？是 → 通过；以收盘/开盘价取值 → 违反。

### 3. 回撤比率校验

- [ ] **F3-1 常用刻度**（Guideline，references/guidelines.md G5）
  - 判定标准：回撤目标是否仅使用 38.2%、50%、61.8% 三档刻度（未使用 45%、70% 等非常规刻度）？仅使用常规三档 → 通过；使用非常规刻度 → 违反。备注：50% 是经验值，非严格斐波那契比率（references/guidelines.md G5），此条为说明性备注，不作为检查条件。
- [ ] **F3-2 形态差异**（Guideline，references/guidelines.md G5）
- 判定标准：锯齿形整体回撤（C 终点）是否优先取深档（50%–61.8%）、平台形整体回撤是否优先取浅档（38.2%–50%）？相符 → 命中 +1；不符 → 未命中 0；不适用 → 0。锯齿形 B 浪回撤的浅档（38.2%–50%）由 F5-2 承接，不在本项重复计分。（无 −1 状态。）

### 4. 延伸与等长校验

- [ ] **F4-1 延伸刻度**（Guideline，references/fibonacci.md 第 1 节；references/guidelines.md G6）
- 判定标准：延伸目标是否使用 1.618、2.618 倍数（自目标浪起点投射）？是 → 通过；使用其他倍数或投射方式错误 → 违反。
- [ ] **F4-2 等长**（Guideline，references/fibonacci.md 第 2.3 节；references/guidelines.md G2）
  - 判定标准：等长目标是否按"直接复制基准浪价格区间、平移到目标浪起点"计算？且前提浪选择正确——第 3 浪延长时 5≈1、锯齿形中 C≈A？计算方式与前提均正确 → 通过；任一错误 → 违反。

### 5. 比率关系校验

- [ ] **F5-1 常见比率**（Guideline，references/fibonacci.md 第 1 节；references/guidelines.md G7）
  - 判定标准：C/A、5/1、B/A 之间是否按 0.618、1.0、1.618 等关系核对？核对完整 → 命中 +1；遗漏或错用 → 未命中 0。（无 −1 状态。）
- [ ] **F5-2 平台形 B 浪**（Guideline，references/guidelines.md G7）
- 判定标准：平台形 B 浪终点是否达到或接近 A 浪起点（B 终点 ≥ A 起点 − 0.382×A，按极端价位；对应"B 回撤 A 接近或超过 100%"，项目默认口径，须披露）？是 → 命中 +1；否 → 未命中 0；非平台形 → 不适用 0。（无 −1 状态。）
- [ ] **F5-3 三角形目标**（Guideline，references/fibonacci.md 第 2.4 节；references/guidelines.md G15）
  - 判定标准：收缩三角形之后的第 5 浪目标是否按"最宽距离 = |B 子浪终点 − A 子浪起点|，平移到 E 子浪终点"计算？是 → 通过；基准或平移错误 → 违反；非收缩三角形 → 不适用。

### 6. 共振区校验

- [ ] **F6-1 共振定义**（Guideline，references/fibonacci.md 第 3 节；references/guidelines.md G8）
  - 判定标准：是否至少有两个独立比率目标落在同一价格区间（误差带 = 当前价格的 ±1%，项目默认口径，须在报告中披露）？是 → 命中 +1；仅一个目标或区间不相交 → 未命中 0；未标注共振区 → 不适用 0。（无 −1 状态。）
- [ ] **F6-2 独立性**（Guideline，references/fibonacci.md 第 3 节；references/guidelines.md G8）
  - 判定标准：共振区是否由不同推导链重合形成？**推导链定义** =（基准浪，计算类型）二元组：同一基准浪的多个倍数（如 1.618× 与 2.618× 均以第 1 浪为基准）属同链，不得重复计数；基准浪不同（如第 1 浪基准 vs 第 3 浪基准）或计算类型不同（延伸 vs 回撤）即属不同链；前级结构点为独立链。不同链重合 → 通过；同链倍数被重复计数 → 违反。
- [ ] **F6-3 极端价位**（Rule，references/rules.md R20）
  - 判定标准：共振区的上/下边界是否按极端价位（含影线）标注？是 → 通过；按收盘价标注 → 违反。
- **F6-4 用途说明（自动派生，references/guidelines.md G8）**：F6-1 与 F6-2 均通过（共振区由 ≥2 个独立推导链重合形成）→ 自动命中 +1（共振区作为目标/失效/入场参考时可信度提高）；未形成共振区 → 不适用 0。不设独立文案检查。

**评分规则**：Rule 条目（F2-4、F6-3）只出通过/不适用/违反（比率计算一般可直接判定，数据不足时按"不适用（前提未证实）"处理）；Guideline 条目按各自判定标准给出命中 +1 / 未命中 0 / 明确违反 −1（仅当判定标准定义了违反条件时，如 F2-1 至 F2-3、F3-1、F4-1、F4-2、F5-3、F6-2）。得分汇总进入概率排序的"斐波那契共振"指标（references/guidelines.md G21）。

### 8. 实战示例：第 5 浪延伸目标 vs 等长目标

**02 提交（假设）**：上升趋势，日线级别 Intermediate。主方案 = 第 3 浪延长，第 5 浪目标 = 1.618× 第 1 浪长度；替代方案 = 第 5 浪约等于第 1 浪（G2 等长）。已知：第 1 浪 100→160（长度 60），第 2 浪终点 130。

**第 1 步 基准浪校验**：

| 检查项 | 结论 | 备注 |
| --- | --- | --- |
| F2-1 回撤基准 | 不适用 | 本方案无回撤目标 |
| F2-2 延伸基准 | **违反** | 02 用 160−130=30 作为"第 1 浪长度"（误用第 2 浪终点 130 代替第 1 浪起点 100）；正确长度应为 60（references/fibonacci.md 第 2.2 节） |
| F2-3 比率关系基准 | 违反 | 同 F2-2，5/1 比率基准错误 |
| F2-4 极端价位 | 通过 | 按极端价位取值（references/rules.md R20） |

**第 2 步 延伸刻度校验（主方案）**：

| 检查项 | 结论 | 备注 |
| --- | --- | --- |
| F4-1 延伸刻度 | 违反 | 倍数 1.618 本身正确，但基于错误基准长度 30 投射：目标 130+30×1.618=178.5；修正后 130+60×1.618=227.08，目标区显著变化 |

**第 3 步 共振校验（主方案）**：

| 检查项 | 结论 | 备注 |
| --- | --- | --- |
| F6-1 共振定义 | 未命中 0 | 声明的"共振区 175–180"仅含 1.618× 目标 178.5，无第二个独立目标 |
| F6-2 独立性 | **违反** | 02 将 1.618× 与 2.618×（同一第 1 浪基准派生）均计入共振计数——同链倍数不得重复计数（references/guidelines.md G8） |

**第 4 步 等长校验（替代方案）**：

| 检查项 | 结论 | 备注 |
| --- | --- | --- |
| F4-2 等长 | 通过 | 第 5 浪目标按第 1 浪长度 60 复制平移（references/fibonacci.md 第 2.3 节；references/guidelines.md G2） |

**第 5 步 结论**：主方案因 F2-2/F2-3 基准错误、F6-2 独立性违规 → **退回第 2 步 修正**（重新以第 1 浪长度 60 计算目标并重建共振区，references/guidelines.md G21）；替代方案等长目标基准正确，可继续进入概率排序。

**第 6 步 完整结论表（节选）**：

| 检查项 | 类型 | 来源编号 | 计算基准 | 结论 | 备注 |
| --- | --- | --- | --- | --- | --- |

**小结**：斐波那契校验 = 基准浪（F2，含极端价位 R20）→ 回撤刻度（F3）→ 延伸与等长（F4）→ 比率关系（F5）→ 共振区（F6：重合、独立性、边界、用途）→ 结论与交接。底线：基准错、刻度错、共振不独立，一律退回第 2 步；但比率错误不使数法失效，只改概率权重。

## 5. 失效校验

> **本文件定位**：校验清单之一，专用于每个方案失效价位（规则失效 + 结构失效）的逐条校验；`references/rules.md` 第 6 节（规则失效价位） 节已指定本文为规则失效价位与结构失效价位的落地处。不重新数浪、不展开理论；失效价位缺失或不可执行时退回第 2 步 补充。
>
> **前置依赖**：术语见 `references/terminology.md`（references/terminology.md 1.7.1），失效价位分类见 `references/rules.md` 第 6 节（规则失效价位），概率经验见 `references/guidelines.md`（G21、G25），复核接口见 `references/workflow.md（第 3 步）` 第 5 节，落库模板见 `assets/失效追踪_invalidation.md`。

### 1. 使用说明与输入

#### 1.1 输入

本清单以 02 数浪输出的"各方案失效价位清单"为输入，区分两类失效价位（references/rules.md 第 6 节（规则失效价位））：

- **规则失效价位（Rule-based Invalidation）**：由具体结构规则（R5、R7、R9、R10、R11、R15、R29 等）推导，价格满足对应规则的比较条件即方案失效（references/rules.md R19 为失效后处理规则，不充当失效价位来源）；
- **结构失效价位（Structural Invalidation）**：预期结构未形成等方案前提判断，不由硬性规则推导（references/rules.md 第 6 节（规则失效价位）注）。

#### 1.2 校验原则

- 本清单只做"检查员"：失效价位缺失、模糊或不可执行时，退回第 2 步 补充，不现场修改（references/rules.md R19、R20）；
- 每个方案独立使用一张清单；结论三态（通过/不适用/违反）——"不适用"包括检查项与方案无关或数据不足/前提未证实，须在备注写明原因；前提未证实的不适用由变更日志跟踪，条件满足后经 03 验证数浪复核更新结论。

### 2. 规则失效价位校验

- [ ] **I2-1 来源推导**（references/rules.md R5、R7、R9、R10、R11、R15、R29、R19）
  - 判定标准：每条规则失效价位是否对应明确的结构规则？常见对应关系——
    - 第 2 浪越过第 1 浪起点 → 违反 R5；
    - 非楔形下第 4 浪进入第 1 浪价格区域 → 违反 R7；
    - 楔形细分：位置不符 → 违反 R11；前置三角形结构不符（非 5-3-5-3-5）→ 违反 R9；终结三角形结构不符（非 3-3-3-3-3）→ 违反 R10；
    - 三角形作为独立形态出现在第 2 浪位置 → 违反 R15；
    - 失败浪假设下价格突破第 3 浪终点 → 违反 R29。
  - 每条价位均有对应规则 → 通过；价位无法对应任何规则 → 违反。
- [ ] **I2-2 编号完整性**（references/rules.md R19、R20）
  - 判定标准：每条失效价位是否都标注了对应规则编号？全部标注 → 通过；无对应规则编号的价位被标为"规则失效" → 违反（不得标为规则失效）。

### 3. 极端价位判定校验

- [ ] **I3-1 判定基准**（references/rules.md R20）
  - 判定标准：失效价位是否按极端价位（含影线的最高/最低价、盘中极端点）判定？是 → 通过；按收盘/开盘价判定 → 违反。
- [ ] **I3-2 触发机制**（references/rules.md R20）
  - 判定标准：是否明确规则失效的比较符（R7 含等号，R5/R29 不含等号）及“满足条件立即失效、无需收盘确认”？已明确 → 通过；要求收盘确认 → 违反。
- [ ] **I3-3 表述规范**（references/rules.md R20）
  - 判定标准：是否写成精确价位（如"3,200"），而非"3,200 附近""180 左右"？精确 → 通过；模糊 → 违反。

### 4. 结构失效价位校验

- [ ] **I4-1 结构失效来源**（references/rules.md 第 6 节（规则失效价位）注）
- 判定标准：是否覆盖方案前提类失效？常见来源——预期延长浪未形成、终结三角形边界被打破、平台形 C 浪未按预期结构展开（如 C 浪未走出五浪）等。覆盖相关前提 → 通过；完全缺失 → 违反；无结构前提 → 不适用。
- [ ] **I4-2 可执行性**（references/rules.md 第 6 节（规则失效价位）注）
- 判定标准：结构失效是否给出了可执行价位或明确判定条件（如"跌破 X 后连续 2 根收盘未收回"），而非"过段时间再看"？可执行 → 通过；模糊/无判定条件 → 违反；无结构失效 → 不适用。本确认口径仅适用于结构失效价位，不适用于规则失效价位（规则失效按 references/rules.md R20 及所引规则比较符立即判定）。
### 5. 主备方案独立性校验

- [ ] **I5-1 独立标注**（references/rules.md R24；references/terminology.md 1.7.5）
  - 判定标准：主方案与替代方案是否各自独立标注失效价位？各自标注 → 通过；任一方案缺失 → 违反。
- [ ] **I5-2 可区分性**（references/rules.md R24；references/terminology.md 1.7.5）
  - 判定标准：每个方案是否至少拥有一个**仅自身触发、其他方案不触发**的失效价位（独立价位）？是 → 通过；否（全部价位与其他方案共享）→ 违反。R24 的"独立标注"即指此要求；规则强制共享的价位（如两方案同为第 4 浪数法时 R7 价位相同）允许存在，但不得作为唯一价位，且共享价位触发后动作必须明确（两方案同时失效或按结构裁决）。
- [ ] **I5-3 切换路径**（references/rules.md R19）
  - 判定标准：每个方案失效后切换到哪个方案是否明确（如"主方案失效 → 启用替代 A；替代 A 失效 → 回退 02"）？明确 → 通过；缺失 → 违反。

### 6. 可执行性、距离与流程衔接校验

- [ ] **I6-1 可执行性**（references/rules.md R20）
