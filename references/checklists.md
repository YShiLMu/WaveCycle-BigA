## 1. 推动浪校验

> **本文件定位**：校验清单核心文件之一，供 `references/workflow.md（第 2 步）` 的 Rule Check / Guideline Check 与 `references/workflow.md（第 3 步）` 的 Rule/Guideline 复核逐条执行。只校验被标为"推动浪（Impulse）"的候选方案（含延长浪与失败浪），不重新数浪、不展开理论；发现违反时退回第 2 步 修正。
>
> **前置依赖**：术语见 `references/terminology.md`，推动浪识别见 `references/patterns.md（推动浪）`，规则见 `references/rules.md`，概率经验见 `references/guidelines.md`，复核接口见 `references/workflow.md（第 3 步）`。

机械项可直接引用wave_facts.py保存的本方案／父浪路径记录（references/tool_discipline.md第7节）：端点来源、段数、父子闭合、普通推动数值规则已批量核对时不重复手算。记录为待确认或未覆盖的内部结构，仍须逐项核对，不能用机械出口0替代全清单通过。

### 1. 使用说明与输入

#### 1.1 输入

本清单以 02 数浪移交的"候选方案标注 + 该方案的 Rule Check / Guideline Check 结果"为输入（02 第 7.1 节）。每个方案独立使用一张清单。

#### 1.2 使用前提

- 先确认方案确实被标为**推动浪（Impulse）**（references/rules.md R1、R2、R21）；
- 调整浪（A-B-C / W-X-Y）→ 转交同目录 `references/checklists.md（调整浪）`；
- 楔形（含重叠的驱动浪、终结三角形及其作用浪例外）→ 转交同目录 `references/checklists.md（楔形）`。

#### 1.3 校验原则

- 本清单只做"检查员"：逐条勾选后输出结论（通过/不适用/违反），不得现场修改数法；
- 结论三态：**通过 / 不适用 / 违反**。"不适用"包括两类——①检查项与方案无关；②前提未证实（数据不足、结构未完成），两种情形都必须在备注写明原因；前提未证实的不适用由变更日志跟踪，条件满足后经 03 验证数浪复核更新结论。本清单结论态仅三态，不存在模糊判定态；涉及清单间裁定的检查项判"不适用"，最终结论以承接清单为准。
- 任何 Rule 违反即方案失效，退回第 2 步 修正（references/rules.md R19）；
- Guideline 只计分，不影响合法性（references/guidelines.md G21）。

### 2. 结构身份与级别校验

- [ ] **C2-1 五浪结构**（Rule，references/rules.md R1）
  - 判定标准：该推动区间的 1-2-3-4-5 子结构是否有证据、1/3/5 是否与该推动整体同向？已核验 → 通过；进行中或内部资料不足 → 不适用（前提未证实，列复核条件）；已完成结构有反例却仍标普通推动 → 违反。只有六个端点不能代替内部检查；该推动若属于更大调整的 A/C，不因其与再上一级趋势反向而否定（references/rules.md R31）。
- [ ] **C2-2 身份一致**（Rule，references/rules.md R2、R21）
- 判定标准：该结构是否被误数成三浪调整？驱动浪是否确为五浪展开？确为五浪推动 → 通过；实为楔形（Diagonal，属驱动浪但非推动浪）→ 不适用（已转交 `references/checklists.md（楔形）`，结论以楔形清单为准）；实为三浪调整或非驱动浪 → 违反（references/rules.md R2、R21；references/terminology.md 1.1.4、1.3.4）。
- [ ] **C2-3 级别嵌套**（Rule，references/rules.md R4；references/terminology.md 1.2.3）
  - 判定标准：已观察的子结构是否符合父浪身份，父子区间与端点衔接是否一致，是否把父浪与其子浪混排为同级？可核验且自洽 → 通过；未走完或分辨率不足 → 不适用（前提未证实，备注注明区间、待补资料与复核条件）；已有跨级混排、端点矛盾或不符合父浪身份的结构证据 → 违反。完整父浪检查首尾闭合，进行中父浪不预补尾段（references/rules.md R34）。仅绝对级别名称待定不自动违反 R4。
- [ ] **C2-4 计数等效**（Rule，references/rules.md R18；references/terminology.md 1.3.7）
  - 判定标准：延长浪产生的九浪序列是否被正确视为一个五浪，而不是拆成两个同级推动浪？未拆分 → 通过；拆分 → 违反。
- [ ] **C2-5 父级框架声明与依据**（Rule，references/rules.md R31；references/terminology.md 1.2.6）
  - 判定标准：是否声明父级形态与位置、前序依据及尚缺证据？声明完整，或多个暂定框架及复核条件均明确 → 通过（仅指声明要求，不等于父级身份已确认）；遗漏框架或明知前序缺失仍宣称唯一确认 → 违反该流程要求。资料未能证实的具体结构项分别判不适用，不凭换周期或改级别名称判其通过。

本节只细化既有 R1/R4/R31 的证据检查，不新增理论规则与分数。主备是否有实质区别交由 C6-3；父级身份待确认不妨碍分别检查已经可见的局部结构。

项目交付另核对D41：日线第一层已建立年尺度框架及历史扫描依据；analysis_scope逐方案列框架起点、当前父浪与复核条件，逐父浪列细分证据和补证。没有逐浪记录不能用“深度3”代替实际检查；短框架须披露原因，不能因时间跨度短而宣称违反某条波浪Rule。

### 3. 推动浪三铁律校验

- [ ] **C3-1 第 2 浪回撤**（Rule，references/rules.md R5）
  - 判定标准：上升推动中，第 2 浪最低点是否越过第 1 浪起点？下降推动中，第 2 浪最高点是否越过第 1 浪起点？未越过 → 通过；越过 → 违反。
- [ ] **C3-2 第 3 浪长度**（Rule，references/rules.md R6）
  - 判定标准：比较同级第 1、3、5 浪的绝对价格区间。已完成的第 3 浪同时短于第 1 浪和已出现的第 5 浪区间 → 违反（第 5 浪尚未结束也不能消除已有反例）；数据齐备且第 3 浪不最短 → 通过。尚不足以裁定 → 不适用（前提未证实），列出待完成浪段；若已完成第 3 浪短于第 1 浪，记录第 5 浪的 R6 长度上限，不能仅凭“第 3 浪通常最强”放行。
- [ ] **C3-3 第 4 浪重叠**（Rule，references/rules.md R7）
  - 判定标准：对明确标为普通推动的划分，上升时第 4 浪最低点 ≤ 第 1 浪最高点、下降时第 4 浪最高点 ≥ 第 1 浪最低点 → 违反；第 4 浪已完成且未进入 → 通过；尚未出现／未完成且暂无违反 → 不适用（前提未证实）。拟改为楔形则转 C3-5，新候选的例外裁定不抹去旧普通推动违反记录。
- [ ] **C3-4 极端价位判定**（Rule，references/rules.md R20）
  - 判定标准：C3-1 至 C3-3 是否全部按含影线的最高/最低价（盘中极端点）判定？盘中满足对应规则比较符即构成违反、不以收盘确认？是 → 通过；以收盘价替代 → 违反。
- [ ] **C3-5 重叠例外转交**（Rule，references/rules.md R8、R11）
  - 判定标准：无重叠 → 不适用（与方案无关）；有重叠且另立楔形候选，转交 `references/checklists.md（楔形）` 核对 R8–R11 → 不适用（已转交，新候选最终结论以楔形清单为准）；以申请豁免为由将原普通推动判为通过 → 违反。楔形证据不足只保留候选，不宣称已获豁免。

### 4. 延长浪与失败浪校验

- [ ] **C4-1 延长浪内部**（Rule，references/rules.md R26）
  - 判定标准：延长浪（第 1/3/5 浪中的延长）内部是否为满足 R5、R6、R7 的完整五浪？是 → 通过；内部未走完 → 不适用（前提未证实，备注注明待复核子浪）；内部已有适用规则反例 → 违反。分别列父级与延长子级端点，不能用父级通过代替子级 R26；嵌套 1–2 必须逐级检查起点与内部组成。
- [ ] **C4-2 失败浪判定前提**（Rule，references/rules.md R17、R29）
  - 判定标准：第 5 浪内部是否已确认完整五浪结构、且终点未超过第 3 浪终点？条件齐备且未提前标失败 → 通过；结构未完成 → 不适用（前提未证实，不得判通过，也不得提前判失败）；结构未完成却标失败 → 违反；无失败浪 → 不适用（与方案无关）。备注：结构未完成即标失败是常见错误（references/guidelines.md G12）；该项为 Rule 检查，G12 不再单独计分。
- [ ] **C4-3 失败浪失效条件**（Rule，references/rules.md R29）
  - 判定标准：无失败浪 → 不适用；价格未突破第 3 浪终点（按极端价位）→ 通过（仅此边界尚未触发，不代表 C4-2 前提已通过）；价格已突破第 3 浪终点 → 方案已标记失败假设失效（如已切换方案）→ 通过；已突破却仍标失败 → 违反（references/rules.md R29）。

**阶段复核**：C4-1/C4-2 的“完成”须有末段内部组成、极值端点及其确认依据，记录当时截止点；不得用随后涨跌、其他方案退出或比率目标兑现补写通过。第五浪进行中不等于延长已成立。此项应用既有 R17/R26/R34，不增设评分项。

### 5. 指导原则校验（概率加分项，不影响合法性）

- [ ] **G-1 交替**（Guideline，references/guidelines.md G1）
  - 判定标准：第 2 浪与第 4 浪调整类型是否不同（陡直型 vs 横向型）？是 → 命中 +1；否 → 违反 −1。
- [ ] **G-2 等长**（Guideline，references/guidelines.md G2）
  - 判定标准：第 3 浪延长时，第 5 浪长度是否落在第 1 浪长度的 0.618–1.0 倍区间（含端点，按极端价位计）？是 → 命中 +1；区间外 → 未命中 0；第 3 浪未延长 → 不适用 0。（本条目无 −1 状态，长度不符不构成违反。）
- [ ] **G-3 通道目标**（Guideline，references/guidelines.md G3）
  - 判定标准（量化口径，通道宽度 W = 上轨与下轨的垂直距离）：a) 第 5 浪终点（极端价位）与上轨距离 ≤ 0.382×W → 命中；b) 失败浪终点与下轨距离 ≤ 0.382×W → 命中。满足任一 → 命中 +1；均不满足 → 未命中 0；未建立通道或无第 5 浪/失败浪 → 不适用 0。（本条目无 −1 状态。）
  - 阈值注册于 `references/defaults.md` D20；调整须同步 D20 并在报告中披露。
- [ ] **G-4 通道突破处理**（Guideline，references/guidelines.md G4）
- 判定标准：通道边界被决定性突破（连续 2 根收盘价位于边界外侧，references/workflow.md 第 5 步第 2 节（失效价位监控）默认口径）后，价格是否出现可重画通道的新摆动结构（新的同向摆动点形成，可重新连接基线）？是 → 命中 +1（按 G4：重画/复查通道，数法不自动失效）；否 → 未命中 0（通道假设失效，触发数法复查）；未突破 → 不适用 0。（本条目无 −1 状态。）
- [ ] **G-5 延长频率**（Guideline，references/guidelines.md G9）
  - 判定标准：一个推动浪是否被数出两个延长浪？否 → 命中 +1；候选性延长（尚未确认）→ 未命中 0；确认两个延长 → 违反 −1。
- [ ] **G-6 双回撤**（Guideline，references/guidelines.md G11）
- 判定标准：第 5 浪延长确认后，当前价格是否已走出第一轮回撤并出现反弹（价格离开第一轮回撤终点 ≥ 2 根当前周期 K 线收盘）？是 → 命中 +1（双回撤结构迹象，第二轮回撤待跟踪）；否 → 未命中 0；无延长 → 不适用 0。（本条目无 −1 状态。）
- [ ] **G-7 失败浪位置与处理**（Guideline，references/guidelines.md G22）
  - 判定标准（量化口径，分支互斥，最多 +1 分）：趋势末端 = 满足以下任一——a) 第 5 浪长度达到第 1 浪长度的 0.618–1.618 倍目标区（references/fibonacci.md 第 1.1 节）；b) 第 5 浪终点位于通道上轨 0.382×W 范围内（本清单 G-3 口径）。弱势环境 = 第 5 浪长度 < 第 3 浪长度的 0.618 倍且未突破通道上轨。
    - 分支 1：失败浪处于趋势末端或弱势环境 → 命中 +1（"优先检视"要求不适用）；
    - 分支 2：失败浪处于趋势中段（不满足分支 1）→ 方案已优先检视延长浪或级别误判 → 命中 +1；未检视 → 未命中 0；
    - 无失败浪 → 不适用 0。（本条目无 −1 状态。）
**评分规则**：每条 Guideline 按各自判定标准给出结论：命中 +1 / 未命中 0 / 明确违反 −1（仅当该条目判定标准定义了违反条件时，如 G-1、G-5）；未定义违反条件的条目（G-2、G-3、G-4、G-6、G-7）只有命中与未命中两态，不得自行加 −1。得分汇总进入概率排序（references/guidelines.md G21；本清单即 references/guidelines.md G21 所指评分细则的落地处）。斐波那契比率条目（回撤/延伸/共振，references/guidelines.md G5–G8）转交同目录 `references/checklists.md（斐波那契）`；作用浪例外（终结三角形中的 1/3/5，references/guidelines.md G13）属楔形范畴，由 `references/checklists.md（楔形）` 承接，不在本清单校验。

### 6. 输出完整性校验

- [ ] **C6-1 级别声明**（Rule，references/rules.md R22）
  - 判定标准：该方案是否声明了分析级别（含标注符号与当前浪段）？是 → 通过；否 → 违反。
- [ ] **C6-2 标注规范**（Rule，references/rules.md R23；references/terminology.md 1.2.4）
  - 判定标准：同一张图是否混用两套标注符号（数字/字母）？未混用 → 通过；混用 → 违反。
- [ ] **C6-3 主备方案**（Rule，references/rules.md R24）
  - 判定标准：是否同时给出主方案与至少一个替代方案，且各自独立标注失效价位？是 → 通过；未标明防御模式的单方案 → 不完整；明确单方案原因且强制观望时按 R24 防御模式检查。共享规则边界不等于省略各方案独立判定，须披露各自成立条件。仅换浪级名称、或一个宽泛解释包含另一个解释时，检查是否按 R24 显著披露非独立解释及理由；未披露不能按两个独立方案验收。前序与后续预期的比较记录随方案说明交接，不另加分。
- [ ] **C6-4 禁止预标未完成结构**（Rule，references/rules.md R34；判据见 09 D39；通用条目，适用全部形态）
  - 判定标准：数浪与绘图是否只实线标注已确认完成的子浪/浪段（终点为 swings 摆动点且其后出现反向摆动），进行中段用虚线+"进行中"、未预标未发生的子浪？是 → 通过；预标未完成结构 → 违反。

### 7. 结论与交接

#### 7.1 结论输出表（每个方案一张）

| C2-1 五浪结构 | Rule | references/rules.md R1 | 能否标出 1-2-3-4-5 且 1/3/5 同向 | | — | |

> 结论枚举：**通过 / 不适用 / 违反**。"不适用"包括两类——①检查项与方案无关；②前提未证实（数据不足、结构未完成），两种情形都必须在备注写明原因；前提未证实的不适用由变更日志跟踪，条件满足后经 03 验证数浪复核更新结论。涉及清单间裁定的检查项判"不适用"，最终结论以承接清单（如 02 楔形校验）为准。

#### 7.2 结论规则

- **校验通过**：全部 Rule 通过 → 结论表（含 Guideline 得分）移交 02 数浪用于概率排序（02 第 5–6 节），并随方案移交 03 验证数浪复核（03 验证数浪第 3–4 节）；
- **校验不通过**：任一 Rule 违反 → 标记"规则失效"，结论表退回第 2 步（references/rules.md R19）；主方案失效时检查替代方案是否可启用；

#### 7.3 与 03 验证数浪的衔接

## 2. 楔形校验

> **本文件定位**：校验清单之一，专用于楔形（前置三角形 Leading Diagonal / 终结三角形 Ending Diagonal）候选方案的逐条校验；是"第 4 浪与第 1 浪重叠例外条款"（R8、R9、R10、R11）的唯一落地检查表。不重新数浪、不展开理论；发现违反时退回第 2 步 修正。
>
> **前置依赖**：术语见 `references/terminology.md`，楔形识别见 `references/patterns.md（楔形）`，规则见 `references/rules.md`，概率经验见 `references/guidelines.md`，复核接口见 `references/workflow.md（第 3 步）`。

### 1. 使用说明与输入

#### 1.1 启用条件

本清单在以下两种情况下启用：

1. 02 数浪直接将方案标为楔形；
2. 推动浪校验中发现第 4 浪与第 1 浪重叠，转交本清单核查（references/rules.md R8；`references/checklists.md（推动浪）` 第 3 节 C3-5）。

#### 1.2 使用前提

- 先确认楔形属于**驱动浪（Motive Wave）**而非调整浪（references/rules.md R21、R2；references/terminology.md 1.1.4、1.3.4）；
- 调整浪三角形（A-B-C-D-E）→ 转交 `references/checklists.md（调整浪）`，不在本清单校验。

#### 1.3 校验原则

- 本清单只做"检查员"：逐条勾选后输出结论（通过/不适用/违反），不得现场修改数法；
- 结论三态：**通过 / 不适用 / 违反**。"不适用"包括两类——①检查项与方案无关；②前提未证实（数据不足、结构未完成），两种情形都必须在备注写明原因；前提未证实的不适用由变更日志跟踪，条件满足后经 03 验证数浪复核更新结论。本清单结论态仅三态，不存在模糊判定态；涉及清单间裁定的检查项判"不适用"，最终结论以承接清单为准。
- 楔形的位置或子浪结构任一不符，即不得享受重叠例外（references/rules.md R11）；
- 重叠例外被否决时，推动浪清单的 C3-3 同步恢复为"违反 R7"判定（references/rules.md R11、R19）。

### 2. 位置校验

- [ ] **D2-1 前置三角形位置**（Rule，references/rules.md R9）
  - 判定标准：该前置型是否处于直接父级第 1/A 浪位置且父级类型适配？是 → 通过；位置反例 → 违反；父级证据不足 → 不适用（前提未证实）；非前置型 → 不适用（与方案无关）。
- [ ] **D2-2 终结三角形位置**（Rule，references/rules.md R10）
  - 判定标准：该终结型是否处于直接父级第 5/C 浪位置？是 → 通过；位置反例 → 违反；父级证据不足 → 不适用（前提未证实）；非终结型 → 不适用（与方案无关）。
- [ ] **D2-3 位置不符处理**（Rule，references/rules.md R11）
  - 判定标准：直接父级位置不符合 R9/R10 时是否拒绝楔形例外？正确处理 → 通过；仍放行 → 违反；无该情形 → 不适用。整个第 3 浪不能标楔形，但其内部第 1/5 子浪须按自身位置另查；调整内部 A/C 同理，不把调整的正常重叠套入 R7。

### 3. 子浪结构校验

- [ ] **D3-1 前置三角形结构**（Rule，references/rules.md R9）
  - 判定标准：内部是否为 5-3-5-3-5 结构（1、3、5 子浪为五浪，2、4 子浪为三浪）？是 → 通过；内部子浪结构未确认（数据不足）→ 不适用（前提未证实，备注注明待复核子浪）；否 → 违反。备注：假设数据**显式设定**内部结构时可判"通过（数据设定）"并注明"非真实复核"；未逐子浪展示内部结构时按"不适用（前提未证实）"。
- [ ] **D3-2 终结三角形结构**（Rule，references/rules.md R10）
  - 判定标准：内部是否为 3-3-3-3-3 结构（五个子浪全部为三浪）？是 → 通过；内部子浪结构未确认（数据不足）→ 不适用（前提未证实，备注注明待复核子浪）；任一子浪为五浪 → 违反。备注：终结三角形中的 1/3/5 是作用浪但以调整形态（三浪）展开（references/guidelines.md G13），误标为推动浪即子浪结构不符，已由本项覆盖，不单独计分；假设数据**显式设定**内部结构时可判"通过（数据设定）"，未逐子浪展示时按"不适用（前提未证实）"。

### 4. 重叠与极端价位校验

- [ ] **D4-1 重叠合法性**（Rule，references/rules.md R7、R8）

### 1. 使用说明与输入

#### 1.1 输入

本清单以 02 数浪移交的"候选方案标注 + Rule Check / Guideline Check 结果"为输入（02 第 7.1 节）。每个方案独立使用一张清单。

#### 1.2 使用前提

- 先确认方案确实被标为**调整浪（Corrective Wave）**（references/rules.md R2、R25；references/terminology.md 1.1.3）；
- 调整浪中的 B 浪、X 浪、联合形组成形态（W、Y、Z）不得被标为推动浪或驱动浪（references/rules.md R30）；
- 调整浪三角形（A-B-C-D-E）由本清单校验；楔形（驱动浪家族）转交 `references/checklists.md（楔形）`。

#### 1.3 校验原则

- 本清单只做"检查员"：逐条勾选后输出结论（通过/不适用/违反），不得现场修改数法；
- 结论三态：**通过 / 不适用 / 违反**。"不适用"包括两类——①检查项与方案无关；②前提未证实（数据不足、结构未完成），两种情形都必须在备注写明原因；前提未证实的不适用由变更日志跟踪，条件满足后经 03 验证数浪复核更新结论。本清单结论态仅三态，不存在模糊判定态；涉及清单间裁定的检查项判"不适用"，最终结论以承接清单为准。
- 任一 Rule 违反即方案失效，退回第 2 步 修正（references/rules.md R19）；
- Guideline 只计分，不影响合法性（references/guidelines.md G21）。

### 2. 身份与分类前提校验

- [ ] **C2-1 身份一致**（Rule，references/rules.md R1、R2）
  - 判定标准：调整浪是否确为三浪或其变体，未被数成五浪推动？确为三浪或其变体 → 通过；被数成五浪推动 → 违反。
- [ ] **C2-2 方向正确**（Rule，references/rules.md R25）
  - 判定标准：以更大级别趋势为参照，A 浪与 C 浪是否反向、B 浪是否同向？符合 → 通过；任一方向不符 → 违反。
- [ ] **C2-3 X 浪身份**（Rule，references/rules.md R3）
  - 判定标准：X 浪是否为调整浪而非推动浪？是 → 通过；X 内部结构未确认 → 不适用（前提未证实，备注注明待复核子浪）；被标为推动浪 → 违反；无 X 浪 → 不适用（与方案无关）。
- [ ] **C2-4 身份不混淆**（Rule，references/rules.md R30）
  - 判定标准：B、X 及联合形组成形态（W、Y、Z）是否被误标为推动/驱动浪？未误标 → 通过；误标 → 违反。

### 3. 锯齿形与复合锯齿校验

- [ ] **C3-1 锯齿形**（Rule，references/rules.md R12；references/terminology.md 1.4.3）
  - 判定标准：按 R12 检查 A/C 的完整驱动组成与 B 的调整组成，并逐级区分整体和内部。证据齐备且符合 → 通过；任一相关段未完成或组成未证实 → 不适用（前提未证实，列出具体段）；任一段已有组成反例仍标锯齿 → 违反；非锯齿形 → 不适用（与方案无关）。单靠三段端点不构成通过。
- [ ] **C3-2 双/三锯齿形**（Rule，references/rules.md R13；references/terminology.md 1.4.4、1.4.5）
  - 判定标准：W、Y（及 Z）是否各为锯齿形并由 X 浪连接？符合 → 通过；组成浪内部结构未确认 → 不适用（前提未证实，备注注明待复核子浪）；任一组成浪非锯齿形 → 违反；非复合锯齿 → 不适用（与方案无关）。

### 4. 平台形校验

- [ ] **C4-1 平台形**（Rule，references/rules.md R14；references/terminology.md 1.4.6）
  - 判定标准：A/B 是否有调整组成、C 是否有完整驱动组成（3-3-5）？符合且完成证据齐备 → 通过；A/B/C 任一组成或末端未确认 → 不适用（前提未证实，备注注明具体段）；任一直接子浪已有身份反例 → 违反；非平台形 → 不适用（与方案无关）。
- [ ] **C4-2 变体分类**（Rule，references/rules.md R28；references/terminology.md 1.4.7）
  - 判定标准：先检查 C4-1；仅对已经完成的相应端点按 R28/D8 分类。下表以**向下 C** 为例，A 长度 L = |A 终点 − A 起点|：
    - 规则平台形：|B 终点 − A 起点| ≤ 0.382×L，且 0 < A 终点 − C 终点 ≤ 0.382×L；
    - 扩张平台形：B 终点 > A 起点，且 C 终点 < A 终点 − 0.382×L；
    - 奔走平台形：B 终点 > A 起点，且 C 终点 > A 终点。
  - **向上 C 的镜像**：规则型使用同一绝对偏差，且 0 < C 终点 − A 终点 ≤ 0.382×L；扩张型 B < A 起点且 C > A 终点 + 0.382×L；奔走型 B < A 起点且 C < A 终点。L 为零时不计算，先查分段或输入。
  - 完成证据齐备且所标变体全部条件满足 → 通过；相关段未完成／端点未确认 → 不适用（前提未证实），即使暂时到价也不能提前通过；完成后与所标变体条件不符 → 违反该变体声明，退回重新归类。D8 未覆盖的边界组合注明“变体未归类”，不强行归类或直接确认其他家族；C4-1 的结构判定与变体名称分别记录。0.382 是本项目口径，须披露，不能冒充统一原著阈值。

### 5. 三角形与联合形校验

- [ ] **C5-1 三角形结构**（Rule，references/rules.md R15、R27；references/terminology.md 1.4.8）
  - 判定标准：是否由 A-B-C-D-E 五个子浪构成，五个子浪全部为三浪（不得出现五浪子浪，references/rules.md R27），子浪 4 与子浪 1 重叠？符合 → 通过；D/E 未完成或子浪结构未确认 → 不适用（前提未证实，备注注明待复核子浪）；直接子浪数、整体身份或区间重叠已有反例 → 违反；非三角形 → 不适用（与方案无关）。备注：假设数据**显式设定**内部结构（如注明 3-3-3-3-3 已设定）时可判"通过（数据设定）"并在备注注明"非真实复核"；假设数据未逐子浪展示内部结构时按"不适用（前提未证实）"。补查 A-C、B-D 连线的时间坐标、E 完成状态；E 未触线或越线不单独判违反，内部 A/C 五浪也不等于直接子浪整体是驱动。
- [ ] **C5-2 三角形位置**（Rule，references/rules.md R15；references/guidelines.md G19）
  - 判定标准：先核直接父级位置与嵌套；作为整个第 2 浪的独立三角形 → 违反；位置有依据且符合 R15/R16 → 通过；父级未确认 → 不适用（前提未证实）；非三角形 → 不适用。第 2 浪复杂调整内部的局部三角形另按直接位置检查，不能因祖父级是第 2 浪一并否决。
- [ ] **C5-3 联合形**（Rule，references/rules.md R16、R13）
  - 判定标准：组成形态是否均为调整形态并经 X 连接？两个锯齿形直接相连是否被错误标成联合形而非双锯齿形？每个组成和 X 的结构、末段确认均有依据 → 通过；组成／连接内部缺证或未完成 → 不适用（前提未证实）；组成含非调整形态、无 X 连接、或双锯齿误标联合形 → 违反；非联合形 → 不适用（与方案无关）。备注：假设数据**显式设定**组成形态时可判"通过（数据设定）"并注明"非真实复核"；未逐子浪展示组成内部结构时按"不适用（前提未证实）"。

### 6. 指导原则校验（概率加分项，不影响合法性）

| 形态 | 必评条目 |
| --- | --- |
| 锯齿形（R12） | G-1 交替、G-2a 回撤深浅、G-5 强趋势反弹识别、G-7 位置偏好 |

| 双/三锯齿形（R13） | G-1、G-2a、G-5、G-3 罕见形态（三锯齿形适用） |

> 其余条目（G-3 罕见形态、G-6 X 浪形态、G-9 扩张平台止损）仅在适用时评，不适用标"不适用 0"，不得漏评必评条目。

- [ ] **G-1 交替**（Guideline，references/guidelines.md G1）
  - 判定标准：第 2 浪陡直时第 4 浪是否倾向横向，反之亦然？交替成立 → 命中 +1；两浪同型 → 违反 −1。
- [ ] **G-2a 回撤深浅**（Guideline，references/guidelines.md G5）
- 判定标准：锯齿形整体回撤（C 终点）是否取深档（50%–61.8%）、平台形整体回撤是否取浅档（38.2%–50%）？相符 → 命中 +1；不符 → 未命中 0；不适用 → 0。本项只检查整体回撤；锯齿形 B/A 按 G7 及斐波那契清单 F2-3/F5-1 核对，不送入仅适用于平台 B 的 G-2b。（无 −1 状态；比率计算转交 `references/checklists.md（斐波那契）`。）
- [ ] **G-2b 平台形 B 回撤**（Guideline，references/guidelines.md G7）
- 判定标准：平台形 B 浪终点是否达到或接近 A 浪起点（向下 C 时 B ≥ A 起点 − 0.382×A 长度；向上 C 时 B ≤ A 起点 + 0.382×A 长度，按极端价位；对应"B 回撤 A 接近或超过 100%"，项目默认口径，须披露）？是 → 命中 +1；否 → 未命中 0；非平台形 → 不适用 0。（无 −1 状态。）
- [ ] **G-3 罕见形态**（Guideline，references/guidelines.md G14）
- 判定标准：三锯齿形（三个锯齿形 + 两个 X）或三重三浪（三个调整形态 + 两个 X）的结构特征是否确认（组成形态与连接数，references/rules.md R13/R16）？确认 → 命中 +1（沿用现有结构识别项；这不是罕见性的统计奖励，也不能称为已执行负向降权）；未确认/无罕见形态 → 不适用 0。（无 −1 状态；G14 的罕见性须另在排序理由中披露，本批不新增频率罚分或权重。）
- [ ] **G-4 联合形组成**（Guideline，references/guidelines.md G16）
  - 判定标准：组成已核验且不同 → 命中 +1；同型但不违反 R13/R16（如平台 + 平台）→ 未命中 0；两个锯齿已正确归为双锯齿 → 不适用 0；两个锯齿仍误标联合形 → 违反 −1，同时按 C5-3 处理。不得把 G16“通常不同”升级为所有组成必须互异的硬规则；组成未确认 → 未命中 0。
- [ ] **G-5 强趋势反弹识别**（Guideline，references/guidelines.md G17）
  - 判定标准：大级别趋势中出现的反弹段，是否被识别为调整浪（B 浪反弹/奔走型调整），未将其误标为新推动浪起点？识别正确 → 命中 +1；被误标为新推动 → 违反 −1（同时触发 C2-4 规则违反）；不涉及反弹歧义或身份前提未证实 → 不适用 0。不得在 B 与新第 1 浪仍有独立结构候选时，提前认定其中一个为误标。
- [ ] **G-6 X 浪形态**（Guideline，references/guidelines.md G18；references/terminology.md 1.1.8）
  - 判定标准：X 浪是否按常见形态（锯齿/平台，偶见三角形）标注？是 → 命中 +1；X 浪整体被确认为五浪推动等非法身份 → 违反 −1（同时触发 C2-3 规则违反）；合法但不常见的调整形态不因罕见而触发 Rule，本项未命中 0；无 X 浪或结构未确认 → 不适用 0。
- [ ] **G-7 位置偏好**（Guideline，references/guidelines.md G23）
  - 判定标准：锯齿形通常作第 2 浪、平台形通常作第 4 浪、三角形作第 4 浪或 B 浪，是否与位置偏好相符？相符 → 命中 +1；不符 → 未命中 0。（无 −1 状态，位置偏好不构成合法性。）
- **G-8 后势特征（自动派生，references/guidelines.md G24）**：相关组成、父级位置与完成证据齐备且无 Rule 违反，C5-1 或 C5-3 通过 → 自动命中 +1（后势快速/有力预期由结构成立派生）；不涉及 → 不适用 0。不设独立文案检查。
- **G-9 扩张平台止损（自动派生，references/guidelines.md G25）**：C4-1 通过且 C4-2 确认扩张平台（B/C 条件及完成证据齐备，无 Rule 违反）→ 自动命中 +1（C 浪终点为后续关键止损参考，反向突破需重新评估）；非扩张平台或完成前提未证实 → 不适用 0。不设独立文案检查。

**评分规则**：每条 Guideline 按各自判定标准给出结论：命中 +1 / 未命中 0 / 明确违反 −1（仅当该条目判定标准定义了违反条件时，如 G-1、G-4、G-5、G-6）；未定义违反条件的条目（G-2a、G-2b、G-3、G-7）只有命中与未命中两态；自动派生条目（G-8、G-9）只有命中与不适用两态。不得自行加 −1。得分汇总进入概率排序（references/guidelines.md G21；本清单即 references/guidelines.md G21 所指评分细则的落地处）。斐波那契比率条目（references/guidelines.md G5–G8）转交 `references/checklists.md（斐波那契）`。

### 7. 失效价位与结论交接

- [ ] **D7-1 规则失效**（Rule，references/rules.md R19）
  - 判定标准：已确认的证据与所声称分类条件冲突（如具体 R28 变体不符）或子浪结构不符时，该方案是否已被标记为规则失效？是 → 通过（处理正确）；否 → 违反。仅因结构未完成、前提缺失而无法验证的，标“不适用（前提未证实）”，不混同已证伪。
- [ ] **D7-2 极端价位**（Rule，references/rules.md R20）
  - 判定标准：重叠与失效判定是否均按含影线的最高/最低价（盘中极端点）执行？是 → 通过；以收盘价替代 → 违反。
- [ ] **D7-3 结构失效转交**（流程，references/guidelines.md G25、references/rules.md 第 6 节（规则失效价位）注）
- 判定标准：扩张平台 C 浪终点被反向突破等结构失效价位，是否已转交 `references/checklists.md（失效）`？已转交 → 不适用（已转交，结论以失效清单为准）；未涉及结构失效 → 不适用（与方案无关）。

#### 7.2 结论规则

- **校验通过**：全部适用 Rule 通过且与结论相关的完成前提齐备 → 进入 Guideline 计分与概率排序（02 第 5–6 节）；
- **校验不通过**：任一 Rule 违反 → 退回第 2 步（references/rules.md R19）；
- Guideline 得分汇总进入概率排序，不影响合法性（references/guidelines.md G21）。

### 8. 实战示例：第 4 浪规则平台形 vs 三角形

**02 提交（假设）**：上升趋势第 4 浪位置，日线级别 Intermediate。主方案 = 平台形（规则平台形）；替代方案 = 三角形。

**第 1 步 身份与分类前提校验**：

| 检查项 | 结论 | 备注 |
| --- | --- | --- |
| C2-1 身份一致 | 通过 | 确为三浪或其变体（references/rules.md R1、R2） |
| C2-2 方向正确 | 通过 | A/C 与更大趋势反向、B 同向（references/rules.md R25） |
| C2-3 X 浪身份 | 不适用 | 无 X 浪 |
| C2-4 身份不混淆 | 通过 | B、W/Y/Z 未误标为推动浪（references/rules.md R30） |

**第 2 步 平台形结构校验（主方案）**：

| 检查项 | 结论 | 备注 |
| --- | --- | --- |
| C4-1 平台形 | 通过 | A、B 为三浪，C 为五浪（references/rules.md R14） |
| C4-2 变体分类 | **违反** | 所标"规则平台形"要求 B 与 A 起点的绝对价差 ≤ 0.382×A 长度（0.382×35≈13.4），但 B 终点（205）低于 A 起点（220）达 15 点；且 B 低于 A 起点也不满足扩张/奔走（均要求 B > A 起点），分类条件未同时满足（references/rules.md R28） |

**第 3 步 三角形结构校验（替代方案）**：

## 4. 斐波那契校验

> **本文件定位**：校验清单之一，专用于比率目标（回撤、延伸、比率关系）与共振区（Confluence）的计算基准、刻度与独立性的逐条校验；是 references/guidelines.md G5–G8 与 `references/fibonacci.md` 的落地检查表。不重新数浪、不展开理论；发现计算错误时退回第 2 步 修正。
>
> **前置依赖**：术语见 `references/terminology.md`，比率表与公式见 `references/fibonacci.md`，规则见 `references/rules.md`，概率经验见 `references/guidelines.md`，复核接口见 `references/workflow.md（第 3 步）`。

公式结果优先引用wave_facts.py／target_calc.py的原始结果（references/tool_discipline.md第7节），不转抄端点重算。脚本的条件目标不代替来源独立性、目标合法范围、容差与共振核验；这些项目缺证时不得自动记通过。

### 1. 使用说明与输入

#### 1.1 输入

本清单以 02 数浪输出的“各方案关键比率目标 + 共振区 + 推导记录”为输入（02 第 3 节；比率表以 `references/fibonacci.md` 为准，50% 刻度说明见 references/guidelines.md G5 注）。

每个目标随方案提供：目标浪及阶段、基准路径/日期/极值、投射起点及状态、方向/公式/倍数、原始结果、Rule 边界、推导链分组、T₀/P₀/截止时间/容差、使用状态。表格格式见 `references/workflow.md（第 2 步）` 的“比率目标的推导记录”；条件目标、已到价与已完成分开记录。

#### 1.2 校验原则

- 比率目标属于 Guideline（G5–G8）：计算错误只影响概率排序，**不使数法失效**（references/guidelines.md G21）；
- 但计算基准错误会导致目标区失真，必须退回第 2 步 修正后重新评分（references/guidelines.md G21）；
- 本清单只做"检查员"：发现错误时退回第 2 步，不现场改数；结论三态（通过/不适用/违反）——"不适用"包括检查项与方案无关或数据不足/前提未证实，须在备注写明原因；前提未证实的不适用由变更日志跟踪，条件满足后经 03 验证数浪复核更新结论。

### 2. 基准浪校验

- [ ] **F2-1 回撤基准**（Guideline，references/fibonacci.md 第 2.1 节；references/guidelines.md G5）
  - 判定标准：是否使用被回撤浪的完整价格区间，向下从其高点减去 L×r、向上从其低点加上 L×r？路径、方向、基准及公式均正确 → 通过；基准选错／方向算反 → 违反；基准未完成 → 不适用（前提未证实），只列条件演算。
- [ ] **F2-2 延伸基准**（Guideline，references/fibonacci.md 第 2.2 节；references/guidelines.md G6）
  - 判定标准：是否按所用关系选取已完成基准浪的长度，并从目标浪起点按方向投射？例如第 5 浪从第 4 浪终点、C 从 B 终点投射；平台 A 本身可为调整，不能一律要求基准为推动。基准与起点正确且确认 → 通过；错用其他浪起点或将未完成基准冒充完整 → 违反；如实登记基准／起点待确认 → 不适用（前提未证实），不作已验证共振。
- [ ] **F2-3 比率关系基准**（Guideline，references/fibonacci.md 第 1 节；references/guidelines.md G7）
  - 判定标准：C/A 是否用 A 浪长度、5/1 是否用第 1 浪长度、B/A 是否用 A 浪长度？对应正确 → 通过；张冠李戴 → 违反；分母为零或端点缺失 → 不适用（前提未证实），返回数据／分段检查，不输出无穷或默认零比率。
- [ ] **F2-4 极端价位**（Rule，references/rules.md R20）
  - 判定标准：所有长度计算是否按含影线的最高/最低价（盘中极端点）取值，不以收盘/开盘价计算？是 → 通过；以收盘/开盘价取值 → 违反。

### 3. 回撤比率校验

- [ ] **F3-1 常用刻度**（Guideline，references/guidelines.md G5）
  - 判定标准：回撤目标是否仅使用 38.2%、50%、61.8% 三档刻度（未使用 45%、70% 等非常规刻度）？预测档位使用常规三档 → 通过；无依据地把非常规预测档冒称本项标准 → 违反。实测回撤 45%/57%/70% 等须如实保留，不因偏离标准档就判计算错误；已声明其他方法的独立测量不进入本项标准档评分。备注：50% 是经验值，非严格斐波那契比率（references/guidelines.md G5），此条为说明性备注，不作为检查条件。
- [ ] **F3-2 形态差异**（Guideline，references/guidelines.md G5）
- 判定标准：锯齿形整体回撤（C 终点）是否优先取深档（50%–61.8%）、平台形整体回撤是否优先取浅档（38.2%–50%）？相符 → 命中 +1；不符 → 未命中 0；不适用 → 0。本项只检查整体回撤；锯齿形 B/A 另按 F2-3/F5-1 及 references/fibonacci.md 第 1.2 节核对，不送入仅适用于平台 B 的 F5-2；完整调整端点未确认时不作实际回撤命中计分。（无 −1 状态。）

### 4. 延伸与等长校验

- [ ] **F4-1 延伸刻度**（Guideline，references/fibonacci.md 第 1 节；references/guidelines.md G6）
- 判定标准：延伸目标是否使用 1.618、2.618 倍数（自目标浪起点投射）？标准延伸档与投射方式正确 → 通过；无依据地使用其他预测倍数或投射方式错误 → 违反；1.0 等长转 F4-2，不在此处罚。实测倍数只作测量披露，不因未达 1.618 就判数法失效；条件起点尚未确认 → 不适用（前提未证实）。
- [ ] **F4-2 等长**（Guideline，references/fibonacci.md 第 2.3 节；references/guidelines.md G2）
  - 判定标准：等长目标是否按"直接复制基准浪价格区间、平移到目标浪起点"计算？且前提浪选择正确——第 3 浪延长时 5≈1、锯齿形中 C≈A？计算方式与前提均正确 → 通过；任一错误 → 违反；基准、目标起点或适用前提未确认 → 不适用（前提未证实），不能仅复制长度就通过。

### 5. 比率关系校验

- [ ] **F5-1 常见比率**（Guideline，references/fibonacci.md 第 1 节；references/guidelines.md G7）
  - 判定标准：C/A、5/1、B/A 之间是否按 0.618、1.0、1.618 等关系核对？核对完整 → 命中 +1（沿用核对项，不等于行情已到预测价）；遗漏或错用 → 未命中 0；区分实测关系和未来目标，同一公式换写法不增加市场证据。（无 −1 状态。）
- [ ] **F5-2 平台形 B 浪**（Guideline，references/guidelines.md G7）
- 判定标准：平台形 B 浪终点是否达到或接近 A 浪起点（向下 C 时 B ≥ A 起点 − 0.382×A 长度；向上 C 时 B ≤ A 起点 + 0.382×A 长度，按极端价位；对应"B 回撤 A 接近或超过 100%"，项目默认口径，须披露）？是 → 命中 +1；否 → 未命中 0；非平台形 → 不适用 0。（无 −1 状态。）
- [ ] **F5-3 三角形目标**（Guideline，references/fibonacci.md 第 2.4 节；references/guidelines.md G15）
  - 判定标准：收缩三角形之后的第 5 浪目标是否明确选取最宽摆动的高低点及日期，以高度 H = 高点 − 低点，自 E 终点沿预期方向投射？不能用两个同侧高点之差代替高度。采用两条边界在同一时刻的垂直间距时，须另披露测量时点与口径，不能混算。计算与前提正确 → 通过；基准或平移错误 → 违反；非收缩三角形 → 不适用。E 或父级位置未确认时仅列条件目标，标“不适用（前提未证实）”；经验目标不构成 Rule。

### 6. 共振区校验

- [ ] **F6-1 共振定义**（Guideline，references/fibonacci.md 第 3 节；references/guidelines.md G8）
  - 判定标准：是否围绕同一方案、目标浪、方向与截止点，以预登记主目标 T₀ 为中心，按 D6 的 ε=abs(P₀)×1% 搜索带找到至少两条有效独立依据（至少一条比率链）？成员各自满足 abs(Ti−T₀)≤ε，结构区间列实际交集；证据及结构约束均满足 → 命中 +1；只有一条有效链、区域不合或只靠同链倍数 → 未命中 0；未登记或前提未证实 → 不适用 0。披露 P₀ 来源和时刻、T₀、搜索带与实际支持包络，不把当前价当搜索中心。（无 −1 状态。）
- [ ] **F6-2 独立性**（Guideline，references/fibonacci.md 第 3.2 节；references/guidelines.md G8）
  - 判定标准：推导链按（基准浪，计算类型）分组，基准标明路径/级别/日期/端点。同一投射的 1.0/1.618/2.618 档、代数改写、同极值换周期只计一份；不同基准或真正不同的回撤／投射依据可分链，披露共用端点及层级关联。前级结构点可为独立依据，须有先于共振搜索的来源。完成去重且独立来源齐备 → 通过；重复计数或把互斥方案／不同目标浪拼成共振 → 违反；来源缺失 → 不适用（前提未证实）。去重不同于统计独立。
- [ ] **F6-3 极端价位**（Rule，references/rules.md R20）
  - 判定标准：比率推导及原生结构区的源端点是否按含影线极值取值、可追溯，派生区间是否能从这些输入和已披露容差复算？是 → 通过；用收盘替代结构极值 → 违反；来源未核实 → 不适用（前提未证实）。P₀ 仅为容差参考现价，可用截止收盘并标明，不冒充浪端点；公式产生的区间边界不是实际成交极值。
- **F6-4 用途说明（自动派生，references/guidelines.md G8）**：F6-1 命中且 F6-2 通过（同一目标区有 ≥2 条有效独立依据、至少一条比率链）→ 自动命中 +1（共振区作为目标/失效/入场参考时可信度提高）；未形成共振区或前提未证实 → 不适用 0。不设独立文案检查；本项是派生分，不另算一份市场证据，不能用它与 F6-1 凑成两条链。

**评分规则**：Rule 条目（F2-4、F6-3）只出通过/不适用/违反（比率计算一般可直接判定，数据不足时按"不适用（前提未证实）"处理）；Guideline 条目按各自判定标准给出命中 +1 / 未命中 0 / 明确违反 −1（仅当判定标准定义了违反条件时，如 F2-1 至 F2-3、F3-1、F4-1、F4-2、F5-3、F6-2）。清单得分按既有条目披露；八因子的“斐波那契共振”按 references/workflow.md 第 5 步第 7 节（概率重新排序）归为 0/1/2，不直接把清单合计分当该因子。既有权重不变，同一事实在清单和因子中的关联须披露（references/guidelines.md G21）。

### 8. 实战示例：第五浪错用了第二浪终点

**独立教学数据**：父级端点 100→140→120→200→180，第一浪长度 40，第三浪延长作为教学设定；更细组成另行设定已核验，当前第五浪形成中。错误移交单使用 120 作为第五浪投射原点，得出等长 160、1.618 档 184.72，并把两个倍率计为“两条独立共振”。

| 检查项 | 结果 | 修正／补证要求 |
| --- | --- | --- |
| F2-2 | 违反 | 第五浪应从第四浪终点 180 投射；120 是第三浪起点 |
| F4-1 | 违反 | 倍率正确，起点错误；1.618 档应为 244.72 |
| F4-2 | 违反 | 复制 40 的长度仍不够，等长起点也必须正确；应为 220 |
| F6-1 | 未命中 0 | 两个分离目标不构成同一共振区 |
| F6-2 | 违反 | 相同基准、同类投射的不同倍数仍是一条链 |
| F6-4 | 不适用 0 | 不能由上述不成立的共振自动加分 |

退回第 2 步 修正计算，不因目标算错就宣布父级结构违反。正确目标与未来行情到价仍是两个状态。

**修正后的独立证据条件**：若截止 P₀=200，以 T₀=220 搜索，ε=2；另有预登记且有日期/筛选依据的历史结构位 221，则支持包络 220–221，F6-1 可命中、F6-2 可通过，斐波那契因子可取 2。若 221 只是看见目标后随意挑出的价位，独立性不成立；有效比率链仍只有一条，因子为 1。起点 180 尚未确认时，两档只列条件目标，不能按已验证共振计分。

**边界反例**：另一个第 4 浪扩张平台候选，A 长 35、B 终点 245、父级 R7 边界 160；2.618 档为 153.37，不能裁为 160.01 再声称有效。即使与别的价位重合，也须先按 references/fibonacci.md 第 3.4 节排除该目标；当前价格尚未触及 160 时，不提前判 R7 违反。

**交接**：提交修正前后端点与公式、去重记录、T₀/P₀/容差、目标适用状态、斐波那契因子依据；03 验证数浪只核验，不替 02 重新选择端点。

**小结**：斐波那契校验 = 基准浪（F2，含极端价位 R20）→ 回撤刻度（F3）→ 延伸与等长（F4）→ 比率关系（F5）→ 共振区（F6：重合、独立性、边界、用途）→ 结论与交接。底线：基准错、刻度错、共振不独立，一律退回第 2 步；但比率错误不使数法失效，只改概率权重。

## 5. 失效校验

> **本文件定位**：校验清单之一，专用于每个方案失效价位（规则失效 + 结构失效）的逐条校验；`references/rules.md` 第 6 节（规则失效价位） 节已指定本文为规则失效价位与结构失效价位的落地处。不重新数浪、不展开理论；失效价位缺失或不可执行时退回第 2 步 补充。
>
> **前置依赖**：术语见 `references/terminology.md`（references/terminology.md 1.7.1），失效价位分类见 `references/rules.md` 第 6 节（规则失效价位），概率经验见 `references/guidelines.md`（G21、G25），复核接口见 `references/workflow.md（第 3 步）` 第 5 节，落库模板见 `assets/失效追踪_invalidation.md`。

### 1. 使用说明与输入

#### 1.1 输入

本清单以 02 数浪输出的"各方案失效价位清单"为输入，区分两类失效价位（references/rules.md 第 6 节（规则失效价位））：

- **规则失效价位（Rule-based Invalidation）**：由具体结构规则（R5、R7、R9、R10、R11、R15、R29 等）推导，价格满足对应规则的比较条件即方案失效（references/rules.md R19 为失效后处理规则，不充当失效价位来源）；
- **结构失效价位（Structural Invalidation）**：预期结构未形成等方案前提判断，不由硬性规则推导（references/rules.md 第 6 节（规则失效价位）注）。

#### 1.2 校验原则

- 本清单只做"检查员"：失效价位缺失、模糊或不可执行时，退回第 2 步 补充，不现场修改（references/rules.md R19、R20）；
- 每个方案独立使用一张清单；结论三态（通过/不适用/违反）——"不适用"包括检查项与方案无关或数据不足/前提未证实，须在备注写明原因；前提未证实的不适用由变更日志跟踪，条件满足后经 03 验证数浪复核更新结论。

### 2. 规则失效价位校验

- [ ] **I2-1 来源推导**（references/rules.md R5、R7、R9、R10、R11、R15、R29、R19）
  - 判定标准：每条规则失效价位是否对应明确的结构规则？常见对应关系——
    - 第 2 浪越过第 1 浪起点 → 违反 R5；
    - 非楔形下第 4 浪进入第 1 浪价格区域 → 违反 R7；
    - 楔形细分：位置不符 → 违反 R11；前置三角形结构不符（非 5-3-5-3-5）→ 违反 R9；终结三角形结构不符（非 3-3-3-3-3）→ 违反 R10；
    - 三角形作为独立形态出现在第 2 浪位置 → 违反 R15；
    - 失败浪假设下价格突破第 3 浪终点 → 违反 R29。
  - 每条价位均有对应规则 → 通过；价位无法对应任何规则 → 违反。
- [ ] **I2-2 编号完整性**（references/rules.md R19、R20）
  - 判定标准：每条失效价位是否都标注了对应规则编号？全部标注 → 通过；无对应规则编号的价位被标为"规则失效" → 违反（不得标为规则失效）。

### 3. 极端价位判定校验

- [ ] **I3-1 判定基准**（references/rules.md R20）
  - 判定标准：失效价位是否按极端价位（含影线的最高/最低价、盘中极端点）判定？是 → 通过；按收盘/开盘价判定 → 违反。
- [ ] **I3-2 触发机制**（references/rules.md R20）
  - 判定标准：是否明确规则失效的比较符（R7 含等号，R5/R29 不含等号）及“满足条件立即失效、无需收盘确认”？已明确 → 通过；要求收盘确认 → 违反。
- [ ] **I3-3 表述规范**（references/rules.md R20）
  - 判定标准：是否写成精确价位（如"3,200"），而非"3,200 附近""180 左右"？精确 → 通过；模糊 → 违反。

### 4. 结构失效价位校验

- [ ] **I4-1 结构失效来源**（references/rules.md 第 6 节（规则失效价位）注）
- 判定标准：是否覆盖事先声明的具体方案前提类失效？须写明形成阶段、所检验结构、价位／事件及确认窗口，不能把尚在形成的延长或 C 浪因“未完成”直接判失效。楔形越界按 `references/patterns.md（楔形）` 第 5.1 节区分：完成后反向突破 2–4 线可支持后势，不能列为原形态通用失效条件。覆盖相关具体前提 → 通过；应列而缺失 → 违反；无该结构前提 → 不适用。
- [ ] **I4-2 可执行性**（references/rules.md 第 6 节（规则失效价位）注）
- 判定标准：结构失效是否给出了可执行价位或明确判定条件（如"跌破 X 后连续 2 根收盘未收回"），而非"过段时间再看"？可执行 → 通过；模糊/无判定条件 → 违反；无结构失效 → 不适用。本确认口径仅适用于结构失效价位，不适用于规则失效价位（规则失效按 references/rules.md R20 及所引规则比较符立即判定）。
### 5. 主备方案独立性校验

- [ ] **I5-1 独立标注**（references/rules.md R24；references/terminology.md 1.7.5）
  - 判定标准：主方案与替代方案是否各自独立标注失效价位？各自标注 → 通过；任一方案缺失 → 违反。
- [ ] **I5-2 可区分性**（references/rules.md R24；references/terminology.md 1.7.5）
  - 判定标准：每个方案是否至少拥有一个**仅自身触发、其他方案不触发**的失效价位（独立价位）？是 → 通过；否（全部价位与其他方案共享）→ 违反。R24 的"独立标注"即指此要求；规则强制共享的价位（如两方案同为第 4 浪数法时 R7 价位相同）允许存在，但不得作为唯一价位，且共享价位触发后动作必须明确（两方案同时失效或按结构裁决）。
- [ ] **I5-3 切换路径**（references/rules.md R19）
  - 判定标准：每个方案失效后切换到哪个方案是否明确（如"主方案失效 → 启用替代 A；替代 A 失效 → 回退 02"）？明确 → 通过；缺失 → 违反。

### 6. 可执行性、距离与流程衔接校验

- [ ] **I6-1 可执行性**（references/rules.md R20）
  - 判定标准：价格触及失效价位时，能否明确判断方案失效而不是模糊区间？能 → 通过；模糊 → 违反。
- [ ] **I6-2 距离评分**（流程，references/guidelines.md G21）
  - 判定标准：失效价位距离是否作为概率排序指标（越远越安全）参与评分？已纳入 → 通过；未纳入 → 退回第 2 步 补充（属工作疏漏，不构成规则违反）。
- [ ] **I6-3 报告衔接**（流程/模板，`assets/失效追踪_invalidation.md`）
  - 判定标准：失效价位是否可直接填入 `assets/失效追踪_invalidation.md` 与 `assets/分析报告_report.md` 的失效价位清单章节（字段：方案、类型、失效价位、方向、规则依据、触发后果）？可直接填入 → 通过；字段缺失 → 退回第 2 步 补充（属流程/模板检查，不构成规则违反）。
- [ ] **I6-4 扩张平台止损**（Guideline，references/guidelines.md G25）
- 判定标准：扩张平台形方案是否成立扩张特征（B 终点 > A 起点，references/rules.md R28）且 C 浪终点已确认？是 → 通过（C 终点作为关键止损参考，反向突破需重新评估）；扩张特征成立但 C 未完成 → 不适用（备注：待 C 完成后复核）；非扩张平台形 → 不适用。
