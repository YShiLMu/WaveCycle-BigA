# 数浪校验清单（Checklists）

> 本文件合并 8 份校验清单（第 6/7/8 章为道氏/江恩/蜡烛图融合新增）。结论三态：**通过 / 不适用 / 违反**。"不适用"包括两类——①检查项与方案无关；②前提未证实（数据不足、结构未完成），两种情形都必须在备注写明原因；前提未证实的不适用由状态列/变更日志跟踪，条件满足后经 03 验证数浪复核更新结论。本清单结论态仅三态，不存在模糊判定态；涉及清单间裁定的检查项判"不适用"，最终结论以承接清单为准。Rule 权威见 `references/rules.md`，概率性见 `references/guidelines.md`。
