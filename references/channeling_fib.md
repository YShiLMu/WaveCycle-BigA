# 通道与深细斐波那契（Channeling & Advanced Fibonacci）—— 前提与验证

> 依据本地《Mastering Elliott Wave》ch06 页 6-1–6-4、ch09 页 9-1、ch12 页 12-8–12-10、12-22–12-28。原书 Neely 条件与项目 G28/G29 的辅助定位分别说明；不新增硬规则或评分权重。

## 第一部分：通道与事后证据

### 1.1 真实 2-4 趋势线与两阶段验证

先固定同级第 2、4 浪终点及时间坐标，画出连线；“真实”不能靠事后移动端点直到突破来取得。第五浪须已有完成候选及内部证据，再观察结束后的行为；突破本身不能补齐缺失的五浪。

Stage 1：按第五浪的形成用时观察 2-4 线的反向突破。未观察满时是待确认，窗口已满仍未出现才记预期未获支持。原书由此复查末端、第四浪或整个解释；原书ch12页12-8明确要求重新检查第五浪、第四浪或整体解释，不能仍称原完成假设已获Neely确认。本项目G28只将其接入辅助评价，不自动追加R19硬失效；若保留经典候选，须另列“经典候选保留／Neely完成确认未通过”，而非一律只减分后沿用确认状态。

Stage 2 必须绑定延长类型及父级位置（ch06 页 6-2）：

| 已确认的延长类型 | 原文回撤要求及限制 | 项目执行 |
| --- | --- | --- |
| 第一浪延长 | 先回到第四浪终点；当整段处于父级第 1／5 浪，常进一步回到第二浪区；处于父级第 3 浪时未必能回到第二浪区 | 不把“必回第二浪”用于所有位置；分别记录最低观察目标和条件预期 |
| 第三浪延长 | 回到第四浪区，常近第四浪终点；整段回撤超过 61.8% 涉及更大一级完成解释 | 分母必须是整段长度，不是第五浪长度 |
| 第五浪延长 | 至少回撤第五浪 61.8%；保持原趋势的情景要求不完全回撤第五浪；完全回撤提示更大趋势终结 | “完全回撤”撤回延续预期，不自动抹去已完成第五浪延长结构 |

`post_constructive_check.py` 用 K 线序号差计时、后续含影线极值检查穿线和回撤；这是项目对 OHLC 数据的操作口径，单根 K 内穿线的具体时刻不可知。脚本对第一／第三浪延长只给目标提示，不自动证明到达整个浪区或整段 61.8%。`--scan` 是扫描上限，不是所有形态的统一完成期限。

### 1.2 奔走双重三浪与通道

ch12 的通道辨识用于提示回头检查复杂调整，不允许只凭穿线命名 Running Double Three。先验证其组成、连接浪、父级位置及结束状态，再观察后势；局部越线还可能来自第四浪未完成或更小级别调整。

### 1.3 三角形与终结形态

收敛／发散不能单独区分 Triangle 与 Terminal。前者整体调整、后者在相应父级位置承担驱动身份；原书 Terminal 与经典 Ending Diagonal 有交集，但不能把两个体系的所有位置条件强行等同。经典楔形的位置合法性仍按 references/rules.md R9/R10 检查。

### 1.4 触点数与样本选择

G29 源于 ch09：比较的是**同一已固定通道、同一级别的候选端点**。推动的六个端点中四个触线、标准调整四点中三个触碰**平行趋势线**是辅助辨识；不能把不同级别的每根 K 高低都计为触点。先登记通道选点与触线容差，再计数，不能反复换线凑数。

本项目尚无统一的触线距离阈值；须披露本次测量口径，不能假称已由脚本精确确认。原书ch09页9-1–9-2中“超过四点”提示复杂调整的讨论针对平行线上的同级触点；标准调整“四点全部触线”也须平行线条件，不能直接推广到收敛／发散边界。复合解释仍须内部结构证明；未完成样本、三角形例外和缺数据分别列“不适用／前提未证实”。不新增 G29 的数值权重。

### 1.5 教学推演：先有窗口，再有结论

假设第二浪终点为 (序号10,120)，第四浪为 (20,150)，第五浪结束于 (25,180)。2-4 线斜率为每根 3，序号26处线价168。后续最低167即在项目含影线口径下穿线，用时1≤第五浪5根；收盘若169，则是“影线穿线、收盘未穿”，两种事实不得混写。

若后续只有2根且均未穿线，是窗口不足。线被及时突破也不证明第五浪内部、延长类型或父级位置已核验；Stage 2 另列分母与深度。

## 第二部分：内部相对比率与适用条件

内部关系（Internal Relationships）直接比较两个浪的价格长度；它不是“更小级别”的同义词。原书另有 External Relationships，不能将二者混用。本批只深化已经引入的内部关系，不扩展为新预测体系。

### 2.1 推动浪内部：按延长类型分别检查

记 Li 为第 i 浪价格长度，S03 为第 1 浪起点至第 3 浪终点的净价差绝对值（不是 L1+L3）。来源 ch12 页 12-23–12-24：

| 前提 | 内部关系 | 防止泛化 |
| --- | --- | --- |
| 第一浪延长／最长 | L3≤0.618L1；当 L3≈0.618L1 时 L5 常≈0.382L3，或 L3≈0.382L1 时 L5 常≈0.618L3 | 是对应类型的关系，不是所有推动都限制第三浪长度 |
| 第三浪延长 | L1 不按约0.618L3 关系解释；可约0.382L3或无明显内部关系；L4/L5 另查近等长或0.618/0.382；L5<0.618L3 | 不把没有精确比例当成项目 Rule 失效 |
| 第三浪延长，且第一浪相对第三浪极小 | 第五浪条件目标=第四浪终点±0.382S03 | 原稿遗漏“第一浪极小”前提；原文未给它统一量化阈值，不得自行补百分数 |
| 第五浪延长 | 若 L1/L3 存在所列内部关系，L3≈1.618L1；否则原文区间为 L1<L3<2.618L1 | 原稿误写上限为1.618，并遗漏第五浪延长前提 |

第三浪延长时，第四浪更复杂对应第五浪不少于第一浪的倾向；第二浪更复杂对应第五浪不大于第一浪的倾向，也须带着类型和复杂度证据使用。各条先列“适用／未证实／不适用”，再记录支持或冲突；不借它们修改经典 R5–R7。

### 2.2 修正浪内部：不能共用一条 C/A 上限

- 锯齿的普通内部 C/A 范围及约1.618上限见 ch12 页12-26；超出后还要检查外部关系与 Elongated 的位置，不能推广为所有调整 C 都不得超过1.618A。
- 同页平台段落用 C/A 比较约1.382；ch11 页11-13 的 Elongated 条件则明确比较 **C/B**，还要求 A/B 在价格或时间相似、C 消耗更多价格和时间。这是不同分母与条件，不能只保留“138.2%”然后混用。
- 三角形 C 常与 A 约0.618相关；B 大于 A 时也可能比较 C/B。原文明确提醒，不因单一比率未命中就删除三角形候选（ch12 页12-28）。

### 2.3 教学推演：同一个数值，不同的结论

假定第三浪延长且第一浪相对极小：起点100、第三浪终点300、第四浪终点260。S03=200，条件目标260+0.382×200=336.4。若缺少第一浪相对大小和内部结构证据，只能列条件演算；不能看到336.4附近价格就反证前提。

另假定第五浪延长候选 L1=40、L3=80。80/40=2.0 不符合1.618关系，但位于原文“未相关”的1至2.618区间；不能按旧稿错误上限1.618排除。这里通过的只是一项关系，父级规则、第五浪及完成证据仍需分别检查。
