## 第一部分：通道独特应用（Channeling, unique applications）

### 1.1 Real 2-4 Trendline（真实 2-4 趋势线）
区分"真实 2-4 趋势线"与普通通道：不是任何两条相邻浪终点连线都算 2-4 趋势线，只有穿过推动浪第 2、4 浪终点的线、且后续行为满足 confirm 条件（见 ch06 两阶段确认）才算真实 2-4 趋势线。用于最终确认波浪身份。

### 1.2 Detection of a Running Double Three（奔走双重三浪辨识）
用通道形态特征辨识"奔走双重三浪（Running Double Three）"——它是一种穿越通道、结构上容易误判为新的推动浪的修正形态。

### 1.3 Triangular / Terminal Activity（三角形 / 终结行为）
借通道形态（收敛 / 发散 / 平行 + 触点数量）判别当前属于三角形（Triangle）还是终结形态（Terminal）行为。

### 1.4 Channeling 识别 Impulse/Correction（用通道反推浪型）
用通道几何反推：内部通道是否被反复穿越、触点数量与平行度，辅助判定当前是推动（Impulsive）还是修正（Corrective）。

> 通道基础规则（触点数量、2-4 趋势线作为 Base line 的约束）详见 `references/guidelines.md`（G3/G4）与本系列第 6 条触点数规则（见 `references/checklists.md（Neely）` 第 3 节 + `references/guidelines.md` G29 追加段）。本文件只补充 ch12 的"独特应用"。

## 第二部分：深细斐波那契（Advanced Fibonacci Relationships）

这是现有 `references/fibonacci.md` 没有的**内部相对比率**（同一推动浪 / 修正浪内部各浪之间的细部关系）。

### 2.1 推动浪内部
- 当 **wave-1 是最长浪**：wave-3 不应超过 wave-1 的 **61.8%**。
- 若 wave-3 = 61.8% × wave-1（交替原则）：wave-5 通常 = 38.2% × wave-3；若 wave-3 = 38.2% × wave-1：wave-5 通常 = 61.8% × wave-3。
- **3rd 浪延长**时：wave-1 与 wave-3 **不应**呈 61.8% 内部关系（可能为 38.2% 或完全无关）。
- **3rd 浪最长**时：wave-4 与 wave-5 应近乎等长（100%），或按 61.8% / 38.2% 相关（按常见度从多到少排序）。
- **wave-5 目标** =（从 wave-1 起点到 wave-3 顶点的全程 × **38.2%**）加在 wave-4 末端；且 wave-5 必须 < 61.8% × wave-3。
- 若 wave-1 与 wave-3 相关：wave-3 = **161.8%** × wave-1；若不相关：wave-3 必须 >100% 但 <161.8%（继续判定）。

### 2.2 修正浪内部
- **wave-c 几乎不会超过 wave-a 的 161.8%**（含 b 浪的贡献）。
- **Wave-c in Zigzags / Flats / Triangles** 各有不同比率（如至少 161.8%；具体随形态而变化，见 ch12 表）。
