## 1. 艾略特经典波浪通道构建法（Elliott Trend Channels）

艾略特指出，平行的趋势通道能够以极高的几何精度界定驱动浪与调整浪的上下边界，为波浪运行目标的预估与结构完整性的校验提供关键几何基准。

### 1.1 推动浪初始通道构建几何法（Initial Channel for Wave 4）
推动浪的初始几何通道至少需要三个确立的波浪端点。该通道专门用于预估和约束**子浪 4** 的回撤边界。

```
       (3) 上轨基线 (1-3 Line)
       /  \
      /    \
     /      \
    (1)      \
   /  \       \
  /    (2) ─── [4] 预测下轨支撑 (Parallel line through 2)
 /
Start
```

#### 几何绘制步骤：推动浪初始通道
1. **基准上轨**：当子浪 3 确认终结后，连接**子浪 1 终点**与**子浪 3 终点**作一条直线；
2. **预测下轨**：通过**子浪 2 终点**作一条平行于 1-3 基线的平行线；
3. **理论作用**：该平行下轨为正在展开的子浪 4 提供了预期的几何支撑位。若子浪 3 行进极其陡峭，下轨线通常能有效界定子浪 4 的回撤极限。

### 1.2 推动浪修正通道构建几何法（Modified Channel for Wave 5）
当子浪 4 确认终结后，为了精确预估**子浪 5** 的终结目标边界，必须根据确立的第 4 浪端点重建通道。

```
              [5] 预测上轨目标 (Parallel line through 3)
              /  \
             /    \
            (3)    \
            / \     \
           /   \     \
          /     \     \
        (1)      \     \
       /  \       \     \
      /    (2) ─── (4) 下轨基线 (2-4 Baseline)
     /
   Start
```

#### 几何绘制步骤：推动浪修正通道
1. **基准下轨**：连接**子浪 2 终点**与**子浪 4 终点**，作一条贯穿两点的直线作为基准下轨；
2. **常规预测上轨**：若子浪 1 与子浪 3 结构正常（浪 3 延长但非垂直暴发），**通过子浪 3 终点作平行于 2-4 基线的平行线**作为上轨。该上轨能高度精准地预测子浪 5 的理论终点；
3. **浪 3 陡峭延长时的通道修正法**：
   - 若子浪 3 呈现异常暴发性拉升、几乎近于竖直，则通过浪 3 顶点做出的平行线位置将大幅偏高而失去几何指导价值；
   - **原著修正公理**：在此类极端行情下，应**通过子浪 1 的终点作平行于 2-4 基线的平行线**作为有效上轨（经典案例见 1976 年 8 月至 1977 年 3 月的伦敦金价走势）。

### 1.3 调整浪平行通道几何构建法（Corrective Channels）
在简单的 A-B-C 锯齿形调整浪中，市场通常以四个几何接触点构成完整的平行调整通道：

```
   Start (浪A起点) ───────── (B) 上轨基线
         \                  /  \
          \                /    \
           \              /      \
            \            /        \
             (A) ───────────────── [C] 预测下轨目标 (Parallel through A)
```

#### 几何绘制步骤：调整浪平行通道
1. **基准上线**：连接**浪 A 的起点**与**浪 B 的终点**，形成第一条基线；
2. **平行下轨**：通过**浪 A 的终点**作平行于前一条基线的平行线；
3. **理论作用**：一旦浪 B 确立，过浪 A 终点的平行线是预估浪 C 确切完结位置的核心几何工具。

## 2. 翻越现象的几何原理（Throw-over & Throw-under）

### 2.1 翻越定义与成因（Throw-over）
在平行趋势通道内或终结斜纹浪的两条汇聚趋势线内，第 5 浪终结阶段出现的短暂突破现象称为**翻越（Throw-over）**。

#### 几何与动力学成因：
1. **蓄势横移**：在翻越发生前，小一浪级的第 4 子浪通常紧贴着通道上轨（牛市）内侧下方横向震荡蓄势；
2. **成交量长钉（Volume Spike）**：随后的第 5 子浪在成交量急剧放大的爆发性冲刺中短暂刺穿上轨趋势线；
3. **反转印证**：翻越本质上属于假突破（False Breakout）。其技术有效性必须由**价格即刻跌回到上通道线下方的迅速反转**来最终印证。

### 2.2 翻下现象与前兆指示（Throw-under）
- **定义**：在推动浪进行过程中，浪 4 或浪 5 内部的第 2 子浪产生的短暂跌破通道下轨的现象称为**翻下（Throw-under）**。
- **理论前兆作用**：艾略特指出，通道下方的翻下往往构成后续即将在上轨发生翻越（Throw-over）的高可靠前兆几何信号。

### 2.3 翻越后的市场动力学行为
翻越现象标志着原有趋势在极限位置完成最后的能量宣泄：
1. **戏剧性反转**：翻越终结后，市场必将迎来极其陡直且迅速的剧烈反向运动；
2. **多级别共振**：当小级别的翻越与大一浪级通道上边界发生时空重叠时，反转将呈现出倍增的杀伤力。

## 3. 交替原则理论体系（The Rule of Alternation）

交替原则（The Rule of Alternation）是艾略特波浪理论中应用极其广泛的核心指导原则。其实质提醒分析人员：**相似的波浪在下一次演变中倾向于以不同的形态展开**。

### 3.1 推动浪中的交替（Alternation in Impulse Waves）
在一个推动浪的五浪序列中，两个反作用调整浪——**子浪 2 与子浪 4** 之间呈现出全方位的互补交替：

```
               [推动浪中的典型交替模式]
模式 A: 浪 2 为陡直调整（锯齿形） ───> 浪 4 为横向调整（平台形 / 三角形）
模式 B: 浪 2 为横向调整（平台形） ───> 浪 4 为陡直调整（锯齿形 / 双重锯齿）
```

#### 交替的具体维度：
1. **形态风格交替**：
   - 若浪 2 表现为**陡直调整（Sharp Correction）**（如单锯齿形、双重锯齿形），则浪 4 绝大多数表现为**横向调整（Sideways Correction）**（如平台形、三角形、双重三浪）；
   - 反之，若浪 2 表现为横向平台形调整，则浪 4 倾向表现为陡直锯齿形调整。
2. **空间深度交替**：
   - 浪 2 通常以极深的空间回撤展开，常回撤浪 1 的 50% 至 61.8% 以上，直逼浪 1 起点；
   - 浪 4 通常回撤幅度较浅，主要回撤浪 3 的 38.2% 左右。
3. **极端价格交替**：
   - 两个调整浪中，必有一个调整过程包含返回或超越前一推动浪正统终点的极端价格（如扩散平台、顺势三角等横向风格）；而另一个调整过程则绝不包含新的极端价格。
4. **驱动浪长度与延长的交替**：
   - 驱动浪同样交替其长度：若第 1 浪较短，第 3 浪出现延长，则第 5 浪倾向于短浪且与第 1 浪趋向等同；
   - 若第 1 浪与第 3 浪均未发生显著延长，则第 5 浪成为延长浪的概率极高。

### 3.2 调整浪中的交替（Alternation in Corrective Waves）
在大级别调整浪的演化过程中，相邻子浪之间同样遵循交替原则：
1. **A 浪与 B 浪的形态交替**：
   - 若调整浪以平台形结构的浪 A 启程，则浪 B 倾向展开为锯齿形结构；
   - 若调整浪以简单锯齿形的浪 A 启程，则浪 B 倾向演化为子浪结构更加复杂的锯齿形或横向复合调整浪。
2. **复杂性的逐级递增**：
   - 大级别调整浪中常见复杂性阶梯：简单浪 A $\to$ 较复杂浪 B $\to$ 高度复杂浪 C。

## 4. 刻度选择的理论原理（Arithmetic vs Semilogarithmic Scale）

在波浪通道与几何形态观察中，选择正确的图表坐标刻度是确立有效通道的先决条件。

### 4.1 两种刻度的本质特征
1. **算术刻度（Arithmetic Scale）**：横纵坐标均为等距线性分布，强调价格变化的**绝对点数**；
2. **半对数刻度（Semilogarithmic Scale）**：纵坐标按百分比比率指数分布，强调价格变化的**相对变化幅度（百分比）**。

### 4.2 浪级与刻度的适用性公理
普莱切特与弗罗斯特在经典原著中确立了关于刻度的权威结论：
1. **大级别通道的半对数必然性**：
   - 对于大浪级（Primary）、循环浪级（Cycle）及更高浪级的宏观长期波浪，由于价格跨越数倍乃至数十倍，必须采用**半对数刻度**绘制趋势通道，方能真实体现群体心理加速过程与斐波那契通道包络；
2. **中小级别的算术刻度有效性**：
   - 对于中浪级（Intermediate）及以下级别（如日线、60 分钟走势），由于特定波段内的百分比差异在算术项上相差较小，采用**算术刻度**能够高度有效且简便地构建平行通道；
3. **双刻度验证准则**：
   - 当在一种刻度下观察到的价格波动呈现无序扭曲或无法落入两条平行趋势线内时，必须及时转换至另一种坐标刻度进行审视；
   - 唯有在适宜的刻度下，波浪形态与平行通道方能展现出其内在的和谐与“恰当的外观（Right Look）”。
