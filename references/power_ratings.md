# 功率评级（Power Ratings）—— 完成方向与回撤条件

> 依据本地《Mastering Elliott Wave》ch10 页10-1–10-6。文字版原表为分离列，向上列19项可顺序核对并结合后续变体说明纠错；向下列末尾及三角形表注行归属有OCR噪声。下表向下列部分依原文方向反转说明对应整理，尚未完成原图逐行核验；不据此补造逐行三角形零评级。功率评级不并入G21/D25八因子，也不是胜率、做多／做空信号或Rule失效价位。

## 1. 评级首先表达方向性强弱

正负号表达对市场上涨的有利／不利，不是脱离方向的“形态质量”。同一类型向上完成与向下完成取不同符号；不能仅比较绝对值就选主方案。原表同分的细序也不等于额外分值，本项目不新增计分。

“完成方向”须以原书相应形态及末段结束方向辨明，不把大趋势方向、持仓方向或形态净涨跌自动替代。特别是奔走、失败或复杂调整，先核对具体类型和父级位置。

## 3. 回撤预期：0不是100%目标，绝对值不能抹去方向

ch10页10-2明确：**0不规定特定回撤比例**，从很小回撤到超过100%都可能。原稿与脚本把它写成“约100%”，应撤回这一目标。

原文一般幅度参照列出：±1约不超过90%、±2约不超过80%、±3约60%–70%。但它同时要求结合方向及具体变体：页10-1直接讨论“向上完成且评级+1至+3”的不宜完全回撤预期；页10-5的C-Failure与Irregular Failure却明确预期被同级后续形态完全回撤。**因此不能把所有负评级向上完成形态也机械套成≤90%或60%–70%。**

原书一般回撤参照与特殊变体后势并列，未提供一段与本项目完全相同的分支算法。为避免一般参照覆盖具体变体，本项目采用保守输出约定：查询脚本只对表中向上为正／向下为负的对应情景展示一般幅度参照；0输出无固定比例；向上为负／向下为正的反向力量情景提示查具体变体，不输出统一的绝对值上限。上述数字都是原书关系的参考，不当作本项目新增止损阈值。

## 4. 先确定评级对象，再观察后续同级形态

1. 先完成局部结构验证并做Compaction，使用当前**最大已完成形态**。若小型双锯齿恰好结束更大的Terminal，不能继续用小型双锯齿评级预测整个后势（ch10页10-2）。
2. 后续对象须是同级形态，区分其形成中与已完成；一根反向K线不等于下一完成形态。
3. 三角形或Terminal的一条腿不一定把评级含义传递给下一腿。ch10页10-1以Double Zigzag为例说明可能被完全回撤；这比旧稿“只有三种特例归零”的说法更广，但不等于所有腿统一评级0。
4. 非零评级结构被更接近0的同级结构完全回撤，是复查Triangle／Terminal的线索；仍需独立的内部组成和位置证据，不能直接命名新形态。

完整性、Compaction、位置或方向任一未确认，记录“不适用（前提未证实）”。不能把脚本查表成功当作这些前提已经通过。

## 5. 教学例与现有八因子的关系

假设一个已完成、未包含在同时结束的更大结构中的向上Double Zigzag，端点100→150，评级+2；在位置和方向条件适用时，下一同级回撤约80%的参考价为150−0.8×50=110。它不是110一触即Rule失效，也不保证价格必到110。

若该结构只是Terminal最后一腿，则上述投射不能继续用于最大形态；若查的是中性Zigzag，不能预测一定回到100；若查的是向上C-Failure（−1），还须读其完全回撤后势，不能用绝对值1给出“最多90%”。
