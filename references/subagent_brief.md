# 子代理数浪契约包（Sub-agent Brief）

> **拼装说明**：本文件由 `build_package.py` 拼装生成——第 2 块从数浪工作流的 `SUBAGENT-BRIEF` 锚点区**只复制不移动**抽取（源正文保留），其余块取固定头尾源。权威仍在 `references/rules.md` / `references/patterns.md` / `references/terminology.md`，本文件仅为子代理必查项摘录。
>
> **用法**：主 agent 派发第 3 层细分子代理时，用 `scripts/print_subagent_brief.py` 取契约包全文，**逐字拼接**进派发提示词；子代理零文件读取。

## 1. 任务边界

- **输入**：**数据文件路径**（子代理据此只读窗口数据，中间产物只写 `%TEMP%`）、浪标签（如 `1-1`）、K 线区间（起止日期）、级别、目标深度、**预期段数**（推动 5 / 调整 3 / 锯齿内 5-3-5 等，由主 agent 按父浪形态给出）。
- **输出**：该区间内的子浪端点清单（格式见第 5 块）。
- **不越界**：只数给定区间；Guideline（交替/通道/共振）**不参与子代理裁决**；**不自行判断结构**——结构由主 agent 指定。

## 2. 段数契约与端点纪律（单一出处）

**每层端点纪律（R20）**：每一层的每个浪段起点/终点必须从上位 swings 前向扫描取含影线极值（references/rules.md R20；见 2.5 端点选取纪律），逐层用更小 `--k` 或人工确认更细摆动；禁止凭记忆填端点。每层端点登记为"浪标签点分 + 日期 + 极值"，供 ew_chart 多层叠加（`--path` 多条）。

**数浪段数契约（硬性，数浪与绘图共同标准）**：任一层的浪都必须满足标准段数与端点——**推动浪 = 5 段 6 端点**（起点→1→2→3→4→5 终点，升-降-升-降-升严格交替，第 3 浪通常最长/非最短，第 4 浪不与第 1 浪重叠 R7）；**调整浪 = 3 段 4 端点**（A-B-C）。凡在给定区间数不出符合标准的段数（数成 4 段、2 段等），**一律标"待确认"，不得硬凑**；端点一律 swings 含影线极值（R20）。

## 3. 必查规则

- **R5** 第 2 浪回撤 ≤ 第 1 浪的 100%；
- **R6** 第 3 浪不得是 1/3/5 中最短；
- **R7** 第 4 浪不得进入第 1 浪价格区域（楔形除外）；
- **R20** 端点一律取含影线极值，且对段内前向扫描取极值；
- **R23** 同层级符号不混用；
- **R17/R29 一行版**：第 5 浪终点未超第 3 浪终点时不得判失败浪，标"待确认"并附疑点。

## 4. 标注规范

- 第 3 层写作 `1-1-1`（数字点分，层数 = 连字符段数）；
- 推动段用数字，调整段用 A-B-C。

## 5. 返回格式

`标签点分 | 起日期:极值 | 终日期:极值 | 段数达标/待确认`；歧义另附"疑点"行。**不含"读取记录"字段**（子代理零文件读取）。

## 6. 禁止项

- 不得凭通用艾略特常识替代本 skill 口径；
- 不得硬凑段数、不得预标未完成子浪（R34）；
- **不得读取任何 skill 文件**；
- 凡非教科书级清晰的结构一律"待确认"，强行闭合视为违规。
