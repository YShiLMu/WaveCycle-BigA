## 1. 模板说明与执行前提

### 1.1 核心原则
- **概率与仓位绑定**：仓位大小必须严格受限于八因子加权总分及共振状态标签（仓位闸门，口径见 `references/workflow.md` §03-4.3）；

## 2. 仓位风控闸门表（对齐 `references/workflow.md` §03-4.3 与 D13）

> **口径变更声明**：原按「八因子总分区间（85/70/50）」映射仓位的表**已废止**——`references/workflow.md` §03-4.3 第 7 条明文规定不得按总分区间直接映射仓位。仓位只能由「D13 基础档位 × 共振标签」共同决定，且终档不得高于功率评级（D35）上限。

### 2.1 第一层：基础档位（D13，Guideline 原始得分差，不乘 2）

| 基础档位 | 判据（Guideline 原始得分差） | 初始仓位 |
| :---: | :---: | :---: |
| 建仓 | ≥ 3 | 30%–50% |
| 轻仓 | = 2 | 10%–20% |
| 观望 | ≤ 1 | 0% |

### 2.2 第二层：共振标签调整（`references/workflow.md` §03-4.3 第 6、7 条）

| 共振标签 | 判定（按「计 2 分项数」，不看总分） | 调整动作 |
| :--- | :--- | :--- |
| 三共振 | 道氏、江恩价格、江恩时间三项中计 2 分者 ≥ 3 | 升一档，累计最多升两档 |
| 双共振（含道氏一致） | 计 2 分项数 = 2，且道氏一致性 = 2 | 升一档 |
| 双共振（不含道氏一致） | 计 2 分项数 = 2，且道氏一致性 ≠ 2 | 不干预，保持基础档 |
| 单信号 | 其余情形 | 封顶轻仓 |
| 背离 | 道氏一致性 = 0 | 强制观望，不参与升档 |

### 2.3 终档 → 仓位区间

| 终档 | 仓位区间 | 到达路径 |
| :---: | :---: | :--- |
| 进取 | 60%–80% | 建仓档经双共振升一档，或轻仓档经三共振连升两档 |
| 标准 | 30%–50% | 建仓基础档，或轻仓档经双共振升一档 |
| 轻仓 | 10%–20% | 轻仓基础档，或建仓档被单信号封顶 |
| 观望 | 0% | 基础档为观望，或触发背离 |

**硬约束**：
- 终档不得高于功率评级（D35）给出的上限；
- 单方案防御模式直接锁死「观望，不执行交易。」，不参与上述任何升档；
- 入场、止损、止盈的每个价位必须取自报告 6.1／6.2 两张表（见 §3.0）。

## 3. 入场、止损与目标参数模板

### 3.0 价位来源约束（短期支撑压力，强制）

- 入场、止损、止盈的**每一个价位都必须取自报告 6.1「短期支撑压力表」或 6.2「多周期共振表」**，不得另行临时计算或目测挂单。
- 止损默认取该方向最近的 **3 级**位；若该位同时是硬失效边界，直接改用报告第 5 章的失效价位。
- 止盈按 **1 级 → 2 级 → 3 级**分批；价格进入 **1 星及以上**共振带时减仓或上移保本。
- 级别与星级表述固定为「N 级」「N 星」，禁止「弱／中强／强」；口径见 `references/short_term_sr.md` 与 `references/multiframe_resonance.md`。

### 3.1 入场条件触发（Entry Triggers）
- **【结构确认触发】**：价格有效突破关键阻力线（如浪 1 高点、调整浪 B 点、三角形突破线）；
- **【蜡烛图执行信号】**：极值点出现看涨/看跌吞没、启明星/黄昏星，且次日收盘获得放量确认；
- **【斐波那契共振落位】**：价格精准回踩至 0.618 或 0.50 密集共振区。

### 3.2 止损设定（双层止损体系）
- **【形态止损（紧凑止损）】**：设置在触发信号的 K 线形态极值外侧（如启明星最低点下方 1~2 个 tick）；
- **【波浪硬失效止损（最终底线）】**：严格设置在对应硬规则失效价位（如 R-IMP-07 浪 2 破浪 1 起点），绝不越过该底线。

### 3.3 止盈目标（Target Projections）
- **【第一目标位（T1）】**：斐波那契典型等度位（如浪 1 幅度 1.00 倍，或 0.618 黄金分割位）；
- **【第二目标位（T2）】**：斐波那契延长共振区（如浪 3 延长的 1.618 倍，或通道上轨交汇处）。
