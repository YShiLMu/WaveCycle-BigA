# 04 交易计划（Trade Plan）——概率排序落地模板

> **用途边界**：本模板为**内部工作底稿**（仓位/入场/止损/目标草稿），产出**不进入 `分析输出/` 归档、不作为交付物**；需要交付的交易计划内容并入分析报告.md 的【6. 交易计划建议】节（归档规则见技能 SKILL.md「输出归档」）。
>
> **本文件定位**：交易计划模板，是概率排序的落地容器：仓位、入场、止损、目标全部绑定概率排序与失效价位，不得脱离排序单独给出（references/guidelines.md G21）。由 04 生成报告「报告结构（8 章节）」第 6 章使用，references/workflow.md 第 5 步第 7 节（概率重新排序）在新排序后调整。只提供计划骨架，不构成确定性预测（references/guidelines.md 前言），亦不构成投资建议。
>
> **前置依赖**：术语见 `references/terminology.md`，规则见 `references/rules.md`（R19、R20），概率经验见 `references/guidelines.md`（G21、G25），比率表见 `references/fibonacci.md`，填写与调整规则见 `references/workflow.md（第 4 步）`「交易计划与概率绑定」节、`references/workflow.md（第 5 步）` 第 7 节（交易计划调整），联动模板见同目录 `assets/分析报告_report.md`、`assets/失效追踪_invalidation.md`。

## 1. 模板说明与使用前提

### 1.1 定位

- 交易计划必须基于概率排序，主方案与替代方案必须分别给出仓位、入场、止损、目标与退出路径（references/guidelines.md G21；04 生成报告「交易计划与概率绑定」节）；
- 本模板只提供计划骨架，不构成确定性预测（references/guidelines.md 前言），不构成投资建议。

### 1.2 使用前提

- 只有在 03 验证通过、04 报告生成后才可填写；
- 概率排序变化后必须按 references/workflow.md 第 5 步第 7 节（概率重新排序）重新调整本计划。

## 2. 仓位模板

### 2.1 得分差三档规则表（04 生成报告「交易计划与概率绑定」节）

| 得分差（主方案 Guideline 原始得分 − 替代方案得分，不乘 2） | 仓位档位 |
| --- | --- |
| ≥3 分 | 按主方案建仓，替代方案作为止损触发后的退路 |
| 2 分 | 轻仓试探，以主方案为主，保留替代方案退出路径 |
| ≤1 分 | 观望，等待结构清晰 |

### 2.2 仓位调节字段

- 【主方案得分】【替代方案得分】【得分差】【对应档位】【仓位比例】；
- 调节规则：失效价位越远，仓位可越重；失效价位很近时，即使主方案概率高也应控制仓位（references/guidelines.md G21"失效价位距离"指标）。
- **交互机制**：先按得分差确定基档；再按 references/guidelines.md G27 的共振状态闸门调整档位（三共振、含道氏一致的双共振可上调；单信号封顶轻仓；背离强制观望）；最后才以失效距离在调整后的档位内微调，距离远取档位上沿、近取档位下沿。得分差机制与共振闸门均须在计划中披露。

## 3. 入场与目标字段

### 3.1 入场条件

- 【结构确认】：如 C/D 子浪展开、三角形突破确认等；
- 【蜡烛图触发】：短期入场时机由蜡烛图执行信号给出（references/candlestick.md第 7 节）——须同时满足三闸门：方向（与主趋势一致）、验证（反转形态次日确认）、落位（信号落在支撑/阻力/回撤/共振位），并写明触发价位（= 该支撑位或信号 K 线收盘价）；假突破（破低反涨）收盘收回确认后为横盘区间买入触发（CS-11）。
- 【价格进入目标区】：价格进入比率目标区（references/fibonacci.md 第 3 节）；
- 填写提示：**入场理由必须引用结构或比率依据**（08 第 2、3 节），禁止写"感觉到位"类表述；蜡烛图触发是执行时机补充，不替代结构确认、不脱离概率排序。

### 3.2 目标字段

- 【主方案目标】：按比率目标与共振区填写（references/guidelines.md G6、G8；08 第 1、3 节）；
- 【替代方案目标】：与主方案分开填写；
- 禁止写"越高越好""看情况"（目标必须可执行）。

## 4. 止损与退出字段

### 4.1 止损位（双层）

- 【形态止损（更紧）】：以触发信号的形态极值为依据（多头：锤子低点 / 吞没低点 / 启明星低点 / 趋势线之下），按极端价位（含影线）设在其外侧；偏移量由用户根据风险偏好设定（建议按 ATR 或最小价格单位的 1–2 倍）。
- 【失效止损（最终）】：以波浪失效价位为**依据**，按极端价位（含影线）设置在失效价位之上/之下——偏移量同口径，但不得越过失效价位本身（references/rules.md R20）；禁止在失效价位之外另设无依据止损。
- 【取舍】：形态止损只能比失效价位更紧（更靠近当前价）；若形态止损落在失效价位外侧，则采用失效价位（references/candlestick.md第 7.3 节）。

### 4.2 退出路径

- 主方案触发规则失效 → 切换替代方案（references/rules.md R19、R24）；
- 替代方案触发失效 → 离场或启用备选（references/rules.md R19、R24）。

### 4.3 扩张平台止损提示

扩张平台形 C 浪终点常成为关键止损位，反向突破需重新评估（references/guidelines.md G25）。

## 7. 实战示例：得分接近时强制观望（示例值）

> 以下数值仅演示字段填写，非真实行情。假设 03 已允许移交，主方案第 4 浪平台形、替代方案第 4 浪三角形；主方案 Guideline +3、替代方案 +2，共振状态为不含道氏一致的双共振（不干预基础档位）。

**【2. 仓位】**（示例）

| 字段 | 值 |
| --- | --- |
| 主方案得分 | +3 |
| 替代方案得分 | +2 |
| 得分差 | 1（≤1 分档） |
| 对应档位 | 观望，等待结构清晰（04 生成报告「交易计划与概率绑定」节） |
| 仓位比例 | 0%；双共振不含道氏一致，不上调基础档位，失效距离不得把观望改成开仓 |
| 仓位调节 | 保留主备失效距离与共振状态记录；待重新评分后先重算基础档位，再应用 G27 闸门 |

**【3. 入场与目标】**（示例）

- 入场条件：当前不入场。等待 C/D 子浪结构、主备区分证据和评分差重新满足执行条件，再核对蜡烛图三闸门。
- 主方案目标：只保留经 03 验证的 C 浪比率推导及适用条件；C 内部五浪与父级边界未确认前，不输出可执行目标区。
- 替代方案目标：第 5 浪 ≈ 三角形最宽处距离（references/guidelines.md G15），仅在三角形 E 与父级位置确认后计算条件目标。

**【4. 止损与退出】**（示例）

- 止损位：当前无持仓，不设执行止损；继续监控各方案已验证的规则失效与结构失效价位。
- 退出路径：主方案触发规则失效 → 按 05 分支升级已验证替代；仅结构失效触及或确认 → 主方案观察中、替代并行跟踪，不自动升级（references/rules.md R19、R24；references/workflow.md 第 5 步第 2 节（失效价位监控））。
- 扩张平台提示：若平台形确认为扩张变体，C 浪终点为关键止损参考，反向突破需重新评估（references/guidelines.md G25）。

**【5. 风险与披露】**（示例）

- 建议关注项：两方案得分接近（差 1 分）、结构待确认（C/D 子浪未展开）；替代方案 D/E 尚未完成。
- 歧义说明：平台形 vs 三角形依赖 C/D 结构最终区分。
- 评分构成披露：加权总分 = 2×Guideline 得分 + 结构完整度 + 斐波那契共振 + 道氏一致性 + 江恩价格共振 + 江恩时间共振 + 蜡烛图信号 + 失效距离（2:1:1:1:1:1:1:1，references/defaults.md D25）；"失效距离相近"判定带 = 相对差 < 当前价格 10%（references/workflow.md 第 5 步第 7 节（概率重新排序）注）。
- 概率表述：本计划基于"大概率/倾向于"的概率判断，不构成确定性预测，亦不构成投资建议（references/guidelines.md 前言）。

---

**小结**：交易计划 = 仓位（三档 + 失效距离调节）→ 入场/目标（结构 + 比率依据）→ 止损/退出（失效价位绑定）→ 风险披露（评分构成 + 概率表述）→ 更新日志。计划与排序绑定，排序变则计划变（references/workflow.md 第 5 步第 7 节（概率重新排序））。
